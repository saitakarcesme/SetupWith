# Windows Terminal setup prompt

Set up Windows Terminal from its verified official source (https://apps.microsoft.com/detail/9n0dx20hk701). Supported targets: Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install Microsoft's published Windows Terminal package from the Microsoft Store or its official release channel, preserving inbox Terminal behavior and selecting Preview only if the user specifically asks for the less stable channel.

Preserve the existing settings JSON, fragments, color schemes, profile GUIDs, command histories owned by shells, startup directory, default-terminal registration, pinned shortcuts, and Store or Preview channel selection. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: default_profile, startup_directory, color_scheme, default_terminal_application. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not overwrite settings JSON, change the system default terminal, install shells, enable acrylic effects, alter execution policy, add elevated profiles, or run profile commands before showing the exact configuration diff. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the signed package identity and version, validate the settings file as JSON, open one ordinary non-elevated tab for the selected existing shell, and verify no profile, default-terminal registration, or shell history was modified. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
