# Flatseal setup prompt

Set up Flatseal from its verified official source (https://flathub.org/apps/com.github.tchx84.Flatseal). Supported targets: Linux. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install Flatseal from its verified Flathub application ID, determine whether the existing Flatpak installation uses user or system scope, and export current overrides before opening any application's permission controls.

Preserve all user-level and system-level Flatpak overrides, filesystem grants, device and socket permissions, environment variables, persistent directories, portal choices, application data, and the current Flathub remote configuration. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: flatpak_scope, override_backup, permission_review, reset_strategy. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not broaden filesystem, session bus, system bus, device, network, Wayland, X11, or PulseAudio access; reset overrides or expose home directories without reviewing each permission's sandbox consequence with the user. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the Flatpak application ID, origin, commit, and sandbox permissions, open Flatseal without changing a toggle, export and compare overrides, and verify every installed Flatpak retains its exact pre-install permission set. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
