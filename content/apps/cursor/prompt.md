# Cursor setup prompt

Set up Cursor from its verified official source (https://www.cursor.com/downloads). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download the stable Cursor build matching the machine architecture from Cursor's official downloads page and install it beside other editors without changing file associations or defaults.

Preserve Preserve current Cursor user data, extensions, workspace trust records, settings sync state, keybindings, indexed-project metadata, and all VS Code profiles that may coexist.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: editor_theme, preferred_shell, privacy_mode, codebase_indexing. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not import VS Code settings, sign in, open a private repository, start codebase indexing, install extensions, or enable shell commands and telemetry without separate approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run Cursor's version command and open one empty window, confirm the expected profile and extensions directories, then verify that no project was indexed and no default editor association changed. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
