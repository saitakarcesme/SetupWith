# ClamAV setup prompt

Set up ClamAV from its verified official source (https://github.com/Cisco-Talos/clamav). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install the official stable ClamAV package or trusted distribution build, keeping the on-demand scanner, signature updater, and scanning daemon as separate components.

Preserve signature databases, `clamd.conf`, `freshclam.conf`, scan logs, quarantine locations, service definitions, and any existing update schedule. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: database_directory, quarantine_directory, scan_scope, update_schedule. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not scan personal or system files, delete or quarantine results, download signatures, enable daemons, or send metadata to update services without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `clamscan --version` and configuration checks; scan only the official harmless EICAR test file when explicitly approved, then remove that generated test file. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
