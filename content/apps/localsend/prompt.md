# LocalSend setup prompt

Set up LocalSend from its verified official source (https://github.com/localsend/localsend). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install the signed official LocalSend desktop package or trusted distribution build for the current platform and architecture.

Preserve LocalSend settings, device identity, transfer history, saved files, download destination, firewall rules, and autostart preferences. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: download_directory, device_name, discovery_enabled, listen_port. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not grant network or notification permissions, open firewall ports, discover devices, send or receive files, change the device name, or enable autostart without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch LocalSend with discovery disabled when possible, confirm the version and download path, and stop before advertising the device or transferring data. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
