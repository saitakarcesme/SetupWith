# Kdenlive setup prompt

Codex, first inspect the OS, architecture, shell, GPU capabilities, existing Kdenlive installation, project folders, proxy settings, render profiles, plugins, and media cache. On Linux prefer the distribution package or official AppImage/Flatpak; on macOS and Windows use Kdenlive’s official signed packages. Ask before administrator access, replacing the application, installing codecs, changing file associations, enabling hardware acceleration, downloading effects, or overwriting project settings. Preserve all `.kdenlive` projects, custom profiles, keyboard shortcuts, title templates, proxies, and render presets. Configure only `project_directory`, `proxy_enabled`, `default_profile`, and `render_directory` when supplied. Validate the selected project profile, frame rate, storage capacity, and proxy path before applying changes. Do not modify existing project files or regenerate proxies without approval. Verify application launch, version information, MLT backend detection, codec availability, project and render directory permissions, and export of a short disposable color clip to a temporary file. Confirm that hardware acceleration is actually supported before enabling it. Rollback restores backed-up preferences, removes only codecs or packages installed here, and leaves projects and media untouched. Finish with a structured summary of package source, profile, proxy state, render path, codec checks, approvals, and rollback.
