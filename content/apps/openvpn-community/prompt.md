# OpenVPN Community setup prompt

Set up OpenVPN Community from its verified official source (https://github.com/OpenVPN/openvpn). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use an official OpenVPN Connect client where appropriate or the trusted Community package for command-line use, and review required network drivers and service integration before elevation.

Preserve VPN profiles, certificates, private keys, authentication files, route and DNS settings, logs, and existing network adapters. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: config_directory, dns_preference, route_policy, autostart. The only available credential references are secret://openvpn/auth-password. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not import profiles, read private keys, connect to a VPN, install drivers, change routes or DNS, enable autostart, or log credential values without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run the client version and configuration parser against only an approved redacted profile; do not initiate a tunnel or contact its remote endpoint. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
