# Joplin setup prompt

Codex, inspect the OS, architecture, shell, existing Joplin desktop or terminal installation, profile directory, notes database, resources, plugins, encryption state, synchronization target, and external editor settings before changing anything. Prefer the official signed Joplin desktop package on macOS, Windows, and supported Linux systems; use the official terminal application only when a CLI workflow is requested. Ask before administrator access, replacing an app, changing sync targets, opening a browser, authenticating to a cloud provider, enabling encryption, installing plugins, or modifying note data. Preserve the profile, database, resources, encryption keys, templates, and synchronization metadata. Configure only `notes_directory`, `sync_target`, `default_editor`, and `theme` when supplied. Use `secret://provider/JOPLIN_TOKEN` only through a protected environment or application credential store; never print, echo, log, or commit it. Do not run synchronization until the target and conflict strategy are approved. Verify application launch or `joplin version`, profile readability, editor path, theme persistence, and creation plus export of a disposable note. Rollback restores profile settings, removes only the temporary note and installed application, and never deletes synchronized or encrypted data. Finish with a structured summary of package type, profile, sync state, editor, theme, verification, approvals, and rollback.
