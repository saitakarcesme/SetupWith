# OBS Studio setup prompt

Codex, inspect the operating system, architecture, shell, GPU, audio devices, cameras, existing OBS Studio installation, profiles, scene collections, plugins, recording paths, and hardware encoders before changing anything. Use the official signed OBS package on macOS or Windows; on Linux prefer the distribution package or official Flatpak when appropriate. Ask before administrator access, replacing the application, changing file associations, installing plugins, accessing cameras or microphones, opening firewall ports, enabling virtual cameras, browser sign-in, or overwriting profiles. Preserve all scenes, sources, filters, hotkeys, stream settings, and recordings. Configure only `recording_path`, `video_resolution`, `video_fps`, and `hardware_encoder` when supplied. Validate encoder support against detected hardware and never silently reduce quality. Reference `secret://provider/TWITCH_STREAM_KEY` and `secret://provider/YOUTUBE_STREAM_KEY` only through OBS’s protected service configuration after approval; never print, echo, log, or expose them. Verify application launch, profile loading, device enumeration, encoder availability, and a short local recording using a temporary scene without streaming. Rollback restores backed-up profiles, removes only plugins added here, and uninstalls only this run’s package. Finish with a structured summary of installer, devices, encoder, recording settings, verification, approvals, and rollback.
