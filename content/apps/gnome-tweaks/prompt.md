# GNOME Tweaks setup prompt

Set up GNOME Tweaks from its verified official source (https://gitlab.gnome.org/GNOME/gnome-tweaks). Supported targets: Linux. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install GNOME Tweaks from the active Linux distribution's signed repository, first confirming that the current desktop session is GNOME and recording its version, extensions, themes, and package-manager transaction plan.

Preserve all dconf values, GNOME Shell extensions, user and system themes, fonts, startup applications, input preferences, window focus behavior, scaling values, and desktop settings managed by organizational policy. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: font_scaling, window_focus_mode, startup_applications, theme_selection. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not add third-party themes or extensions, edit system theme directories, reset dconf, change startup applications, alter font scaling, or modify accessibility and input behavior without showing the exact affected keys first. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the repository package and version, launch Tweaks in the existing GNOME session, inspect requested panels without saving changes, and compare relevant dconf keys against the baseline to prove unapproved desktop settings remain intact. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
