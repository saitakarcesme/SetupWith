# Postman setup prompt

Set up Postman from its verified official source (https://www.postman.com/downloads/). Supported targets: macOS, Linux, Windows, Web. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Choose the Postman desktop application for the detected operating system from Postman's verified downloads page and distinguish it from the optional Desktop Agent and CLI.

Preserve Preserve local Scratch Pad data, collections, environments, certificates, proxy settings, cookies, workspace caches, account state, and any separately installed Postman Agent or CLI.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: workspace_mode, proxy_settings, certificate_store, update_channel. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not sign in, synchronize a workspace, import collections, install the Desktop Agent, trust client certificates, configure a proxy, or send any API request without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch Postman in local signed-out mode, report its version and data paths, confirm existing local items remain present, and verify that no request, sync, or background agent started. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
