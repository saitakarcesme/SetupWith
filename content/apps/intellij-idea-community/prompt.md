# IntelliJ IDEA Community setup prompt

Set up IntelliJ IDEA Community from its verified official source (https://github.com/JetBrains/intellij-community). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use JetBrains Toolbox or the official Community Edition package for the current platform; select a stable release compatible with the user's JDK and avoid silently replacing another JetBrains edition.

Preserve IDE settings, plugins, trusted-project records, local history, custom VM options, and existing project metadata. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: jdk_path, editor_theme, editor_font_size, project_directory. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not import settings, install plugins, associate file types, or open and index private projects without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch the Community edition, report its build and runtime JDK, create no project, and verify the configured JDK and command-line launcher only if requested. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
