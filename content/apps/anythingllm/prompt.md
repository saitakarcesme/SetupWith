# AnythingLLM setup prompt

Set up AnythingLLM from its verified official source (https://github.com/Mintplex-Labs/anything-llm). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Choose either the signed desktop application or documented Docker deployment after confirming the desired trust boundary; use only official release artifacts and keep data storage explicit.

Preserve workspaces, vector data, uploaded documents, application databases, Docker volumes, provider settings, and existing credentials. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: deployment_mode, llm_provider, embedding_provider, storage_directory, listen_address. The only available credential references are secret://openai/api-key, secret://hf/token. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not ingest documents, connect an external provider, reveal API keys, enable multi-user access, or expose the service beyond loopback without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch to the onboarding screen or check the loopback health endpoint with no provider configured, report storage paths, and stop any test container cleanly. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
