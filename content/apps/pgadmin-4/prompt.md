# pgAdmin 4 setup prompt

Set up pgAdmin 4 from its verified official source (https://github.com/pgadmin-org/pgadmin4). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the official desktop package, trusted package repository, or documented container image according to the intended single-user or server mode.

Preserve pgAdmin configuration databases, registered servers, master-password state, query history, storage directories, certificates, and container volumes. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: deployment_mode, storage_directory, listen_address, listen_port, default_server_group. The only available credential references are secret://pgadmin/master-password. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not register or connect to databases, save passwords, reset the master password, run queries, or expose server mode without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch the desktop application or a loopback-only fresh container, confirm the version and login surface, and stop before registering any PostgreSQL server. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
