# Tailscale setup prompt

Codex, first inspect the OS, architecture, shell, existing Tailscale client, daemon or system extension, network interfaces, current login state, advertised routes, DNS settings, and exit-node configuration. Use Tailscale’s official package or signed application: Homebrew Cask or official macOS app, the official Linux repository and `tailscale` package, and the official Windows installer or `winget` package. Ask before administrator access, installing network extensions, enabling or restarting the daemon, changing routes, DNS, firewall rules, opening a browser, logging in, advertising subnets, or selecting an exit node. Preserve current preferences, node identity, keys, routes, and service state. Configure only `hostname`, `accept_dns`, `advertise_routes`, and `exit_node` when supplied. Use `secret://provider/TS_AUTHKEY` through a non-printing `tailscale up` authentication path; never print, echo, log, or persist it in shell history. Do not authenticate through a browser without approval. Verify client and daemon versions, `tailscale status`, interface state, DNS behavior, and connectivity to an approved peer only. Rollback restores previous preferences, disables routes or exit-node changes made here, and uninstalls only the new client package. Finish with a structured summary of installation, authentication method, hostname, routes, DNS, exit node, verification, approvals, and rollback.
