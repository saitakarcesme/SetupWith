# Hulu setup prompt

Set up Hulu from its verified official source (https://www.hulu.com/). Supported targets: Web. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Open the official hulu.com service and accept any current Disney-managed redirect only when its destination remains an official Hulu or Disney property, then offer browser app installation without unofficial wrappers or media downloaders.

Preserve existing Hulu and Disney account cookies, profiles, My Stuff, watch history, home-location registration, Live TV settings, parental controls, subtitles, playback preferences, subscription add-ons, and browser DRM storage. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: playback_quality, subtitle_preferences, profile_controls, location_services. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Stop before sign-in, MFA, profile PIN, home-location update, free trial, subscription change, add-on, Live TV activation, playback, or download; never evade advertisements, DRM, household, geographic, or stream-count restrictions. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm every redirect and installed scope belongs to Hulu or Disney, stop at a signed-out landing page, inspect browser permissions, and verify no account, home-location, subscription, playback, Live TV, or download state changed. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
