# KiCad setup prompt

Set up KiCad from its verified official source (https://www.kicad.org/download/). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Choose a stable KiCad release from the project's platform download page, preserve the installed major version when project compatibility matters, and disclose the application and official symbol, footprint, and 3D-model library sizes separately. Avoid nightly builds and third-party repositories by default.

Preserve KiCad projects, schematics, PCB layouts, local and global symbol and footprint tables, custom libraries, 3D models, design rules, templates, hotkeys, color themes, environment variables, autosaves, rescue files, plot presets, and prior major versions. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: major_version, project_directory, global_library_table, third_party_content. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not open or migrate a project, remap legacy libraries, rescue symbols, update footprints from a library, install third-party content, alter global tables, run action plug-ins or scripts, connect to a fabrication service, overwrite Gerbers, or remove an older major version without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `kicad-cli version`, open the manager with no project, and verify official library availability, environment paths, and global table syntax without modifying them. If approved, create a disposable empty project only; rollback preserves all boards, schematics, custom libraries, tables, autosaves, and older releases. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
