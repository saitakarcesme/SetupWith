# Wireshark setup prompt

Set up Wireshark from its verified official source (https://www.wireshark.org/download.html). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download the stable Wireshark package from the Wireshark Foundation, verify its signature or published hashes, and present optional Npcap, USBPcap, and ChmodBPF components separately.

Preserve Preserve capture files, profiles, display filters, coloring rules, protocol preferences, decryption key settings, extcap tools, recent files, and any existing Npcap configuration.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: capture_interfaces, capture_permissions, profile_directory, name_resolution. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Require explicit approval for packet-capture privileges, Npcap or USBPcap drivers, ChmodBPF, raw-interface access, promiscuous mode, name resolution, firewall changes, and any restart. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Open Wireshark without starting a capture, report its version and capture-library status, list visible interfaces read-only, and verify no driver, capture session, or privileged helper is active. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
