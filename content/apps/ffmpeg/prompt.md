# FFmpeg setup prompt

Codex, begin by detecting the OS, architecture, shell, existing `ffmpeg`, `ffprobe`, and `ffplay` binaries, package ownership, enabled codecs, hardware acceleration APIs, and PATH precedence. On macOS prefer Homebrew `ffmpeg`; on Debian or Ubuntu use `apt install ffmpeg`; on Fedora-family systems use the appropriate trusted repository package; on Windows prefer `winget install Gyan.FFmpeg` or an official trusted build source. Ask before administrator access, adding repositories, replacing another build, modifying PATH, or installing patent-encumbered codec packages. Preserve existing scripts, aliases, presets, and binaries. Configure only `hardware_acceleration`, `default_video_codec`, `default_audio_codec`, and `output_directory` when supplied. Validate requested codecs with `ffmpeg -encoders` and hardware support with `ffmpeg -hwaccels`; do not claim unavailable acceleration. Avoid creating global aliases that hide explicit codec choices unless approved. Verify with `ffmpeg -version`, `ffprobe -version`, codec listings, and generation plus transcoding of a short synthetic test pattern and sine wave into the selected output directory. Rollback restores PATH and shell backups and removes only the package installed here. Finish with a structured summary of build source, enabled codecs, acceleration, output path, test results, approvals, and rollback.
