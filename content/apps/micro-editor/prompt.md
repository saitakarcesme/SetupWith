# Micro setup prompt

Set up Micro from its verified official source (https://github.com/zyedidia/micro). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the official release archive or a trusted native package and place the executable in a user-owned path unless a system-wide installation is explicitly approved.

Preserve Micro's configuration, bindings, plug-ins, buffers, and any existing executable earlier on `PATH`. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: preferred_shell, editor_theme, tab_width, clipboard_integration. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not install plug-ins, enable clipboard helpers, or change `$EDITOR` and file associations without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `micro --version`, inspect configuration resolution, and edit a disposable text file to confirm launch and save behavior without touching user documents. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
