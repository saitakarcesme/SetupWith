# Parsec setup prompt

Set up Parsec from its verified official source (https://parsec.app/downloads). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download Parsec for the detected platform and verify host-versus-client support before installation: Windows and supported macOS systems can host, while Linux is client-only. Keep VUSB, virtual display, audio capture, and other optional driver components deselected unless the requested workflow requires them.

Preserve the existing Parsec configuration, approved computers and friends, team membership, host name, decoder and encoder choices, bandwidth limits, virtual-display arrangement, service state, and any Parsec VUSB or audio-capture driver. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: hosting_enabled, decoder, bandwidth_limit, virtual_display. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Hand control back before required Parsec account creation, sign-in, email verification, MFA, team enrollment, enabling hosting, exposing a computer to the account, installing VUSB, virtual display, or audio drivers, granting capture permissions, or joining any remote session. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the Parsec publisher and version plus supported decoding and hosting capability, then stop at the signed-out screen. Inspect services and optional drivers, verify no computer was advertised and no virtual display was created, and include driver-aware rollback with a restart checkpoint if required. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
