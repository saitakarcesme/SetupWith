# Xbox app setup prompt

Set up Xbox app from its verified official source (https://apps.microsoft.com/detail/9MV0B5HZVK9Z). Supported targets: Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Open the verified Microsoft Store listing and install only the Xbox app and mandatory Microsoft gaming services after showing the user exactly what will be added.

Preserve existing Xbox game folders, Gaming Services state, offline permissions, captures, and download settings. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: game_install_drive, download_limit, offline_permissions, launch_on_startup. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Stop before Microsoft sign-in, MFA or CAPTCHA, age verification, Game Pass subscription, purchases, or payment. Gaming Services, anti-cheat or kernel drivers, firewall/autostart changes, reboots, and large game downloads require explicit approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the Store reports the Xbox app installed, open it to the signed-out state, and verify that no game or optional service download remains queued. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
