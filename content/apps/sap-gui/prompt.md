# SAP GUI setup prompt

Set up SAP GUI from its verified official source (https://support.sap.com/en/my-support/software-downloads.html). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Obtain the licensed SAP GUI for Windows or SAP GUI for Java package through the organization's authorized SAP download channel, verify SAP's signature, and match client version and patches to the approved landscape standard.

Preserve existing SAP Logon landscape files, SAPUILandscape XML, saplogon INI data, SAProuter strings, SNC and SSO configuration, certificates, themes, accessibility settings, local history, traces, patches, and enterprise deployment policy. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: sap_gui_variant, system_landscape, saprouter, gui_theme. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not use another person's S-user, import an unreviewed landscape, access production systems, enter SAP credentials, install SNC libraries, import certificates, change SAProuter, save passwords, run transactions, or migrate settings without administrator approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm SAP package and patch versions, open SAP Logon with networking disabled or no system selected, validate only approved landscape entries and theme settings, and verify no authentication, production session, transaction, certificate, or landscape mutation occurred. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
