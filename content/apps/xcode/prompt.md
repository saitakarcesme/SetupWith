# Xcode setup prompt

Set up Xcode from its verified official source (https://apps.apple.com/us/app/xcode/id497799835). Supported targets: macOS. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use Apple's Mac App Store listing for the stable Xcode release, confirm macOS compatibility and the large download size, and avoid beta or older developer downloads unless requested.

Preserve Preserve installed Xcode versions, command-line tools selection, DerivedData, archives, simulators, device support, provisioning profiles, signing identities, templates, and source repositories.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: derived_data_location, command_line_tools_version, simulator_runtimes, developer_directory. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Stop before Apple Account sign-in, license acceptance, first-launch component installation, simulator runtime downloads, certificate changes, device pairing, or switching `xcode-select` globally. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `xcodebuild -version` and `xcode-select -p`, open Xcode without a project, and confirm that command-line tools, simulators, signing assets, and developer directory remain unchanged. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
