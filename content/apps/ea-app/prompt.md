# EA app setup prompt

Set up EA app from its verified official source (https://www.ea.com/ea-app). Supported targets: macOS, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use EA's signed platform installer and install only the EA app, leaving game discovery and downloads disabled until reviewed.

Preserve existing EA game libraries, saves, cache, download limits, and application preferences. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: install_location, download_limit, background_updates, launch_on_startup. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Stop before EA sign-in, MFA or CAPTCHA, age checks, EA Play subscriptions, purchases, or game license prompts. EA AntiCheat or any kernel driver, firewall/autostart change, reboot, or large download needs explicit approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Open the signed-out EA app, confirm the build and install directory, and verify that no game or anti-cheat payload is scheduled. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
