# Beekeeper Studio setup prompt

Set up Beekeeper Studio from its verified official source (https://github.com/beekeeper-studio/beekeeper-studio). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the official stable Community Edition package for the platform and avoid replacing another edition or enabling automatic migration without review.

Preserve saved connections, encrypted credentials, query tabs, workspace files, application settings, SSH tunnels, and certificates. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: connection_favorites, read_only_mode, query_directory, ssl_mode. The only available credential references are secret://database/url. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not connect to a database, import URLs, save credentials, open SSH tunnels, or execute SQL without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch Beekeeper Studio to an empty connection screen, confirm the version and settings location, and make no outbound database or update connection. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
