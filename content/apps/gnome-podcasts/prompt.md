# Podcasts setup prompt

Set up Podcasts from its official GNOME project and verified Flathub listing (https://apps.gnome.org/Podcasts/). Inventory Linux architecture, Flatpak scopes, existing package and data paths, subscription and episode counts, downloaded/partial byte totals, update schedule, playback queue, output route, OPML policy and private-feed credential-reference presence without listing shows, URLs, episode titles, listening history or secrets. Install stable `org.gnome.Podcasts` from verified Flathub in the existing ownership scope. Do not compile from source, launch Podcasts, fetch a feed, import OPML, add a subscription, download or decode media, change progress or play audio during setup.

Preserve subscriptions, feed URLs, categories, episodes, enclosure metadata, chapter marks, artwork, downloads, queue, playback position and speed, played state, history, credentials and preferences. Subscription and listening history can reveal political, religious, health and personal interests; redact them from diagnostics, MPRIS and locked-screen notifications. Private feed URLs may embed durable credentials, so never print them, place them in OPML without protection or send them through URL-preview services.

Treat OPML and feed XML as untrusted structured input. Before import or fetch show provenance, checksum or exact HTTPS origin, redirects, encoding, entry counts, duplicate policy, credential handling, XML/entity and size limits. Preview subscription additions using redacted identifiers. Enclosure URLs, artwork and chapter metadata can redirect or track clients; validate schemes/final hosts and do not render, decode or follow links during verification. iTunes and SoundCloud links may resolve through third-party services and must be reviewed separately from direct RSS/Atom.

Automatic updates and downloads can create sustained traffic and fill storage. Require an interval, conditional-request/backoff behavior, metered/battery policy, download root, quota, partial-file cleanup and retention rules before enabling. Treat media as untrusted decoder input and never install codecs automatically. Confirm output device and gradual volume before playback. Verify provenance, app ID, origin, commit, runtime, executable, files and permissions offline. Prove no network request, feed parse, OPML operation, download, decoder, progress change, MPRIS state, notification, audio or filesystem state changed. On failure, rollback only the new Podcasts ref in its original scope; preserve runtimes, remotes, overrides, subscriptions, media, progress and credentials.
