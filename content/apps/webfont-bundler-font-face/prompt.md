# Webfont Bundler setup prompt

Set up Webfont Bundler from its official project and verified Flathub listing (https://apps.gnome.org/WebfontKitGenerator/). Inventory Linux architecture, Flatpak scopes, existing package and data paths, saved output preferences, recent-state and partial-output bytes, portal grants, network policy and backup coverage without opening fonts or revealing proprietary family names, filenames, foundries, license contents, project paths, glyph inventories, checksums or generated CSS. Install stable `com.rafaelmardojai.WebfontKitGenerator` from verified Flathub in the existing ownership scope. Do not compile from source, launch the app, select or parse a font, contact Google Fonts, download a family, subset glyphs, convert OTF or TTF, generate CSS, create an output directory, or overwrite files during setup.

Preserve every source font byte, owner, permission and license file, plus existing WOFF/WOFF2 kits, CSS, manifests, output preferences, portal grants, remotes, overrides and scope ownership. Possessing a font does not grant web embedding, modification, conversion or redistribution rights. Require a retained license artifact and explicit project scope before any conversion. Never upload proprietary fonts for analysis, remove copyright or trademark metadata without legal review, or imply that Google Fonts origin eliminates attribution and license obligations.

Before a later build, require a manifest containing source checksum and version, foundry, license, embedding and modification permissions, target family, weight, style, stretch and variable-axis mappings. Define the required languages, scripts, Unicode ranges, combining marks, shaping rules, ligatures and fallback stack; validate missing glyphs against a reviewed corpus. Treat font files as untrusted binary parser input with table, glyph, recursion, memory and time limits. For Google Fonts, pin exact official endpoints, redirects, version metadata, checksums and accompanying licenses. Generate WOFF and WOFF2 plus CSS deterministically, preserve necessary variation and color tables, and map each face without synthetic style ambiguity.

Preview output names, CSS URLs, `font-display`, preload and CORS implications, collision policy and license placement. Never overwrite sources or an existing kit silently. Verify provenance, app ID, origin, commit, runtime, executable, files and sandbox permissions offline. Prove no font open, parser, network request, download, subset, conversion, CSS generation, temporary file, output collision or state mutation occurred. On failure, rollback only the new Webfont Bundler ref in its original scope; preserve shared runtimes, remotes, overrides, source fonts, licenses, existing kits, CSS, manifests, portal grants and backups.
