# Sudoku setup prompt

Set up Sudoku from its official project and verified Flathub listing (https://apps.gnome.org/Sudoku/). Inventory Linux architecture, Flatpak scopes, existing package and data paths, save-slot count, current-game presence, aggregate filled-cell and pencil-note counts, selected difficulty, elapsed-time presence, assist settings, statistics count, sandbox overrides and backup coverage without revealing the puzzle grid, solution, individual entries, notes, generator seeds, completion times or player history. Install stable `io.github.sepehr_rs.Sudoku` from verified Flathub in the existing ownership scope. Do not compile from source, launch Sudoku, load a save, generate or start a puzzle, reveal a solution, enter or erase a digit, change notes, request a hint, advance a timer, update statistics, play sound or show a notification during setup.

Preserve every given, user entry, pencil note, selection, undo and redo state, difficulty, elapsed time, pause state, save identity, assist preference, statistics, remotes, overrides and scope ownership. Installation must not treat a conflict as corruption, remove notes because of a newly interpreted entry, complete an unfinished grid, regenerate a puzzle from an unstable seed or overwrite an active game with a fresh board. Redact boards, seeds and completion history from diagnostics.

Before later play, document the difficulty definition, generator and version, whether the puzzle has exactly one solution, seed reproducibility and symmetry policy. Conflict highlighting only identifies rule violations; it does not prove an unconflicted partial grid leads to a unique solution. Define whether valid-input displays, automatic pencil-note removal, hints and solution reveal are enabled, and keep assist changes explicit. Test generation and completion only with a disposable synthetic puzzle excluded from real saves and statistics. Require confirmation before new game, reset or save replacement, with a recoverable snapshot.

Review keyboard and keypad mappings, input-method behavior, focus order, zoom, touch targets, screen-reader labels, high contrast and non-color conflict cues. Specify timer behavior across pause, suspend and resume so clock changes do not falsify elapsed time. Verify provenance, app ID, origin, commit, runtime, executable, files and static sandbox permissions offline; flag unexpected network, telemetry, broad filesystem or portal access without exercising it. Prove no save read, puzzle generation, grid or note mutation, hint, timer change, statistic, audio, notification, portal or network request occurred. On failure, rollback only the new Sudoku ref in its original scope; preserve shared runtimes, remotes, overrides, games, notes, timers, assists, statistics and backups.
