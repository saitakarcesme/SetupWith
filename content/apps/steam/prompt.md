# Steam setup prompt

Set up Steam from its verified official source (https://store.steampowered.com/about/). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download only the signed Steam client from Valve for the detected OS; report installer and expected client size before running it, and do not download any game yet.

Preserve existing Steam library folders, userdata, screenshots, controller layouts, Workshop content, and bandwidth settings. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: library_location, download_region, bandwidth_limit, launch_on_startup. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Stop before account sign-in, MFA or CAPTCHA, age verification, purchases or subscriptions. Never install a game, anti-cheat or kernel driver, firewall rule, autostart item, or reboot without explicit approval; disclose every large download first. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch the client to the signed-out welcome screen, confirm its version and library path, then close it without signing in or starting content downloads. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
