# CLion setup prompt

Set up CLion from its verified official source (https://www.jetbrains.com/clion/download/). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Obtain CLion from JetBrains' official download page or approved Toolbox installation, choose the stable build for the detected architecture, and avoid bundling a new compiler toolchain.

Preserve Preserve CLion profiles, plugins, trusted projects, CMake presets, remote hosts, debugger settings, compiler toolchains, local history, licenses, and custom JVM options.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: cpp_toolchain, cmake_profile, project_directory, debugger_backend. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not activate a subscription trial, import IDE settings, install compilers or debuggers, open a source tree, configure remote access, or install plugins until separately approved. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Start CLion at its welcome screen, report the build and bundled runtime, inspect detected toolchains without changing them, and confirm that no project configuration was generated. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
