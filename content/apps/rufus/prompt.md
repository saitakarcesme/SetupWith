# Rufus setup prompt

Codex, first inspect the Windows version, architecture, shell, existing Rufus executable, package ownership, connected removable drives, current drive letters, and any saved Rufus settings. Rufus is Windows-only; do not attempt installation on macOS or Linux. Prefer the official signed Rufus executable from `rufus.ie` or the supported `winget install Rufus.Rufus` package. Ask before administrator access, downloading an image, changing update settings, writing to any USB device, modifying partitions, assigning drive letters, or overwriting files. Preserve the existing executable, configuration, logs, and all connected media. Configure only `default_device`, `partition_scheme`, `filesystem`, and `image_path` when supplied. Treat `default_device` as a selection preference only; never start a write operation without separately displaying the device model, capacity, current partitions, image path, partition scheme, and filesystem and receiving explicit approval. Verify the digital signature, executable version, image readability and checksum when available, and compatibility of the selected image and target settings. Do not perform a destructive test write. Rollback removes only the installed executable or package and restores preferences; no disk changes should occur without approval. Finish with a structured summary of support status, installer source, detected devices, selected settings, image validation, pending destructive approval, verification, and rollback.
