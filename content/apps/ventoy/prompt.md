# Ventoy setup prompt

Set up Ventoy from its verified official source (https://github.com/ventoy/Ventoy). Supported targets: Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download the official Ventoy release, verify its checksum where published, and unpack it to a user-owned directory; installing the utility is separate from writing Ventoy to a device.

Preserve all removable-drive contents, partition tables, boot records, Ventoy configuration, ISO images, and any previous Ventoy installation. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: target_device, partition_style, secure_boot_support, image_directory. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not select, unmount, repartition, format, update, or write any disk and do not enable Secure Boot options without explicit device-by-device approval and a backup. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the Ventoy tool version and list no raw device details beyond what the user approves; stop before any install or update action. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
