# Audacious setup prompt

Set up Audacious from its official stable download page (https://audacious-media-player.org/download). Detect Linux or Windows, architecture, package managers, existing Qt, GTK, Winamp-style, portable or source installation, core and `audacious-plugins` versions, configuration, playlists, skins, presets, audio servers and output devices, codecs, LADSPA paths, network settings, scrobbling accounts and desktop integration. Install the current stable official binary or distribution package. Keep the core and plugin bundle at exactly the same release; do not select a testing release, compile alternate frontends, enable restricted codec repositories, or replace an installation owned by another package manager.

Install without starting playback, scanning a music folder, importing a playlist, opening a URL, taking file associations or changing the default player. Preserve every playlist, queue, playback position, history, equalizer preset, skin, hotkey, plugin setting, proxy, stream favorite, tag, cover image, lyrics cache, scrobbling token, output selection, volume and balance value. Do not probe private media files or submit filenames and tags to a remote service merely to validate codec support.

Output plugins can open PipeWire, PulseAudio, ALSA, JACK, OSS or Windows audio devices and may change mixer or connection state. FileWriter and stream-recording features write decoded media to disk and can overwrite outputs. Do not play even a sample, seize a device, connect JACK ports, alter server volume, enable recording, select FileWriter, transcode, or export playlists during setup. Treat third-party native and LADSPA plugins as executable code; install no extra input, output, effect, visualization, transport or general plugin. Keep network streams, lyric lookup, radio directories and automatic cover retrieval offline.

Never authenticate a scrobbler, submit listening history, embed credentials in proxy URLs, ignore TLS errors, edit file tags, or enable global hotkeys, MPRIS, tray startup and song-change commands without approval. Verify publisher or package provenance, checksum when available, `audacious --version`, resolved executable, method, matching plugin package, plugin search paths and file-association baseline without launching a persistent player. Confirm no process, audio connection, media access, tag, playlist, output, cache, account, network request, hotkey or association changed. Roll back only the installed core, matching setup-owned plugins and shortcuts.
