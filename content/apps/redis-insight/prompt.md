# Redis Insight setup prompt

Set up Redis Insight from its verified official source (https://redis.io/docs/latest/operate/redisinsight/install/). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Follow Redis's official Redis Insight desktop installation route for the detected platform, validate the package origin, and avoid Docker, Kubernetes, or cloud deployment alternatives unless requested.

Preserve Preserve existing Redis database definitions, encrypted connection details, TLS certificates, workbench history, browser preferences, profiler settings, and any locally saved scripts.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: connection_storage, telemetry, browser_limit, tls_validation. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not add a Redis endpoint, import cloud databases, store credentials, relax TLS checks, run commands, delete keys, start profiling, or enable telemetry without explicit approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Open Redis Insight without connecting to a database, report the version and configuration path, and verify that no endpoint was contacted, command executed, or browser state altered. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
