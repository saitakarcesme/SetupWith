# Oh My Zsh setup prompt

Set up Oh My Zsh from its verified official source (https://github.com/ohmyzsh/ohmyzsh). Supported targets: macOS, Linux. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Confirm Zsh works first, inspect the official installer before execution, and prefer a documented unattended path that does not launch a new shell or replace files implicitly.

Preserve `.zshrc`, `.zprofile`, custom themes and plug-ins, shell history, completion caches, and any existing Oh My Zsh directory. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: shell_theme, shell_plugins, config_directory, default_shell. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not pipe a remote script directly to a shell, run `chsh`, enable plug-ins, or replace dotfiles without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Start a non-login Zsh with the backed-up configuration disabled, confirm `$ZSH` and framework version state, then report any plug-in or theme errors without auto-fixing them. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
