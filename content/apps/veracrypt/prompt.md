# VeraCrypt setup prompt

Set up VeraCrypt from its verified official source (https://github.com/veracrypt/VeraCrypt). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download the signed official VeraCrypt release for the detected platform and verify its signature or checksum before requesting any privileged driver or kernel integration.

Preserve encrypted containers, headers and header backups, keyfiles, mount favorites, preferences, rescue media, and any existing VeraCrypt drivers. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: volume_directory, encryption_algorithm, filesystem, mount_preference. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not create, mount, decrypt, format, resize, repair, or benchmark volumes and never request passwords or keyfile contents during installation. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the installed application and CLI versions and signature status; launch the UI without mounting devices or enumerating private volume locations. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
