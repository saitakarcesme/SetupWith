# Apple Music setup prompt

Set up Apple Music from its verified official source (https://support.apple.com/guide/music-windows/welcome/windows). Supported targets: macOS, Windows, Web. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the built-in Music app on supported macOS versions, the official Microsoft Store app on Windows, or music.apple.com on the web.

Preserve existing local Music library, media folder, playlists, ratings, downloads, and sync preferences. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: audio_quality, lossless_audio, download_location, library_sync. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Stop before Apple Account sign-in, MFA or CAPTCHA, age/region verification, subscription trials, purchases, payment, library sync, or device authorization. Ask before DRM permissions, autostart, reboot, or large lossless downloads. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Open the app or web client signed out, confirm the installed version or web support, and leave library sync and downloads disabled. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
