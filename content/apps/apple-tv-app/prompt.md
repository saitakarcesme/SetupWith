# Apple TV setup prompt

Set up Apple TV from its verified official source (https://support.apple.com/guide/tvapp-windows/welcome/windows). Supported targets: macOS, Windows, Web. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the built-in TV app on macOS, Apple's official Windows Store app, or tv.apple.com, without starting a subscription or rental.

Preserve existing local media, library database, downloads, playback history, subtitles, and device authorizations. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: playback_quality, download_quality, subtitle_preferences, media_location. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Stop before Apple Account sign-in, MFA or CAPTCHA, age/region checks, subscriptions, rentals, purchases, payment, or DRM authorization. Ask before notifications, autostart, reboot, or large offline downloads. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Open to the signed-out storefront, confirm app version or browser compatibility, and do not start protected playback or media downloads. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
