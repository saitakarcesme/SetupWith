# Immich setup prompt

Codex, inspect the OS, architecture, shell, Docker and Compose availability, existing Immich deployment, upload library, PostgreSQL data, machine-learning cache, environment files, backups, and occupied ports. Prefer Immich’s official Docker Compose release files and documented upgrade procedure. Ask before administrator access, installing or starting Docker, creating services, running database migrations, binding ports, changing firewall rules, opening a browser, scanning photo libraries, or overwriting environment files. Preserve originals, thumbnails, metadata, albums, database volumes, user accounts, and backups. Configure only `upload_location`, `server_port`, `timezone`, and `machine_learning_enabled` when supplied. Inject `secret://provider/DB_PASSWORD` through a protected environment or secret file with restrictive permissions; never print, echo, log, or commit it. Validate upload-path ownership and free space before startup. Do not import or scan user media during verification. Verify official image sources, container health, database migration completion, storage permissions, machine-learning service state when enabled, API readiness, and login-page availability. Rollback restores compose and environment backups, removes only newly created containers, and retains all photos and database volumes unless deletion is explicitly authorized. Finish with a structured summary of release source, storage, database, ML state, port, timezone, verification, approvals, and rollback.
