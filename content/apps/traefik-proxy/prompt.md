# Traefik Proxy setup prompt

Set up Traefik Proxy from its verified official source (https://github.com/traefik/traefik). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the official Traefik binary, container, or Helm chart for the intended environment, pinning a stable major version and separating static from dynamic configuration.

Preserve Traefik configuration, certificates and ACME storage, middleware, provider credentials, ingress resources, logs, and container volumes. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: deployment_mode, config_path, listen_address, http_port, https_port. The only available credential references are secret://dns/provider-api-token. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not bind privileged ports, expose the dashboard, request certificates, connect providers, change ingress, or start a persistent proxy without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run the version and configuration validation; only with a minimal loopback configuration start Traefik, query its local ping endpoint, and stop it without contacting providers. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
