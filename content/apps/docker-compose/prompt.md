# Docker Compose setup prompt

Set up Docker Compose from its verified official source (https://github.com/docker/compose). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Prefer the current Docker CLI Compose plug-in from Docker's official channel, detect and report any legacy `docker-compose` v1 binary, and avoid keeping conflicting executable paths.

Preserve Compose files, override files, `.env` files, project names, running containers, networks, volumes, contexts, and registry authentication. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: docker_context, compose_project_directory, compose_profiles, resource_limits. The only available credential references are secret://container/registry-token. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not pull images, interpolate or reveal secrets, run `up` or `down`, delete volumes, or change Docker contexts without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `docker compose version` and validate only an explicitly selected Compose file with `docker compose config --quiet`, redacting all environment-derived values. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
