# Mullvad VPN setup prompt

Set up Mullvad VPN from its verified official source (https://mullvad.net/en/download/vpn). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use Mullvad's signed installer or documented operating-system repository, verify its signing identity, and describe every WireGuard, Wintun, TUN, system service, firewall, and DNS component before the privileged installation begins.

Preserve current Mullvad account state, tunnel settings, custom DNS, split-tunnel exclusions, lockdown policy, local network sharing preference, firewall rules, and all profiles belonging to other VPN clients. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: tunnel_protocol, lockdown_mode, split_tunneling, dns_content_blockers. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Treat the Mullvad account number as a credential and leave its entry to the user; do not enable lockdown mode, DAITA, multihop, custom DNS, LAN blocking, startup connection, or tunnel activation without explicit approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

After an approved temporary connection, verify the tunnel protocol, Mullvad connection check, DNS resolver, IPv6 behavior, route table, and kill-switch response, then disconnect and confirm the pre-install routes and DNS settings return. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
