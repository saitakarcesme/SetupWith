# Bruno setup prompt

Set up Bruno from its verified official source (https://www.usebruno.com/downloads). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Select Bruno's official desktop installer or supported Linux package for the host architecture, check the published release channel, and avoid installing the separate CLI unless requested.

Preserve Preserve filesystem collections, environments, `.bru` files, request history, preferences, certificates, scripts, secrets files, and any Git working tree containing Bruno definitions.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: collections_directory, proxy_settings, certificate_validation, script_runtime. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not open or modify an existing collection, execute pre-request or post-response scripts, import secrets, change certificate validation, configure proxies, or send traffic without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch Bruno without selecting a collection, report its version and configuration directory, and confirm no collection file changed, script ran, or outbound request was created. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
