# Insomnia setup prompt

Set up Insomnia from its verified official source (https://insomnia.rest/download). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download the signed Insomnia desktop build from Kong's official Insomnia page, select the architecture-specific package, and retain any current installation for data migration review.

Preserve Preserve Scratch Pad and local projects, request history, environments, certificates, plugins, Git repositories, vault settings, account state, and application data directories.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: project_storage, proxy_settings, plugin_policy, certificate_validation. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not sign in, enable cloud or Git synchronization, install plugins, import API definitions, expose environment values, disable TLS verification, or transmit a request without consent. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Open Insomnia to a local empty or existing project list, record the version and storage mode, and confirm no project synchronized, plugin executed, or network request was issued. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
