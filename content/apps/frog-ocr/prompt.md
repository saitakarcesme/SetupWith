# Frog setup prompt

Set up Frog from its official project and verified Flathub listing (https://getfrog.app/). Inventory Linux architecture, desktop portal implementation, Flatpak scopes, existing Frog package and preferences, OCR languages and model files, telemetry opt-out state, clipboard behavior, QR link handling, sharing settings, command-line shortcuts and any prior temporary-data location. Install stable `com.github.tenderowl.frog` from the verified Flathub origin in the existing ownership scope. Do not install the Snap, a source build or a delayed CI artifact, and do not launch Frog or request a screen-capture session during setup.

Preserve all language choices, models, preferences, telemetry state, QR behavior, shortcuts and temporary-file policy. Screen regions and pasted images can contain passwords, messages, financial records, health data, private video frames or unreleased work. Do not capture a test region, open or drop an image, inspect clipboard contents, invoke the extract-to-clipboard command, retain OCR output or include recognized text in diagnostics. Verify temporary paths and model inventories only by names and hashes, never by rendering private inputs.

A QR payload is untrusted data and may encode credentials, payment requests, Wi-Fi secrets, custom URI schemes or phishing URLs. Decode only after the source image is approved; never automatically follow a decoded link, resolve a hostname, invoke a handler or copy a secret payload. Before any future share action show the exact extracted text, target application or service, endpoint, account context and redactions. Sharing to email, social networks, Pocket, Instapaper or Telegram is separate from local OCR and must never be inferred from extraction consent.

Language packs and anonymous usage reporting can create network requests. Do not download models, enable telemetry, test an endpoint or change an existing opt-out choice. Treat text-to-speech as unavailable unless current metadata proves an offline path; do not send OCR text to speech services or open audio output. Verify Frog provenance, app ID, origin, installed commit, runtime, executable, files and declared permissions through Flatpak metadata offline. Prove no portal session, screenshot, clipboard value, model, OCR output, QR handler, telemetry setting, temporary file, process, audio device or network request changed. On failure, rollback only the new Frog ref in its original scope; retain shared runtimes, remotes, overrides, models and user data.
