# Mahjongg setup prompt

Set up Mahjongg from its official GNOME project and verified Flathub listing (https://apps.gnome.org/Mahjongg/). Inventory Linux architecture, Flatpak scopes, existing package and data paths, presence of an unfinished game, selected layout, statistics count, input methods, tile-theme preference and accessibility needs without reading board positions, elapsed times or personal performance. Install stable `org.gnome.Mahjongg` from verified Flathub in the existing ownership scope. Do not compile from source, launch Mahjongg, start or resume a game, request a hint, move tiles, reset statistics or change theme during setup.

Preserve the current board, tile arrangement, elapsed time, pause state, selected layout, statistics, best times, theme and preferences. Installation must not treat an unfinished game as disposable or migrate its state without a protected backup. Mahjongg here is single-player tile-matching solitaire, not the four-player game and not gambling; never introduce accounts, wagers, online services or competitive ranking. Explain that a tile is selectable only when free on its left or right at the same level and that visually similar tiles may differ.

Before any future game-state action show whether it will resume, restart, shuffle, request a hint or change layout, and identify the exact effect on time, statistics and undoability. A hint carries a substantial time penalty; do not use hints for verification or enable them without the player's intent. Never claim that a board is unsolvable solely because no obvious move was found, and do not reset progress to obtain an easier deal. Preserve randomness or deal identity when testing reproducibility.

Review tile contrast, glyph distinguishability, window scale, keyboard focus, touch targets and screen-reader naming. Accessibility accommodations should not be treated as cheating or silently change recorded times. Encourage breaks for long sessions and avoid performance or cognitive-health claims. Verify Mahjongg provenance, app ID, origin, commit, runtime, executable, layouts, tile assets, files and permissions offline. Prove no game start, timer, board mutation, hint, statistic, sound, notification, network request or filesystem state changed. On failure, rollback only the new Mahjongg ref in its original scope; preserve runtimes, remotes, overrides, saved game and statistics.
