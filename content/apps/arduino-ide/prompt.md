# Arduino IDE setup prompt

Set up Arduino IDE from its verified official source (https://www.arduino.cc/en/software). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download Arduino IDE 2 for the detected OS and architecture from arduino.cc, distinguishing the installer, portable ZIP, AppImage, and legacy IDE channels. Install the editor only; board cores, USB or serial drivers, libraries, Arduino CLI updates, and udev rules are separate actions.

Preserve sketches and sketchbook location, custom hardware packages, board-manager URLs, installed cores and toolchains, user libraries, examples, `arduino-cli.yaml`, editor preferences, serial-monitor settings, programmer choice, cached downloads, and existing USB or udev configuration. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: sketchbook_path, board_core, library_sources, cli_config_path. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Do not install a board core or library, add a package URL, modify udev rules or group membership, install a USB driver, connect to a serial port, reset or flash a board, compile or upload a sketch, open private source, or enable Arduino Cloud sign-in without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm Arduino's signature and IDE build, run `arduino-cli version` only if bundled, and launch with no board or port selected. Verify sketchbook and package paths without scanning private sketches, and ensure no core download, serial connection, driver, udev rule, compilation, or device upload occurred before rollback. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
