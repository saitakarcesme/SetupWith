# Power BI Desktop setup prompt

Set up Power BI Desktop from its verified official source (https://apps.microsoft.com/detail/9ntxr16hnw1t). Supported targets: Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install Microsoft's verified Power BI Desktop Store package, confirm architecture and monthly release channel, and do not add database connectors, on-premises gateway, preview features, custom visuals, Python, or R runtimes during base setup.

Preserve existing PBIX and PBIT files, AutoRecovery data, Power Query cache, custom visuals, data-source settings, privacy levels, connector drivers, tenant policy, gateway configuration, credentials, and current Microsoft Store update state. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: locale, data_load_privacy, auto_recovery, update_channel. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not connect to production data, enter credentials, lower privacy levels, enable native queries, run scripts, install gateways or connectors, publish reports, replace datasets, activate preview features, or upload telemetry without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the Microsoft Store identity and Desktop version, launch to a blank signed-out report, inspect locale and privacy settings, and verify no production connection, gateway, custom visual, workspace publish, or existing report was opened. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
