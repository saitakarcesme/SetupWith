# Scribus setup prompt

Set up Scribus from its official download page and repository (https://www.scribus.net/downloads/). Detect Windows, macOS, or Linux, architecture, package managers, existing stable or development installation, configuration, templates, autosaves, recoveries, color profiles, fonts, dictionaries, scripts, plugins, Ghostscript and external render-frame tools. Install only the current stable signed or distribution package matching the existing ownership model. Do not choose a nightly or development build, replace a package-managed version, add third-party repositories, or install optional production tools automatically.

Install without opening or converting an SLA document. Preserve every publication, linked image and vector, font reference, master page, style, swatch, spot color, ICC profile, script, template, barcode, form action, autosave, recovery file, recent path, preflight preset, printer setting and export profile. Scribus layouts frequently link to external artwork rather than embedding it; never move, relink, collect, downsample or substitute missing assets and fonts during setup. Hash configuration and recovery locations before any functional launch.

Treat Python Scripter files and render-frame configurations for LaTeX, LilyPond, Gnuplot, Graphviz or POV-Ray as arbitrary commands. Do not execute scripts, render frames, install plugins, invoke Ghostscript, follow document JavaScript actions or trust imported templates without source and command review. Font activation, embedding and subsetting require license verification. Never copy a restricted font into an output package, silently substitute typography, install system-wide fonts, or change ICC defaults, rendering intent, CMYK conversion, ink limits, spot colors or separations.

Collect for Output can copy the document, graphics and fonts into a new directory. PDF/PDF-X, EPS, PostScript, image and print outputs can expose document metadata, form actions, hidden layers and linked content or overwrite production files. Before any later output, require preflight results and show exact pages, bleeds, marks, color space, profiles, font treatment, transparency, forms, encryption, metadata, destinations and collisions. Verify publisher or package provenance, checksum when available, version, executable, method, Ghostscript detection and data paths from CLI or package metadata without loading documents. Confirm no asset, font, profile, script, recovery, output, print job or process changed. Roll back only the installed application and setup-owned shortcuts.
