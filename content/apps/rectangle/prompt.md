# Rectangle setup prompt

Set up Rectangle from its verified official source (https://rectangleapp.com/). Supported targets: macOS. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download the notarized Rectangle release from its official site or GitHub project, compare existing window-manager applications and shortcut conflicts, and copy the app without granting Accessibility or login-item permission automatically.

Preserve current Rectangle preferences, custom shortcuts, snap areas, ignored applications, launch-at-login state, macOS Accessibility grants, window sizes, and settings from other window-management utilities. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: window_shortcuts, snap_areas, launch_on_login, restore_window_size. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Accessibility permission allows control of other application windows and must be granted manually; do not disable competing tools, overwrite shortcuts, enable login startup, import configurations, or purchase Rectangle Pro without direct approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the app's notarization and version, test one approved resize shortcut on a disposable Finder window after permission is granted, restore that window, and verify no unrequested shortcut, login item, or competing utility changed. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
