# Blanket setup prompt

Set up Blanket from its official repository and verified Flathub listing (https://apps.gnome.org/Blanket/). Inventory Linux architecture, Flatpak scopes, existing Blanket package and data paths, saved preset count, custom-sound locations, master/per-sound volume policy, audio server, selected output, background autostart, start-paused setting, MPRIS state, suspend inhibition and power-saver behavior without reading filenames or opening audio. Install stable `com.rafaelmardojai.Blanket` from verified Flathub in the existing ownership scope. Do not install an unofficial package, compile from source, launch Blanket, play a tone or request audio access during setup.

Preserve every preset, custom sound, custom name, volume, loop choice, output preference, autostart setting and power policy byte-for-byte. Do not enumerate private audio libraries, follow symlinks, decode custom files, rename sounds, normalize gain or create a demonstration preset. Custom filenames and metadata may reveal locations, people or routines; keep them out of diagnostics. Treat malformed audio and codec metadata as untrusted parser input and do not install codecs merely to make a file playable.

Multiple ambient layers can sum above a safe or unclipped level even when each individual slider seems moderate. Before future playback show selected layers, per-layer and master gain, output device, route, expected duration and a gradual volume plan. Never produce audio unexpectedly, switch to Bluetooth speakers, bypass an existing limiter or present Blanket as medical treatment for insomnia, tinnitus, anxiety or concentration disorders. Bundled white/pink noise is audio content, not a calibrated therapeutic signal.

Background autostart and MPRIS allow playback control outside the visible window. Keep autostart, start-paused and MPRIS exposure unchanged during setup. Suspend inhibition can prevent sleep and drain a battery; leave it disabled unless explicitly reviewed, and preserve power-saver pause behavior. Verify Blanket provenance, app ID, origin, commit, runtime, executable, bundled sounds, files and permissions offline. Prove no audio file read, decoder, stream, device route, preset, MPRIS name, login item, inhibitor, power policy, notification or network request changed. On failure, rollback only the new Blanket ref in its original scope; preserve shared runtimes, remotes, overrides, custom sounds, presets and desktop audio configuration.
