# Share Preview setup prompt

Set up Share Preview from its official project and verified Flathub listing (https://apps.gnome.org/SharePreview/). Inventory Linux architecture, Flatpak scopes, existing package and data paths, saved-source mode, URL-history count, aggregate preview and image-cache bytes, crawler-profile choices, sandbox overrides, network permission presence and backup coverage without revealing URLs, hostnames, page titles, descriptions, canonical links, image paths, private staging names, credentials, tokens or fetched content. Install stable `com.rafaelmardojai.SharePreview` from verified Flathub in the existing ownership scope. Do not compile from source, launch the app, open local HTML, read the clipboard, resolve a hostname, fetch a URL, follow a redirect, download an image, parse metadata, render a card, update history, clear caches or publish anything during setup.

Preserve all source choices, history, preview profiles, cached artifacts, window state, permissions, remotes, overrides and scope ownership. Treat URLs, HTML, metadata and images as untrusted input. Private staging addresses and query credentials are secrets: never persist or print them, and never forward ambient cookies, authorization headers or browser sessions. Installation must not revisit prior URLs or assume a friendly page title, canonical link or preview image proves origin ownership.

Before a later preview fetch, require an exact normalized HTTP or HTTPS URL, Unicode and punycode hostname, expected redirects, ownership and whether the result should be public. Deny loopback, private, link-local, cloud-metadata and local-socket destinations; revalidate every redirect and DNS result to prevent rebinding. Apply response byte, redirect, decompression, parse and time limits. Distinguish server-rendered metadata from JavaScript-generated DOM and document the selected crawler user agent, content negotiation and authentication-free behavior. Resolve Open Graph and card duplicates deterministically while showing the actual source tags.

Validate remote images by final origin, signature, MIME, dimensions, pixel and byte caps; do not execute SVG activity, preserve hidden EXIF or open files automatically. Platform cards are approximations whose truncation, cache and supported tags change; label the profile and never imply that a local preview updated a social network. Verify provenance, app ID, origin, commit, runtime, executable, files and static permissions offline. Prove no file or clipboard read, DNS, HTTP request, redirect, image download, metadata parse, preview render, history or cache mutation occurred. On failure, rollback only the new Share Preview ref in its original scope; preserve shared runtimes, remotes, overrides, source settings, histories, profiles, caches and backups.
