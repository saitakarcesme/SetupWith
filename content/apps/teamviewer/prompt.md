# TeamViewer setup prompt

Set up TeamViewer from its verified official source (https://www.teamviewer.com/en/download.html). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download the full TeamViewer client for the detected desktop OS from TeamViewer, identify whether the user needs run-once or installed mode, and default to attended use. Treat the background service, printer or VPN driver, Host module, and managed deployment package as optional components.

Preserve the existing TeamViewer ID, trusted-device records, allowlists and blocklists, account assignment, custom modules, unattended-access policy, wake-on-LAN settings, management state, service startup choice, and prior license classification. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: access_mode, unattended_access, launch_on_startup, device_alias. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Do not start or accept a remote session, display a session password, assign the device to an account, enable Easy Access or unattended control, create a permanent password, install a driver, grant screen-recording or accessibility permission, or start a persistent service without separate approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Validate the TeamViewer publisher signature and version, inspect the installed module and service state, and launch only to the local ready screen without sharing its ID or password. Confirm no remote peer connected, no account was assigned, and rollback disables only setup-created persistence. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
