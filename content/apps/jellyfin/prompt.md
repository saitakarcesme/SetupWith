# Jellyfin setup prompt

Set up Jellyfin from its verified official source (https://github.com/jellyfin/jellyfin). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use Jellyfin's official package repository, installer, or container for the host, with persistent configuration and cache directories and read-only media mounts by default.

Preserve Jellyfin databases, metadata, artwork, plug-ins, transcode cache, users, watch history, certificates, configuration, and media files. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: deployment_mode, media_directories, data_directory, listen_address, http_port. The only available credential references are secret://jellyfin/admin-password. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not scan media, create users, install plug-ins, enable remote access, expose ports, alter media files, or enable hardware transcoding without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Start a fresh loopback instance with no media mounts, confirm the web setup page and server version, then stop without creating an administrator. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
