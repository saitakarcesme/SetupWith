# asdf setup prompt

Set up asdf from its verified official source (https://github.com/asdf-vm/asdf). Supported targets: macOS, Linux. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install the current stable asdf core through its documented method, first checking its release-specific dependencies and whether another runtime manager already owns the requested tools.

Preserve `.tool-versions`, asdf data and configuration, installed runtimes, shims, shell startup files, and competing version-manager state. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: preferred_shell, runtime_versions, plugin_sources, project_directory. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not add community plug-ins, download runtimes, reshim executables, or modify shell startup files without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `asdf version`, report active configuration and shim paths, and perform no plug-in or runtime installation unless each source and version is approved. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
