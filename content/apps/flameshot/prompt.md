# Flameshot setup prompt

Set up Flameshot from its verified official source (https://github.com/flameshot-org/flameshot). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the official stable Flameshot package or trusted distribution build and identify platform-specific screen-recording or accessibility permissions before requesting them.

Preserve Flameshot configuration, saved screenshots, upload history, keyboard shortcuts, autostart entries, and existing screenshot-tool bindings. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: screenshot_directory, keyboard_shortcut, clipboard_behavior, autostart. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not grant screen-capture permission, capture the screen, upload images, change global shortcuts, enable autostart, or overwrite screenshots without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `flameshot --version` and launch its configuration window only; confirm the application starts without taking or uploading a screenshot. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
