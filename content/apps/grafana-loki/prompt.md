# Grafana Loki setup prompt

Set up Grafana Loki from its verified official source (https://github.com/grafana/loki). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use an official Loki binary or container matching the architecture and select single-binary local mode only for an approved evaluation; production topologies require a separate plan.

Preserve Loki configuration, indexes, chunks, write-ahead logs, rules, object-store data, credentials, and container volumes. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: deployment_mode, data_directory, config_path, listen_address, http_port. The only available credential references are secret://loki/auth-token. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not ingest host logs, connect object storage, compact or delete data, start services, or expose ingestion and query ports without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run the version and configuration verification commands; only with temporary storage start a loopback instance, check `/ready`, and stop it without sending user logs. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
