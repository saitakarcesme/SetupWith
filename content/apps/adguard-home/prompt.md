# AdGuard Home setup prompt

Set up AdGuard Home from its verified official source (https://github.com/AdguardTeam/AdGuardHome). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the signed official release or container for the detected platform, selecting explicit working and configuration directories and checking DNS and web-port conflicts before startup.

Preserve `AdGuardHome.yaml`, filters, rewrites, query logs, users, certificates, DHCP settings, backups, and container volumes. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: data_directory, dns_upstream, listen_address, dns_port, web_port. The only available credential references are secret://adguard/admin-password. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not replace host or router DNS, enable DHCP, bind privileged ports, create an admin user, change firewall rules, or expose the UI without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `AdGuardHome --version` and configuration checks; only with temporary ports start a loopback instance, reach onboarding, and stop without completing it. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
