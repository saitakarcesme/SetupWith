Inventory Linux architecture, Flatpak scopes, existing package and data paths, compatible Stream Deck count by model class, USB-access declaration, profile, page and action counts by action type, custom-asset byte totals, OBS and network credential-reference presence, sandbox overrides and backup coverage without opening devices or revealing serials, key labels, icons, sounds, URLs, scene names, file paths, commands, request bodies, tokens or operator workflows. Do not compile from source, launch Boatswain, claim a USB interface, illuminate a key, change a profile, decode an icon, play sound, control media or OBS, send a network request, open a file, launch an application, modify a score or execute any configured action during setup.

Preserve every device binding, profile, page, key position, action graph, icon, sound, counter, integration setting, USB rule, permission, remote, override and scope ownership. A Stream Deck press can trigger irreversible external behavior; profile imports are executable configuration, not harmless themes. Redact device serials, endpoints, credentials and action payloads. Installation must not attach the first matching USB device, remap active controls, auto-run an action, switch OBS scenes, alter media playback or install broad udev rules.

Before later device use, match vendor ID, product ID, model, key layout and a locally retained serial reference to the intended operator. Preview a complete profile diff and reject actions whose coordinates do not exist on that model. Treat custom icons as untrusted image input and sound effects as controlled audio with reviewed route, duration and low initial volume. Debounce repeated keys, cap action rate and define disconnect and cancellation behavior. Validate only with a synthetic profile and mocked endpoints while the real device remains unclaimed.

For OBS, pin host, protocol, TLS certificate and narrowly scoped credential; identify each scene or source mutation. For network actions, require method, final HTTPS URL, redirect rule, headers, body, timeout, response cap, idempotency and SSRF denial. File and application actions need a canonical target, argument and environment preview with no shell interpolation. Verify provenance, app ID, origin, commit, runtime, executable, files and static permissions offline. Prove no USB claim, display write, profile change, asset decode, audio, MPRIS, OBS, network, file, process or counter mutation occurred. On failure, rollback only the new Boatswain ref in its original scope; preserve shared runtimes, remotes, overrides, devices, profiles, assets, integrations, rules and backups.
