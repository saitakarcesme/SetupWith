# OpenBoard setup prompt

Set up OpenBoard from its official download page (https://openboard.ch/en/download). Detect Windows 10+, macOS 12+, or Debian 12, architecture, package managers, existing OpenBoard or Open-Sankoré installation, document library, profiles, caches, interactive displays, pen tablets, projectors, dual-screen layout, cameras, microphones, media backends, virtual printers and file associations. Install only the current stable official package for the supported platform and architecture. Do not select a development branch, community package for an officially supported platform, or migrate legacy libraries without approval.

Install without starting a lesson, creating a board document, opening the library or changing handlers for UBZ, UBX or PDF files. Preserve every document, page, annotation, embedded resource, background, thumbnail, folder, trash item, favorite, widget, podcast, recording, cache, preference, toolbar, pen setting, calibration and recent item. OpenBoard may maintain its document library rather than asking for a normal Save operation; never assume closing a test document leaves storage untouched. Inventory library paths and hashes before any functional launch.

Printable-file, PDF, UBZ and UBX import can create converted documents and extracted assets; export, duplication, rename, move and deletion can alter the library. Do not import or export real teaching material merely to test installation. Treat web widgets as remote applications: they can run JavaScript, store cookies, follow links, download files and display private or untrusted content. Never add a widget, enable cookie persistence, sign in, capture a web page, trust a certificate, grant browser permissions or expose student data. Desktop mode, region capture and page capture can record other applications, notifications and credentials.

Podcast recording can capture the board, microphone and system media into persistent files. Do not request microphone, camera, screen-recording or accessibility access; do not start a recording or select an output folder. Preserve display arrangement, projector resolution, pen mapping and interactive-whiteboard calibration, and never install hardware drivers or recalibrate a classroom device for verification. Verify publisher or package provenance, checksum when provided, package version, executable, bundle files, supported platform and data locations from package metadata without launching the normal GUI. Confirm no document, cache, handler, cookie, capture, device grant, calibration, media file, process or network connection changed. Roll back only the installed application and setup-owned shortcuts.
