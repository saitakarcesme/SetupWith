# Adobe Lightroom setup prompt

Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install the cloud-oriented Lightroom application through Creative Cloud only after distinguishing it from Lightroom Classic and checking current OS and GPU support. Do not migrate a Classic catalog, import photographs, or enable download of cloud originals during installation.

Preserve all originals and smart previews, Lightroom Classic catalogs if present, cloud-library state, local cache, albums, ratings, flags, edit history, presets, profiles, masks, export settings, camera defaults, and pending uploads or downloads. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: local_storage_location, cache_limit, originals_download, gpu_acceleration. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Stop before Adobe sign-in, subscription or trial activation, importing or scanning a photo folder, migrating a Classic catalog, enabling cloud sync, downloading originals, changing local storage, deleting cloud or local photos, applying metadata, or invoking AI features on private images. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Verify that no catalog migration, photo import, face analysis, original download, or upload began; rollback must retain originals, catalogs, edits, presets, and synchronization databases. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values.
