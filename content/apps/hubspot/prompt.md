# HubSpot setup prompt

Set up HubSpot from its verified official source (https://app.hubspot.com/). Supported targets: Web. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Open app.hubspot.com in a dedicated browser profile after confirming the intended portal or sandbox account, verify HubSpot's certificate, and offer only the browser-managed app flow without marketplace integrations or extensions.

Preserve existing HubSpot sessions, portal selection, sandbox data, contacts, companies, deals, tickets, lists, workflows, marketing assets, reports, connected inboxes, OAuth grants, browser storage, and notification preferences. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: portal_id, sandbox_account, browser_profile, notification_policy. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Stop before sign-in, MFA, portal entry, OAuth consent, production record access, import, export, email connection or send, workflow enrollment, campaign publication, billing, marketplace installation, property change, deletion, or merge. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the official HubSpot origin and intended sandbox or production classification, stop at authentication, inspect installed-app permissions, and verify no portal session, CRM record, email, workflow, import, export, integration, or production data changed. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
