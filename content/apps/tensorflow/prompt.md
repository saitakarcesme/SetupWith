# TensorFlow setup prompt

Set up TensorFlow from its verified official source (https://github.com/tensorflow/tensorflow). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Create an isolated Python environment and select the official stable TensorFlow package compatible with the platform, Python release, CPU instruction set, and supported accelerator path.

Preserve Python environments, lockfiles, Keras configuration, model caches, CUDA libraries, GPU drivers, and existing TensorFlow installations. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: python_version, virtual_environment, compute_backend, model_cache_directory. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not replace system CUDA components, enable unsupported GPU paths, download datasets, or modify global Python without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Import TensorFlow, report its version and physical devices, then execute a tiny constant addition while suppressing no diagnostic errors and using no external data. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
