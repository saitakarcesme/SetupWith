# Graphs setup prompt

Set up Graphs from its official GNOME project and verified Flathub listing (https://apps.gnome.org/Graphs/). Inventory Linux architecture, Flatpak scopes, existing package and data paths, project-file count, approved import roots, stylesheet count, autosave behavior and export destinations without opening datasets, reading labels or exposing scientific results. Install stable `se.sjoerd.Graphs` from verified Flathub in the existing ownership scope. Do not compile from source, launch Graphs, import a file, evaluate an equation, transform or fit data, alter a stylesheet or export a plot during setup.

Preserve source datasets, project files, equations, selections, transformation order and parameters, fit definitions, stylesheets, axes, units, annotations, autosaves and exports byte-for-byte. Never overwrite raw measurements or silently reinterpret delimiter, decimal locale, missing value, uncertainty or unit. Treat CSV, XRDML, project and style files as untrusted structured input; before parsing show provenance, checksum, license, encoding, schema, expected dimensions, parser limits and a protected duplicate destination.

Every select, cut, translate, multiply, centre, smooth or custom transformation changes the evidentiary meaning of data. Record an immutable ledger with input checksum, operation, parameters, affected range, output checksum and reviewer. Equation-generated series require domain, sampling interval, resolution, units, discontinuity and overflow checks. Curve fitting requires an explicit model rationale, initial values, bounds, weighting, residual inspection, uncertainty, convergence status and disclosure of excluded observations; a converged curve is not proof of causality or model validity.

Plots can mislead through truncated axes, inconsistent units, hidden normalization, absent uncertainty, inaccessible colors or smoothing. Review visual encoding and underlying transformed values before publication. Vector exports may retain editable text and metadata; verify fonts, links and destination classification. Verify Graphs provenance, app ID, origin, commit, runtime, executable, files and permissions offline. Prove no dataset read, parser invocation, equation evaluation, transformation, fit, project write, stylesheet, clipboard, export or filesystem state changed. On failure, rollback only the new Graphs ref in its original scope; preserve runtimes, remotes, overrides, data, projects and published artifacts.
