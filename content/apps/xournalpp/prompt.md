# Xournal++ setup prompt

Set up Xournal++ from its official installation page (https://xournalpp.github.io/installation/). Detect Windows, macOS, or Linux, architecture, package managers, existing native, portable, Flatpak or distribution installation, configuration, templates, plugins, autosaves, recent journals, file associations, stylus and touch devices, microphone permissions, LaTeX tools and print system. Install the latest stable signed or repository-verified package matching the existing installation method. Do not choose a mobile beta, nightly build, alternate confinement model, or source build without approval.

Install without opening a journal or PDF and without changing the default application for `.xopp` or PDF files. Preserve every journal, background PDF, annotation, layer, embedded image, audio note, template, autosave, recovered document, plugin, toolbar, color, shortcut, device map, input preference, recent path, print setting and export. Hash configuration and autosave locations before launch. Do not recover, rename, relocate or delete an autosave merely because its parent document appears closed.

A normal `.xopp` journal is stored separately from its PDF background and can contain that PDF's absolute path. Attach mode copies the PDF beside the journal during Save and changes path semantics. Never enable attach mode, replace a missing background, move a journal, copy a private PDF, or rewrite stored paths automatically. Before later Save As or PDF export, show the source journal, background, attachment behavior, destination, page range, layers, flattening, file permissions and collision policy. Do not overwrite the original PDF, print, or export sensitive annotations without approval.

Treat Lua plugins and configured LaTeX commands as executable code. Do not install, enable or update plugins, compile formulas, invoke external tools, access the clipboard, or open links until source, command line, files and network behavior are reviewed. Do not request microphone access or record audio. Preserve tablet pressure curves, eraser behavior, touch rejection and monitor mapping; never recalibrate a production pen display for verification. Verify publisher or package provenance, checksum where available, `xournalpp --version`, executable, method, data paths and plugin baseline without loading user content. Confirm no journal, PDF, autosave, cache, association, device setting, permission, process, plugin, audio file, print job or export changed. Roll back only the installed application and setup-owned shortcuts.
