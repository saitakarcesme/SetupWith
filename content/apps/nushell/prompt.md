# Nushell setup prompt

Set up Nushell from its verified official source (https://github.com/nushell/nushell). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the official Nushell release or trusted package for the platform and avoid mixing package-manager and manually installed binaries on `PATH`.

Preserve Nushell `config.nu` and `env.nu`, history and database files, plug-ins, login-shell settings, and existing environment initialization. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: shell_prompt, config_directory, environment_variables, default_shell. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not register plug-ins, translate shell startup files, import secrets, or change the login shell without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `nu --version` and a clean `nu --no-config-file` command that emits a small table; report configuration paths without evaluating the user's startup scripts. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
