# QGIS setup prompt

Set up QGIS from its verified official source (https://qgis.org/download/). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Choose QGIS's current Long Term Release or latest stable release explicitly and use the official all-in-one macOS or Windows installer, or the documented distribution repository on Linux. Do not mix OSGeo4W and standalone channels or install testing builds, GRASS, SAGA, or extra providers silently.

Preserve QGIS user profiles, projects and layouts, GeoPackage and shapefile data, style databases, processing models, scripts, templates, custom CRS definitions, authentication database, master-password state, plugins, provider settings, database connections, and browser favorites. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: release_channel, user_profile, plugin_policy, default_crs. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not open a project, scan data directories, connect to a database or web service, reveal authentication entries, install or update plugins, change the default CRS, run Processing algorithms, edit vector layers, repair geometries, or migrate a user profile without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `qgis --version` or inspect About, launch with a fresh temporary profile and no project, and verify GDAL, GEOS, PROJ, Python, and Qt versions without accessing user connections. Rollback removes only the new application or repository and preserves profiles, plugins, auth databases, projects, and geodata. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
