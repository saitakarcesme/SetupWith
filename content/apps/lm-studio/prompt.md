# LM Studio setup prompt

Set up LM Studio from its verified official source (https://lmstudio.ai/download). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Select the official LM Studio package for the detected operating system and architecture, verify available RAM, GPU support, and disk space, then install the application without downloading a model.

Preserve Preserve the existing models directory, chats, presets, runtime versions, local-server settings, sideloaded weights, and any custom model search or storage locations.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: models_directory, default_context_length, gpu_offload, local_server_bind_address. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not download model weights, replace runtimes, expose the local API beyond loopback, enable remote access, or accept a model license until size, source, and terms are approved. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch LM Studio offline, confirm its application and bundled runtime versions, inspect the configured models path, and verify that no model, network listener, or background daemon was started. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
