# Directus setup prompt

Set up Directus from its verified official source (https://github.com/directus/directus). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Prefer the official container image or documented Node.js package in a fresh environment, with explicit database, upload, extension, and snapshot storage.

Preserve database schemas and data, uploads, extensions, snapshots, flows, users, cryptographic keys, environment files, and container volumes. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: deployment_mode, data_directory, database_name, listen_address, listen_port. The only available credential references are secret://directus/key, secret://directus/secret, secret://directus/database-password. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not connect or migrate an existing database, generate or replace production keys, create an administrator, expose ports, or install extensions without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

For a fresh temporary database, start Directus on loopback, confirm the server health endpoint and setup page, then stop before creating an administrator. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
