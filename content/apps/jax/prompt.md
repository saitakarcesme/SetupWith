# JAX setup prompt

Set up JAX from its verified official source (https://github.com/jax-ml/jax). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install JAX and the matching `jaxlib` wheel in an isolated environment, following the official CPU, NVIDIA, AMD, or Apple guidance and treating native Windows support conservatively.

Preserve Python environments, dependency locks, XLA caches, CUDA or ROCm libraries, GPU drivers, and existing JAX installations. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: python_version, virtual_environment, compute_backend, xla_memory_fraction. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not replace accelerator drivers, use unofficial wheels, reserve large device memory, or change global Python packages without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Import `jax`, report versions and `jax.devices()`, then run a tiny jitted array calculation without compiling a large workload or downloading data. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
