# GitLab CLI setup prompt

Set up GitLab CLI from its verified official source (https://gitlab.com/gitlab-org/cli#installation). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the GitLab-maintained CLI repository's installation method for the current platform, verify the package source, and avoid replacing another `glab` binary until its origin is known.

Preserve Preserve `glab` configuration, authenticated hosts, Git protocol choice, aliases, editor and browser settings, repository remotes, environment tokens, and shell completion files.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: gitlab_host, git_protocol, editor, browser. The only available credential references are secret://gitlab/token. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not authenticate, paste a token, change Git remotes or protocols, create issues or merge requests, trigger pipelines, alter releases, or write repository files without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `glab version` and unauthenticated help, report the binary and package origin, and confirm that no host credentials, repository metadata, or GitLab resource was read or changed. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
