# Switcheroo setup prompt

Set up Switcheroo from its official project and verified Flathub listing (https://apps.gnome.org/Converter/). Inventory Linux architecture, Flatpak scopes, existing package and data paths, saved conversion preferences, recent input and output counts, aggregate cache and partial-file bytes, accessible portal grants and backup coverage without opening images or revealing filenames, directories, thumbnails, EXIF, GPS, camera identifiers, dimensions, hashes or creative content. Install stable `io.gitlab.adhami3310.Converter` from verified Flathub in the existing ownership scope. Do not compile from source, launch Switcheroo, select files, decode or render an image, follow an SVG reference, inspect metadata, resize, convert, remove EXIF, create output, or overwrite anything during setup.

Preserve every source byte, owner, permission and timestamp where practical, plus existing outputs, metadata choices, naming rules, recent state, portal grants, remotes, overrides and scope ownership. Image metadata can contain precise location, device identity, author and capture time; redact it from diagnostics. Removing all EXIF may also remove orientation needed for correct display, while format conversion can lose ICC profiles, transparency, HDR, animation, frames, comments or bit depth. Never describe a successful decode as proof of visual equivalence.

Before a later conversion, require a manifest with input checksum, detected type, byte and pixel limits, output format, quality or lossless settings, target dimensions, aspect-ratio and enlargement policy, orientation normalization, metadata allowlist or removal rule, color-profile handling, alpha background and animation or multi-frame behavior. Treat raster and vector inputs as hostile decoder content. Deny SVG network access, scripts and external resources; cap decompressed pixels, memory, CPU, concurrency and time. Preview output names and collision decisions, reserve free space, use atomic writes, and never overwrite sources or existing outputs without per-file approval.

Verify provenance, app ID, origin, commit, runtime, executable, files and sandbox permissions offline. Confirm file-portal reach without selecting a document. Prove no file open, decoder, renderer, metadata read, SVG request, encoder, resize, EXIF mutation, temporary file, output collision, source change or notification occurred. On failure, rollback only the new Switcheroo ref in its original scope; preserve shared runtimes, remotes, overrides, sources, outputs, metadata, color profiles, portal grants, preferences and backups.
