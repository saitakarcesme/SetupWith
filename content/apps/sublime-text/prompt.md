# Sublime Text setup prompt

Codex, start by detecting the OS, architecture, login shell, existing Sublime Text installations, package source, executable locations, and current user configuration. On macOS prefer the official signed application or Homebrew Cask `sublime-text`; on Debian/Ubuntu use Sublime HQ’s signed apt repository and package `sublime-text`; on Fedora-family systems use the official RPM repository; on Windows prefer `winget install SublimeHQ.SublimeText.4`. Ask before administrator access, adding repositories, replacing an app bundle, registering file associations, or creating PATH links. Preserve the `Packages/User` directory, installed packages, license state, session data, and existing `Preferences.sublime-settings`. Configure only `editor_theme`, `editor_font_size`, and `preferred_shell` when provided. Merge JSON safely, retain comments where possible, and add terminal integration only if an existing package supports it; do not install Package Control or third-party plugins without approval. For shell access, use the supported `subl` command and ask before creating symlinks. Verify the application binary, `subl --version` where supported, JSON validity, launch of a temporary text file, and persistence of the selected theme and font size. Rollback should restore the backed-up User settings, remove added links, and uninstall only this run’s package. End with a structured summary of installation, files changed, tests, approvals, and rollback commands.
