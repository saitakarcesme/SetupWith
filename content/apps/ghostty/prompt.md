# Ghostty setup prompt

Set up Ghostty from its verified official source (https://ghostty.org/download). Supported targets: macOS, Linux. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use Ghostty's signed and notarized DMG or its official-binary Homebrew cask on macOS; on Linux choose a distribution-maintained package, and reject unreviewed community install scripts or binaries unless the user explicitly accepts their provenance risk.

Preserve all XDG and macOS Ghostty configuration files, imported themes, keybindings, font choices, working-directory behavior, shell startup files, terminfo entries, desktop launchers, and the current default-terminal association. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: theme, font-family, shell-integration, config-file. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not change the default terminal, edit shell startup files, enable SSH wrappers, install remote terminfo, load untrusted themes, replace fonts, add third-party repositories, or build from an unpinned Zig toolchain without separate review and approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the package signature or distribution provenance and Ghostty version, validate the effective configuration with Ghostty's show-config action, launch one local shell, check TERM and resource discovery, reload the config, and prove no startup file, default-terminal setting, or remote host changed. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
