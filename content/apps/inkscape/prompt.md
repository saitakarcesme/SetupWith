# Inkscape setup prompt

Codex, inspect the OS, architecture, shell, existing Inkscape installation, user preferences, extensions, templates, themes, color profiles, and file associations before making changes. Prefer the official signed application on macOS, the distribution package or official Flatpak on Linux, and the official Windows installer or supported `winget` package. Ask before administrator access, installing Flatpak, replacing an application, changing SVG associations, installing extensions, or overwriting preferences and templates. Preserve custom palettes, extensions, symbols, templates, keyboard mappings, and recent-document data. Configure only `default_template`, `theme`, and `extension_directory` when supplied. Confirm that the requested template is a valid SVG and add extension paths without removing existing locations. Do not execute untrusted extension scripts. Verify Inkscape launch, `inkscape --version`, preference parsing, theme persistence, template loading, extension discovery, and command-line export of a disposable SVG to PNG or PDF. Do not open or rewrite user artwork during verification. Rollback restores preference backups, removes only extension paths or templates added here, and uninstalls only the application installed in this run. Finish with a structured summary of package source, profile, template, theme, extension paths, verification, approvals, and rollback.
