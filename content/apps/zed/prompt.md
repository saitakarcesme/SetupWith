# Zed setup prompt

Codex, inspect the OS, architecture, current shell, GPU/display environment, existing Zed installation, application data, and whether the platform is officially supported before proceeding. Install only on supported systems. On macOS prefer the official signed Zed application or Homebrew Cask `zed`; on supported Linux use Zed’s official installation path; do not invent a native Windows installation if unavailable. Ask before administrator access, replacing an app bundle, adding the `zed` CLI to PATH, opening a browser, or enabling account synchronization. Preserve Zed settings, keymaps, extensions, and workspace state. Configure only `editor_theme`, `editor_font_size`, and `preferred_shell` when supplied, merging into the existing settings file without deleting unrelated keys. If AI providers are requested, reference only `secret://provider/ANTHROPIC_API_KEY` or `secret://provider/OPENAI_API_KEY`; never print, echo, log, or hard-code secret values. Ask before writing provider credentials into any application-managed credential store. Verify the installed application launches, the `zed` command resolves when enabled, settings parse correctly, and a temporary folder opens with the requested terminal shell. Avoid account sign-in during verification. Roll back by restoring backed-up settings, removing added CLI links, and uninstalling only the installed channel. Finish with a structured summary of support status, install source, config changes, verification, approvals, and rollback.
