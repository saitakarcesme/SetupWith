# Label Studio setup prompt

Codex, inspect the OS, architecture, shell, Python and container tooling, existing Label Studio deployment, data directory, database, projects, media storage, and occupied ports. Prefer the official Docker image with persistent storage for an isolated deployment; use the official `label-studio` PyPI package in a dedicated virtual environment when containers are unsuitable. Ask before administrator access, installing or starting a container daemon, running database migrations, binding port 8080, changing firewall rules, opening a browser, or replacing data volumes. Preserve project exports, uploaded assets, user accounts, database files, and existing environment configuration. Configure only `server_port`, `data_dir`, and `database_url` when supplied. Reference `secret://provider/SECRET_KEY` and `secret://provider/DATABASE_PASSWORD` only through protected environment injection; never print, echo, log, or commit their values. Bind to localhost unless shared access is approved, and do not create public accounts automatically. Verify the package or image identity, persistent mount, database connectivity, migration status, health page, and creation of a disposable local project without uploading private data. Rollback stops and removes only resources created here, restores configuration, and retains databases and media unless deletion is authorized. End with a structured summary of deployment mode, storage, database, port, checks, approvals, and rollback.
