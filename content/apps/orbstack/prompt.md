# OrbStack setup prompt

Set up OrbStack from its verified official source (https://orbstack.dev/download). Supported targets: macOS. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install OrbStack from its notarized macOS download or the official Homebrew cask, then launch it without migrating Docker Desktop data, replacing command-line tools, changing the active Docker context, or creating a Linux machine.

Preserve existing Docker Desktop and Colima contexts, containers, images, volumes, BuildKit caches, Kubernetes clusters, Linux machines, registry credentials, Compose projects, socket links, PATH ordering, and resource limits. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: memory_mib, cpu, rosetta, docker_context. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Ask separately before updating /var/run/docker.sock, linking tools into /usr/local/bin, switching Docker contexts, stopping another runtime, copying Docker data, enabling Kubernetes or Rosetta, exposing container networks, forwarding SSH agents, or attaching USB devices. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the OrbStack code signature and version, inspect orb status and the available Docker contexts, run an approved disposable hello-world container without publishing ports, remove it, and prove that pre-existing runtimes, contexts, volumes, machines, and socket ownership remain unchanged. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
