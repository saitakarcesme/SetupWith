# SQL Server Management Studio setup prompt

Set up SQL Server Management Studio from its verified official source (https://learn.microsoft.com/en-us/ssms/install/install). Supported targets: Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use Microsoft's current SSMS installer documentation and signed bootstrapper, identify the stable release channel, and disclose the Visual Studio Installer components and disk requirement first.

Preserve Preserve existing SSMS versions, registered servers, connection profiles, templates, snippets, settings, extensions, query history, certificates, execution plans, and installer caches.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: install_location, selected_components, connection_encryption, query_execution_mode. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Require approval for elevation, component selection, extension installation, instance migration, certificate trust, server connection, authentication, query execution, firewall changes, and any restart. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the installed SSMS instance and components in Microsoft Installer, launch without connecting to a server, report the build, and verify that registered servers and settings remain intact. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
