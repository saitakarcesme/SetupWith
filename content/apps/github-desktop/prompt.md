# GitHub Desktop setup prompt

Set up GitHub Desktop from its verified official source (https://github.com/desktop/desktop). Supported targets: macOS, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install the signed official application for macOS or Windows and confirm whether the user wants it alongside an existing Git client.

Preserve Git configuration, credential helpers, SSH keys, known repositories, application preferences, and existing GitHub authentication. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: git_name, git_email, git_protocol, repository_directory. The only available credential references are secret://github/token. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not sign in, clone repositories, change global Git identity, install command-line tools, or alter credential helpers without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch GitHub Desktop signed out or in its current state, report the application and bundled Git versions, and do not open or scan repository directories. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
