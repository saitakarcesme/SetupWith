# Box Drive setup prompt

Set up Box Drive from its verified official source (https://www.box.com/resources/downloads). Supported targets: macOS, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download the current signed Box Drive build from Box's desktop downloads page, distinguish it from the retired Box Sync product and optional Box Tools, and verify OS support before allowing its Finder or File Explorer provider integration.

Preserve the Box Drive cache, offline-file selections, Box Sync migration state, pending uploads, conflicted copies, Finder or Explorer favorites, organization policy, and any content pinned for offline work. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: drive_location, offline_folders, cache_limit, launch_at_login. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Stop before organizational sign-in or SSO, enabling the filesystem provider, migrating Box Sync, choosing folders for offline use, evicting cached files, changing the drive location, opening cloud documents, or enabling launch at login. Do not infer that an online-only item is safely backed up locally. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Check the Box publisher signature and client version, then launch to the sign-in screen without mounting a tenant. Verify that no Box volume, offline download, cache migration, or shell action is active and provide rollback that does not remove cached or pending user files. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
