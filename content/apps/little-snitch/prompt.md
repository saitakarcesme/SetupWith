# Little Snitch setup prompt

Set up Little Snitch from its verified official source (https://www.obdev.at/products/littlesnitch/download.html). Supported targets: macOS. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download the signed Little Snitch disk image from Objective Development, verify its notarization, and explain the Network Extension, privileged helper, content filter, system approval, login item, and possible restart before running its installer.

Preserve all existing Little Snitch rules, rule groups, profiles, DNS-encryption settings, Network Monitor history, license state, backups, macOS network filters, and rules managed by an administrator. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: initial_rule_mode, dns_encryption, rule_group_location, network_monitor_history. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Do not approve the Network Extension, import rules, switch to alert or silent mode, block traffic, enable DNS encryption, subscribe to blocklists, or alter managed policies until the user reviews the connectivity impact. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the notarized application and extension versions, check extension approval and daemon health without creating rules, open Network Monitor with no forced traffic, and prove uninstall guidance preserves exported rules while restoring normal filtering. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
