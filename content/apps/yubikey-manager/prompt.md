# YubiKey Manager setup prompt

Set up YubiKey Manager from its verified official source (https://www.yubico.com/support/download/yubikey-manager/). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install Yubico's signed YubiKey Manager package for the detected platform, add Linux USB permissions only when required and approved, and launch initially without a hardware key connected so no configuration action can occur accidentally.

Preserve every YubiKey slot, FIDO credential, PIV certificate and key, OATH account, OTP secret, PIN, management key, interface setting, touch policy, and existing USB access rule. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: enabled_interfaces, fido2_pin_management, piv_touch_policy, oath_access. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Never reset an application, change a PIN or management key, disable USB or NFC interfaces, overwrite OTP slots, import private keys, generate resident credentials, or attempt unsupported firmware modification without precise user confirmation. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the signed application version, then with permission read only the connected key's model, serial, firmware, and enabled interfaces; perform no write operation and report that every credential and policy remains unchanged. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
