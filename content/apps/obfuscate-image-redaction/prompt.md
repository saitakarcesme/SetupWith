# Obfuscate setup prompt

Set up Obfuscate from its official GNOME project and verified Flathub listing (https://apps.gnome.org/Obfuscate/). Inventory Linux architecture, Flatpak scopes, existing package and data paths, approved image roots, recent-file count, temporary-data location, clipboard policy and organization redaction standard without opening images, listing filenames or examining sensitive regions. Install stable `com.belmoussaoui.Obfuscate` from verified Flathub in the existing ownership scope. Do not compile from source, launch Obfuscate, import an image, grant broader file access, apply censorship, write temporary previews, copy, save or share during setup.

Preserve every original image, timestamp, permission, metadata record and existing edited copy. Installation is not authorization to inspect or censor content. Before future work establish the owner, subject consent, disclosure purpose, audience and exact information categories to remove. Review not only obvious text and faces but reflections, backgrounds, badges, screens, addresses, account identifiers, QR/barcodes and combinations of innocuous details that can re-identify a person. Always edit a protected duplicate and never overwrite the sole original.

A visual effect is not automatically secure redaction. Blur and pixelation can leave recognizable structure, while an editor may retain underlying pixels in undo state, alpha, thumbnails, temporary files or metadata. Use an organization-approved opaque treatment with sufficient edge padding, flatten to a new raster output, strip metadata and embedded thumbnails, and avoid formats or workflows that preserve editable layers. Animated or multipage inputs require every frame or page to be handled by a suitable reviewed tool rather than assuming the visible frame is complete.

Close and reopen only the exported copy, inspect it at several zoom and contrast levels, run approved OCR and barcode checks, verify dimensions/metadata, and require a second reviewer who understands the disclosure boundary. Sharing creates copies that may not be revocable; confirm destination access, retention and final checksum separately. Verify Obfuscate provenance, app ID, origin, commit, runtime, executable, files and permissions offline. Prove no image read, portal grant, temporary file, censor operation, clipboard, export, metadata change, network request or filesystem state changed. On failure, rollback only the new Obfuscate ref in its original scope; preserve runtimes, remotes, overrides, originals and edited files.
