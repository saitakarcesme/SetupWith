# rclone setup prompt

Set up rclone from its verified official source (https://rclone.org/downloads/). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install the signed stable rclone binary or the trusted OS package for the exact architecture, record its provenance, and avoid piping the install script directly into an elevated shell. Do not add FUSE, WinFsp, macFUSE, a mount service, or shell completion as part of the base install.

Preserve every existing `rclone.conf`, crypt remote, OAuth token, service-account reference, filter file, cache directory, scheduled task, mount unit, bandwidth schedule, and local or remote path used by prior copy, sync, bisync, or mount jobs. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: config_path, cache_directory, mount_point, bandwidth_limit. The only available credential references are secret://rclone/config-pass. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Never run `sync`, `move`, `delete`, `purge`, `dedupe`, `cleanup`, or a real transfer during setup. Stop before `rclone config`, browser authorization, resolving secret://rclone/config-pass, installing a filesystem driver, starting a mount, creating a service, or testing against a user remote. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `rclone version`, `rclone config file`, and a read-only configuration inventory that reveals remote names and types but no token or password values. If approved, test only an isolated in-memory or temporary local backend; rollback removes the new binary without touching configs, caches, remotes, or scheduled jobs. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
