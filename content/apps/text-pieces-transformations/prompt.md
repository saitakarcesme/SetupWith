# Text Pieces setup prompt

Set up Text Pieces from its official project and verified Flathub listing (https://apps.gnome.org/TextPieces/). Inventory Linux architecture, Flatpak scopes, existing package and data paths, saved custom-action count, scratchpad byte count, parser preferences, clipboard-history exposure and backup coverage without reading or printing scratchpad text, action bodies, filenames, clipboard contents, environment values, hashes, transformed output or personal data. Install stable `io.gitlab.liferooter.TextPieces` from verified Flathub in the existing ownership scope. Do not compile from source, launch the app, read the clipboard, load text, run a transformation, parse structured data, calculate a hash, execute a custom action, or overwrite saved state during setup.

Preserve scratchpad content, saved actions, action parameters, encoding and line-ending choices, recent state, clipboard policy, permissions, remotes, overrides and scope ownership. Text placed in a developer scratchpad may contain credentials, tokens, customer records or unpublished source code; redact it from diagnostics and never use real sensitive text to test installation. Base64 and escaping do not provide encryption, while ordinary checksums are not a substitute for password hashing. Label every later result with the exact operation and algorithm so transformed output is not mistaken for protected data.

Treat JSON, XML, YAML, regular expressions and custom scripts as untrusted executable or parser-adjacent input. Before a transformation, require source classification, byte and nesting limits, encoding, normalization, invalid-input behavior and a preview against synthetic fixtures. Disable external entities and unsafe YAML tags; define duplicate-key, alias and numeric-precision handling. For JSON/YAML conversion, disclose losses involving comments, anchors, timestamps, ordering and scalar types. For filters, cap regex time and preview affected lines. Custom actions require separately reviewed source, checksum, interpreter, arguments, environment allowlist, filesystem and network denial, timeout and output limit.

Verify provenance, app ID, origin, commit, runtime, executable, files and sandbox permissions offline. Confirm which portals and directories are reachable without exercising them. Prove no clipboard access, text read, parser invocation, hash computation, conversion, filter, script process, network request, temporary file, saved-action mutation or notification occurred. On failure, rollback only the new Text Pieces ref in its original scope; preserve shared runtimes, remotes, overrides, scratchpads, custom actions, clipboard state and backups.
