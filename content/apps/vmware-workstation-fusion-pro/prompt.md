# VMware Workstation Pro / Fusion Pro setup prompt

Set up VMware Workstation Pro / Fusion Pro from its verified official source (https://www.vmware.com/products/desktop-hypervisor/workstation-and-fusion). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Choose Fusion Pro only for macOS and Workstation Pro only for Windows or Linux, matching Intel, AMD, or Apple silicon host support. Use VMware's current download route, and enumerate virtual network, USB, keyboard, filesystem, and privileged helper components before installation.

Preserve every `.vmwarevm` bundle and VMX directory, VMDK, snapshot tree, suspend state, encryption key and vTPM data, virtual networks, NAT and DHCP settings, shared folders, preferences, licenses, and existing VMware Tools state. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: vm_library, network_mode, shared_folders, guest_tools. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Stop before Broadcom account sign-in, importing or opening a VM, accepting a commercial support obligation, changing Hyper-V or VBS, installing host drivers or kernel modules, creating virtual networks, enabling shared folders, attaching a device, upgrading virtual hardware, or restarting the host. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the installed Fusion or Workstation build and host architecture, use `vmrun` version or a safe About check, and inspect services and virtual adapters without powering on a guest. Verify VM registrations and files are unchanged; rollback must retain networks, disks, snapshots, encryption metadata, and libraries. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
