# Oracle VirtualBox setup prompt

Set up Oracle VirtualBox from its verified official source (https://www.virtualbox.org/wiki/Downloads). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Select Oracle's base package for the host OS and architecture, check hardware virtualization and conflicts with Hyper-V, KVM, or another hypervisor, and show every host network, USB, and kernel driver before installation. Keep the separately licensed Extension Pack uninstalled by default.

Preserve all registered and unregistered VM folders, virtual disks, snapshots, saved states, host-only and NAT networks, DHCP configuration, global preferences, media registry, Extension Packs, Guest Additions images, and autostart definitions. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: default_machine_folder, host_only_network, extension_pack, guest_additions. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Never start, upgrade, import, register, move, clone, snapshot, or delete a VM during verification. Require separate approval for host drivers, kernel modules, Secure Boot module signing, network adapters, USB filters, Extension Pack licensing, Guest Additions, firewall rules, and any host restart. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `VBoxManage --version` and `VBoxManage list hostinfo`, inspect driver or kernel-module status and list VM names without opening disks. Launch Manager without starting a guest, confirm existing machines remain registered and unchanged, and provide rollback that preserves every VM and virtual disk. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
