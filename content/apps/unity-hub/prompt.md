# Unity Hub setup prompt

Set up Unity Hub from its verified official source (https://unity.com/download). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install Unity Hub from Unity's official download page only; do not install an Editor, template, SDK, or platform build module automatically.

Preserve existing Unity editors, projects, license files, templates, caches, modules, and install locations. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: editor_install_location, project_location, download_location, license_type. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Stop before Unity ID sign-in, MFA or CAPTCHA, age verification, subscription, payment, or license activation. Ask before editors/SDKs, firewall/autostart, drivers/kernel components, reboot, or multi-gigabyte modules. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Open Hub to the signed-out state, confirm its version and existing editor/project discovery, and ensure no editor or module download was queued. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
