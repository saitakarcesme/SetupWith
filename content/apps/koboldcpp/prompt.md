# KoboldCpp setup prompt

Set up KoboldCpp from its verified official source (https://github.com/LostRuins/koboldcpp). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Choose the official stable executable or source build that matches the OS, architecture, and available CPU, CUDA, ROCm, or Metal backend; verify release checksums where published.

Preserve GGUF models, presets, saved stories, launch arguments, configuration, generated content, and any previous KoboldCpp binary. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: model_directory, compute_backend, context_length, listen_address, listen_port. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not download models, execute model-adjacent scripts, expose a network listener, enable remote tunnels, or allocate most system memory without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run the binary's version or help command first; only with approval load a small local GGUF and confirm one loopback request before cleanly stopping the server. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
