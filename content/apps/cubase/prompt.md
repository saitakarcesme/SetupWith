# Cubase setup prompt

Set up Cubase from its verified official source (https://o.steinberg.net/en/support/downloads/steinberg_download_assistant.html). Supported targets: macOS, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install Steinberg Download Assistant first, then select only the licensed Cubase Pro, Artist, Elements, AI, or LE core application. Present separate sizes for HALion, Groove Agent, `vstsound` libraries, MediaBay, Activation Manager, and the optional Windows ASIO driver before downloading them.

Preserve Cubase projects, audio pools, backups, preferences, profiles, key commands, track and project templates, workspaces, presets, VST plug-in paths, blacklist, content libraries, MediaBay database, Steinberg licensing state, and older Cubase releases. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: edition, content_location, asio_driver, vst_plugin_paths. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Stop before MySteinberg sign-in, license activation, redeeming a code, installing the built-in ASIO driver, downloading multi-gigabyte content, moving `vstsound` libraries, scanning VST plug-ins, updating Activation or Library Manager, opening a project, or restarting Windows. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch the selected Cubase edition with no project, report exact build and licensed edition, then inspect ASIO choice, content paths, Steinberg utilities, and plug-in folders without scanning them. Confirm no content pack or driver was queued; rollback retains projects, libraries, licenses, presets, and prior editions. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
