# AWS CLI setup prompt

Set up AWS CLI from its verified official source (https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Follow AWS's platform-specific version 2 installer instructions, verify the downloaded signature or package origin, and detect any older packaged AWS CLI before selecting side-by-side or update behavior.

Preserve Preserve `~/.aws` credentials and config files, named profiles, SSO caches, plugins, completion settings, custom CA bundles, aliases, and the existing executable symlink target.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: default_region, output_format, profile_name, cli_auto_prompt. The only available credential references are secret://aws/access-key-id, secret://aws/secret-access-key, secret://aws/session-token. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not run `aws configure`, initiate SSO, store access keys, replace profile files, change CA or proxy settings, modify shell startup files, or call an AWS API without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `aws --version` and `aws configure list` only if it can redact values, report executable and install paths, and confirm that no credentials changed or AWS request was sent. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
