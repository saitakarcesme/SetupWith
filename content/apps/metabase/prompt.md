# Metabase setup prompt

Set up Metabase from its verified official source (https://github.com/metabase/metabase). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Choose the official JAR or container deployment, confirm a supported Java runtime or container engine, and use an explicit application database and persistent storage for anything beyond a disposable trial.

Preserve the Metabase application database, uploaded assets, plug-ins, encryption key, container volumes, logs, and existing data-source definitions. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: deployment_mode, application_database, storage_directory, listen_address, listen_port. The only available credential references are secret://metabase/database-url, secret://metabase/encryption-secret-key. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not connect databases, create an admin account, migrate an existing application database, expose the port, or enable email without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Start a fresh loopback-only instance with temporary storage only when approved, confirm the health endpoint and version, then stop it without completing onboarding. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
