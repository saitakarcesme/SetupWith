# Canva setup prompt

Set up Canva from its verified official source (https://www.canva.com/download/). Supported targets: macOS, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install the signed Canva desktop client from Canva's download page for the detected platform and architecture, preserving any existing browser-only workflow. Do not add browser extensions, import a browser profile, claim a template, or enable startup and notifications during the installer flow.

Preserve desktop cache and drafts, downloaded exports, browser and desktop account sessions, team and brand-kit context, upload history, local fonts exposed to Canva, notification choices, deep-link handlers, and any unsaved collaborative design state. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: download_folder, launch_at_login, notification_permissions, hardware_acceleration. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Hand control back before Canva account creation or sign-in, SSO or MFA, team selection, trial or paid subscription, uploading media, accessing brand assets, inviting collaborators, publishing or ordering prints, using AI generation, granting notifications, or opening private designs. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Check the Canva publisher signature and client version, then open only to the signed-out welcome screen. Confirm no browser profile or account was imported, no design or team loaded, no asset uploaded, and no startup or notification permission changed; rollback preserves exports, drafts, and cache. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
