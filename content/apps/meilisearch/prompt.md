# Meilisearch setup prompt

Codex, inspect the OS, architecture, active shell, existing Meilisearch binary or container, database directory, dump and snapshot files, environment configuration, and port 7700 before changes. Prefer the official Meilisearch Docker image with persistent storage for cross-platform setups; on supported Linux or macOS, the official binary or Homebrew package is acceptable when a native process is preferred. Ask before administrator access, installing container tooling, starting a service, exposing ports, changing firewall rules, replacing a binary or container, or upgrading an existing database. Preserve indexes, dumps, snapshots, task history, and environment files. Configure only `database_path`, `http_address`, and `environment` when supplied. Inject `secret://provider/MEILI_MASTER_KEY` through a protected environment or secrets store; never print, echo, log, or write it into committed files. Default to production-style authentication when externally exposed and bind locally otherwise. Verify the executable or image, database mount, `/health`, version endpoint, master-key enforcement, and a disposable index with a few documents and one search query. Rollback restores manifests and configuration, removes only the installed process or container, and keeps database files unless deletion is explicitly approved. End with a structured summary of install method, bind address, environment mode, authentication, persistence, verification, approvals, and rollback.
