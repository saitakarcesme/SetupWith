# Dialect setup prompt

Set up Dialect from its official project and verified Flathub listing (https://dialectapp.org/). Inventory Linux architecture, desktop, Flatpak scopes, existing Dialect package, provider choice, custom LibreTranslate or Lingva endpoint, stored provider credentials, translation history policy, clipboard integration, text-to-speech settings, audio output and GNOME search-provider state. Install stable `app.drey.Dialect` from the verified Flathub origin in the existing ownership scope. Do not replace a distro package, build from source, launch Dialect, choose a provider, store a key or send a test phrase during setup.

Preserve provider settings, endpoint URLs, language pairs, history, favorites, credentials, clipboard preferences, speech configuration, window state and search integration. Translation content may contain contracts, source code, health information, credentials or private conversations. Never include existing history or clipboard contents in diagnostics. Keep DeepL keys and Kagi session tokens inside the existing secret-service boundary; do not print, migrate, validate or substitute them, and never treat a Kagi session token as a harmless URL.

Every online translation or automatic-language-detection request can disclose source text, language metadata and network identity to Google, DeepL, Kagi, Microsoft, Yandex or an operator of a LibreTranslate/Lingva instance. Before future use show the exact HTTPS endpoint, operator, provider terms, authentication method, text scope, retention expectation and redirects. Do not probe public instances, accept invalid TLS, silently fall back between providers or send sample text. A self-hosted endpoint is not trusted merely because it is open source.

Do not read or overwrite the clipboard, enable background selection handling, retain a new history entry, activate the GNOME search provider, synthesize speech or open an audio device. Text-to-speech may send translated content to another service, so review its endpoint independently from translation. Verify Dialect provenance, app ID, origin, installed commit, runtime, executable, files and declared permissions through Flatpak metadata offline. Prove no provider, keyring item, endpoint, history record, clipboard, search setting, audio process or network request changed. On failure, rollback only the newly installed Dialect ref in its original scope; retain shared runtimes, remotes, overrides, history and secrets.
