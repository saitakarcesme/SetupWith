# Wolfram Mathematica setup prompt

Set up Wolfram Mathematica from its verified official source (https://account.wolfram.com/products). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Retrieve the entitled Mathematica installer from the user's Wolfram Account for the exact platform and architecture, distinguish it from Wolfram Engine and Wolfram Desktop, and preserve side-by-side versions. Do not install documentation, paclets, grid components, or a network license manager automatically.

Preserve notebooks, Wolfram Language source and packages, `$UserBaseDirectory`, init files, front-end preferences, stylesheets, palettes, paclets, documentation, application data, activation records, MathLM server configuration, kernels, and existing Mathematica versions. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: version, installation_directory, license_method, user_base_directory. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Hand control back before Wolfram Account sign-in, product activation, entering an activation key, selecting a MathLM server, installing paclets, evaluating initialization files, opening a notebook, enabling cloud connectivity, downloading knowledge data, or replacing a front-end or kernel version. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Check Wolfram's signature and application version, then query `$Version` and `$SystemID` with initialization disabled and no notebook evaluation. Report front-end and kernel locations plus license status without keys or server secrets; rollback preserves activation, user base content, notebooks, paclets, and older kernels. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
