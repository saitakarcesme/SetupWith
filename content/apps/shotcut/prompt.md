# Shotcut setup prompt

Set up Shotcut from its verified official source (https://github.com/mltframework/shotcut). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the official stable Shotcut installer, bundle, or portable archive for the current platform and confirm hardware and graphics requirements before enabling acceleration.

Preserve Shotcut settings, layouts, presets, autosaves, project files, proxy media, recent files, and export queues. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: project_directory, video_mode, proxy_directory, hardware_encoder. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not open projects, scan media, enable hardware encoders, change file associations, render exports, or remove proxy files without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch Shotcut with no project, report application and MLT versions, and use only a generated color clip for an optional preview test with no export. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
