# AutoHotkey setup prompt

Set up AutoHotkey from its verified official source (https://www.autohotkey.com/download/). Supported targets: Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install the official AutoHotkey v2 runtime unless an existing script explicitly requires v1, preserve side-by-side versions when needed, and register script associations only after showing which interpreter each extension will invoke.

Preserve all existing scripts, compiled executables, libraries, startup shortcuts, scheduled tasks, file associations, editor integration, version-specific interpreters, hotkey assignments, and per-script working directories. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: major_version, script_directory, file_association, startup_scripts. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not download or execute unreviewed scripts, automate credential entry, bypass security prompts, create persistence, intercept broad keyboard input, compile scripts, or run anything elevated; present every proposed script for line-by-line review. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the interpreter version and executable path, syntax-check a harmless disposable script that displays its version without registering hotkeys, then remove it and verify no startup item, scheduled task, or file association changed unexpectedly. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
