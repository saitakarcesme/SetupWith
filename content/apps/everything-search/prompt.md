# Everything setup prompt

Set up Everything from its verified official source (https://www.voidtools.com/downloads/). Supported targets: Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Choose voidtools' signed installer or portable package for the detected Windows architecture, explain that NTFS filename indexing reads the USN journal, and request approval separately before installing the Everything background service.

Preserve existing Everything database files, indexed-volume selection, excluded paths, filters, bookmarks, search history, HTTP or ETP settings, hotkeys, portable configuration, and the current service registration state. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: indexed_volumes, exclude_patterns, everything_service, search_history. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not index newly attached or sensitive volumes, enable the HTTP or ETP server, expose search results remotely, install a service, persist search history, or change filesystem permissions without explicit approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the voidtools signature and executable version, verify only approved volumes appear in the index, run a filename-only query for a disposable file, and check that no network listener or unapproved service was created. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
