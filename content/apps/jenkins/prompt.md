# Jenkins setup prompt

Set up Jenkins from its verified official source (https://github.com/jenkinsci/jenkins). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the current Jenkins LTS package, WAR, or official container with a supported Java runtime and explicit persistent home; distinguish evaluation from a durable service.

Preserve `JENKINS_HOME`, jobs, build records, plug-ins, credentials, secrets, nodes, configuration-as-code, and container volumes. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: java_home, jenkins_home, listen_address, http_port, deployment_mode. The only available credential references are secret://jenkins/admin-password. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not unlock Jenkins, install plug-ins, create users, run jobs, attach agents, migrate home data, or expose the HTTP port without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm Java and Jenkins versions; only with a fresh temporary home start loopback Jenkins, reach the locked setup screen, then stop it without recording the initial password. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
