# tmux setup prompt

Codex, inspect the OS, architecture, login shell, terminal type, existing `tmux` binary, server sessions, and configuration files before making changes. On macOS use Homebrew `tmux`; on Debian/Ubuntu use `apt install tmux`; on Fedora-family systems use `dnf install tmux`; on Windows do not claim native support—use an existing WSL environment only after confirming the user wants that. Ask before administrator access, terminating sessions, changing the default shell, or replacing terminal key bindings. Preserve `~/.tmux.conf`, included files, plugins, and all running sessions. Configure only `prefix_key`, `default_shell`, and `mouse_support` when provided. Validate the requested prefix syntax, ensure the shell executable exists, and append a clearly marked SetupWith section rather than overwriting existing directives. Do not install TPM or plugins unless approved. Verify with `tmux -V`, `tmux source-file` against a temporary combined config, and a detached test server using a unique socket name. Confirm the prefix binding, shell command, and mouse option through `show-options`; do not attach to or alter existing sessions. Rollback removes the marked section, restores the backup, and uninstalls only the package added here. End with a structured summary of existing sessions, install method, config changes, test results, approvals, and rollback commands.
