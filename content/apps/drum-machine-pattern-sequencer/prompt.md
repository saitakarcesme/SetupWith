# Drum Machine setup prompt

Inventory Linux architecture, Flatpak scopes, existing package and data paths, pattern, page and active-step counts, BPM range, custom-sample and MIDI-mapping counts, aggregate sample and project bytes, audio-output and export-format preferences, sandbox overrides and backup coverage without opening projects or revealing pattern content, sample filenames, waveforms, musical ideas, MIDI notes tied to devices, export paths or listening history. Install stable `io.github.revisto.drum-machine` from verified Flathub in the existing ownership scope. Do not compile from source, launch Drum Machine, load or clear a pattern, decode a sample, remap MIDI, start transport, schedule a hit, play audio, change BPM or volume, reset defaults, render MIDI or audio, reserve an output or write project state during setup.

Preserve every pattern page, step, BPM, sample byte and assignment, MIDI mapping, gain, transport state, project path, export preference, owner and permission, plus remotes, overrides and scope ownership. Installation must not confuse Clear with Reset to Defaults, replace custom samples, renumber MIDI notes, start playback, normalize gain, rewrite relative paths or convert a project format. Custom samples may be private and untrusted; redact names and decode them only within strict format and resource limits.

Before later playback, define step resolution, bar and page order, BPM, loop boundary and scheduler clock. Pin sample checksum, license, format, rate, channels, bit depth and instrument row. Review duplicate MIDI note and channel mappings and external-device assumptions without sending messages during tests. Set a low master volume and explicit output, preserve headroom for simultaneous hits, measure latency and tempo drift, and stop cleanly across page boundaries, suspend and underrun. Validate timing with synthetic clicks and a virtual MIDI sink, not user patterns or physical gear.

Saving requires a versioned manifest, portable path policy, collision preview and atomic write. Clear Pattern may remove steps only; Reset to Defaults may also replace samples, BPM and volume and therefore needs a broader confirmation and backup. For WAV, FLAC, Ogg, MP3 or MIDI export, preview range, tail, codec, sample rate, normalization, metadata and destination. Verify duration, event count, tempo map, peak level and decode or MIDI-parse success, then remove only owned partials after cancel. Verify installation provenance and permissions offline, proving no project read, sample decode, mapping, transport, audio, tempo, reset, export or write occurred. On failure, rollback only the new Drum Machine ref; preserve shared runtimes, patterns, samples, mappings, settings and backups.
