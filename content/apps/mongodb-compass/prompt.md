# MongoDB Compass setup prompt

Set up MongoDB Compass from its verified official source (https://github.com/mongodb-js/compass). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install the signed stable Compass package for the detected platform and architecture, keeping preview channels and command-line database tools separate.

Preserve saved connections, favorites, query history, application preferences, certificates, SSH settings, and existing MongoDB credentials. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: connection_favorites, read_only_mode, telemetry_preference, proxy_settings. The only available credential references are secret://mongodb/uri. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not connect to a deployment, import connection strings, save credentials, enable telemetry, or execute queries without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch Compass to its connection screen, report the application version and data directory, and make no network connection or automatic connection attempt. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
