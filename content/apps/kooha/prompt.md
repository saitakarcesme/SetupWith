# Kooha setup prompt

Set up Kooha from its verified Flathub listing (https://flathub.org/apps/io.github.seadve.Kooha). Detect Linux architecture, desktop environment, Wayland or X11 session, Flatpak installation, existing Kooha app and data, PipeWire, GStreamer PipeWire plugin, xdg-desktop-portal implementation, screen-cast portal state, microphones, audio outputs, recording folders, codecs and hardware encoders. Install only the stable verified Flatpak application `io.github.seadve.Kooha` and its declared runtime. Do not build from source, use a third-party distribution package, add beta remotes, or install host codecs and portal implementations automatically.

Install without launching Kooha or opening a portal chooser. Preserve every existing recording, partial capture, filename, timestamp, metadata, save location, preference, Flatpak override, portal permission, PipeWire configuration, audio route and recent source. Never choose a monitor, window, region, microphone or desktop-audio node merely to verify setup. Screen recordings can expose passwords, notifications, private messages, customer data, browser tabs and other applications; audio can capture conversations and system media.

Do not request or retain screen-cast, microphone or filesystem permission, change a mixer, unmute an input, reroute PipeWire nodes, hide or show the pointer, or start a countdown. Before any later recording, show the exact visual sources, crop, audio nodes, consent, frame rate, cursor state, delay, format, codec, output path, free space, collision behavior and retention plan. Require an isolated desktop with notifications disabled and a disposable destination. Never overwrite a recording or delete an incomplete file automatically.

Keep `KOOHA_EXPERIMENTAL` unset. Experimental formats, hardware encoders, window capture and multiple video sources are disabled for stability and performance reasons and need separate testing plus approval. Do not add broad `--filesystem`, device, socket or D-Bus Flatpak overrides to bypass a broken portal. Verify Flathub verification, application ID, installed commit, signature, runtime, declared permissions and data paths using Flatpak metadata without running the app. Confirm no portal prompt, grant, PipeWire node, audio state, process, recording, partial file, preference, override or experimental flag changed. Roll back only the installed Flatpak ref and setup-owned launcher while retaining all data and permissions.
