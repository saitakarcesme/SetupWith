# MySQL setup prompt

Codex, inspect the OS, architecture, shell, existing MySQL clients and servers, package source, data directory, configuration files, services, port 3306, and available backups before changes. Prefer Homebrew `mysql` on macOS, Oracle’s official MySQL repository or the distribution-supported package on Linux, and the official MySQL Installer or `winget` package on Windows. Ask before administrator access, adding repositories, initializing data, enabling a service, changing ports or firewall rules, running upgrades, resetting accounts, or overwriting configuration. Preserve all databases, users, grants, binary logs, `my.cnf` files, and service definitions. Configure only `mysql_user`, `mysql_database`, `mysql_port`, and `data_directory` when supplied. Use `secret://provider/MYSQL_ROOT_PASSWORD` and `secret://provider/MYSQL_PASSWORD` only through protected input or option-file mechanisms; never print, echo, log, or expose them in process arguments. Keep network access local unless explicitly approved. Create requested accounts and schemas idempotently with least-privilege grants. Verify `mysql --version`, server status, `mysqladmin ping`, local authentication, schema ownership, and a disposable transactional table. Rollback restores configs and prior service state, removes only a newly created empty instance with approval, and never deletes existing data automatically. End with a structured summary of package source, instance, accounts, schema, port, verification, approvals, and rollback.
