# Azure CLI setup prompt

Set up Azure CLI from its verified official source (https://learn.microsoft.com/en-us/cli/azure/install-azure-cli). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use Microsoft Learn's installer path for the detected platform, prefer Microsoft's signed repository or package, and inspect an existing `az` executable before changing its version or channel.

Preserve Preserve the Azure CLI configuration directory, account and token caches, cloud selection, defaults, installed extensions, service-principal settings, certificates, and shell completion configuration.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: default_subscription, output_format, extension_policy, cloud_environment. The only available credential references are secret://azure/client-id, secret://azure/tenant-id, secret://azure/client-secret. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not run `az login`, choose a subscription, install an extension, store service-principal credentials, alter a cloud endpoint, enable telemetry, or invoke Azure operations without consent. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `az version` and a local configuration inspection without account enumeration, report package and executable paths, and verify that no login, extension update, or cloud request occurred. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
