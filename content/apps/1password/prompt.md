# 1Password setup prompt

Set up 1Password from its verified official source (https://1password.com/downloads/). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Select the signed 1Password desktop package for the detected operating system, using its supported Linux repository only when that platform is selected, and install the application without adding browser extensions or enabling the SSH agent automatically.

Preserve existing local vault cache, account metadata, application preferences, browser integration state, SSH agent configuration, recovery documents, and any independently installed 1Password command-line tools. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: autolock_timeout, browser_integration, ssh_agent, biometric_unlock. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Stop before entering an account password, Secret Key, recovery code, passkey, biometric approval, or vault item; browser integration, biometric unlock, Watchtower, and SSH-agent access each require the user's explicit consent. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the signed application version and publisher, open only the locked welcome screen, verify the configured auto-lock policy, and ensure no vault, browser extension, credential, or SSH socket was changed during setup. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
