# Android Studio setup prompt

Set up Android Studio from its verified official source (https://developer.android.com/studio). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download the current stable Android Studio package from Android Developers, verify its published checksum where available, and install the IDE without accepting SDK or emulator downloads yet.

Preserve Preserve Android Studio profiles, SDK directories, AVDs, Gradle caches, keystores, trusted projects, custom JDKs, plugins, emulator snapshots, and command-line tool versions.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: android_sdk_location, jdk_location, emulator_location, gradle_user_home. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Treat SDK packages, emulator images, USB or hypervisor drivers, hardware acceleration, license acceptance, analytics, sign-in, and multi-gigabyte downloads as separate approval checkpoints. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Start the IDE at the welcome screen, report its build and runtime, inspect SDK and virtualization detection read-only, and confirm that no SDK component, AVD, driver, or project was created. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
