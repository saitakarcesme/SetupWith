# Homebrew setup prompt

Codex, inspect the OS, CPU architecture, shell, existing `brew` commands, installation prefixes, ownership, and shell environment before proceeding. Homebrew is appropriate only for macOS and supported Linux environments; do not attempt installation on Windows outside an explicitly approved WSL setup. If Homebrew already exists, diagnose it before upgrading or repairing. For a new installation, use the official Homebrew installer from the canonical repository, but ask before administrator access, creating `/opt/homebrew`, `/usr/local`, or Linuxbrew directories, changing ownership, or editing shell profiles. Preserve existing taps, formulae, casks, services, and configuration. Configure only `install_prefix` and `auto_update` when supplied. Never force a nonstandard prefix unless Homebrew supports it and the user explicitly approves. Add `brew shellenv` to the correct profile through a clearly marked, idempotent block. Interpret `auto_update` through supported Homebrew environment variables, without disabling security updates silently. Verify using `brew --version`, `brew config`, `brew doctor`, prefix ownership checks, and a read-only `brew update --preinstall` only with approval. Do not install arbitrary formulae as a test. Rollback should remove only profile lines and files created in this run; full Homebrew removal requires separate confirmation because it is destructive. End with a structured summary of prefix, architecture, profile edits, diagnostic results, approvals, and safe rollback options.
