# MusicBrainz Picard setup prompt

Set up MusicBrainz Picard from its official downloads page (https://picard.musicbrainz.org/downloads/). Detect Windows, macOS, or Linux, architecture, package managers, an existing stable or portable installation, configuration, plugins, scripts, naming presets, cache, browser integration, fpcalc, MusicBrainz account, AcoustID API key, and configured music directories. Install the current stable signed package or distribution package; do not choose a beta, daily PPA, unpinned source build, or a second portable copy without approval.

Launch with no music folders or files loaded. Preserve the entire audio library, filenames, directory layout, timestamps, permissions, extended attributes, tags, embedded artwork, sidecar images and logs, playlists, cues, configuration, naming and metadata scripts, plugins, cache, credentials, API keys, collections, and pending edits. Keep rename files, move files, move additional files, overwrite existing files, delete empty directories, tag writing, cover-art embedding, fingerprint storage, browser commands, and submission features disabled during setup. Do not let the first-run wizard select or reorganize a real library.

Picard's Save operation can rewrite audio metadata, embed images, rename files, move them into generated directories, move wildcard-matched sidecars, overwrite destinations, and remove emptied source directories. Before any later write, require a backup or verified copy, hash the source files, preview old and new tags plus every destination path, check path-length and filesystem compatibility, and obtain approval for the exact batch. Treat file-naming scripts and plugins as code. Never install or enable a registry, URL, local, or third-party plugin without reviewing its source, version and permissions; installed plugins are enabled automatically. Never expose credentials in logs, submit a collection, or send acoustic fingerprints. `Scan` invokes fpcalc and contacts AcoustID for lookup, while Submit uploads fingerprints tied to matched recordings; both require explicit network and privacy approval.

Verify publisher or package provenance, artifact checksum where published, application version, executable, configuration path, install method, bundled fpcalc path, and plugin baseline. Use only a setup-created copy of a small freely redistributable audio sample when functional validation is requested; record before-and-after hashes and delete no source. Otherwise verify startup and preferences without loading media. Confirm no library file, directory, tag, artwork, playlist, cue, cache, plugin, script, account, API key, fingerprint, collection, browser, or network state changed. Roll back only the installed application and setup-owned shortcuts, preserving every existing Picard setting and music asset.
