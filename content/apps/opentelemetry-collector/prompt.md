# OpenTelemetry Collector setup prompt

Set up OpenTelemetry Collector from its verified official source (https://github.com/open-telemetry/opentelemetry-collector). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Choose the core or contributed Collector distribution deliberately, install an official stable binary, package, or container, and pin configuration syntax to that release.

Preserve Collector configuration, service definitions, queues, file-storage extensions, certificates, authentication headers, and existing telemetry pipelines. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: distribution, config_path, listen_address, receiver_ports, exporter_endpoint. The only available credential references are secret://otel/exporter-auth-token. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not bind receivers, send telemetry, read host logs, install a service, expose diagnostics, or connect exporters without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run the binary version and validate an approved configuration; otherwise use a minimal no-network configuration that starts briefly and exits cleanly without collecting host data. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
