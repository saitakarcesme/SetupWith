# ComfyUI setup prompt

Codex, first inspect the OS, architecture, shell, GPU vendor and memory, Python installation, existing ComfyUI or Comfy Desktop setup, custom nodes, models, workflows, and occupied ports. On supported Windows and macOS systems prefer the official ComfyUI Desktop installer; on Linux use the official manual installation with Git and a dedicated Python virtual environment, selecting the correct PyTorch backend for detected hardware. Ask before administrator access, installing GPU drivers, opening ports, changing firewall rules, downloading checkpoints, replacing environments, or overwriting workflows. Preserve `custom_nodes`, `models`, `input`, `output`, user settings, and workflow JSON files. Configure only `model_path`, `output_path`, `listen_address`, and `gpu_backend` when supplied. Reference `secret://provider/HUGGINGFACE_TOKEN` only through a secure downloader or environment mechanism; never print or log it. Bind to loopback unless LAN access is explicitly approved. Do not install third-party custom nodes automatically. Verify startup logs, GPU detection, HTTP access, model path discovery, output write permissions, and execution of a minimal built-in workflow only when a compatible approved model exists. Rollback restores paths and settings, removes only the created environment or application, and retains models and outputs unless approved. End with a structured summary of installation, acceleration, paths, service state, checks, approvals, and rollback.
