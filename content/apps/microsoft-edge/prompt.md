# Microsoft Edge setup prompt

Set up Microsoft Edge from its verified official source (https://www.microsoft.com/edge/download). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use Microsoft's signed Edge package for the detected operating system, detect whether Edge is already system-managed or built into Windows, and avoid replacing or repairing the existing browser unless the user explicitly requests that path.

Preserve all Edge profiles, bookmarks, history, cookies, passkeys, extensions, enterprise policies, installed web apps, default-browser choice, search settings, certificates, and any system-managed update channel. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: default_browser, tracking_prevention, profile_directory, sync_enabled. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not make Edge the default browser, import another browser's data, sign in, enable sync, install extensions, change search providers, modify enterprise policy, or enable background startup without separate user approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the Microsoft signature, installed channel, version, executable, and profile path; launch a temporary signed-out window to the internal version page, then close it without importing data, changing defaults, or leaving background processes enabled. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
