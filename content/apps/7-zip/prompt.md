# 7-Zip setup prompt

Set up 7-Zip from its verified official source (https://github.com/ip7z/7zip). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install the official stable 7-Zip package or trusted distribution build for the platform and architecture, keeping GUI shell integration and command-line binaries as explicit choices.

Preserve archives, extraction directories, context-menu settings, file associations, saved paths, and any previous 7-Zip installation. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: archive_directory, compression_level, default_format, file_associations. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not extract untrusted archives, overwrite files, change associations, add shell integration, or test password-protected user archives without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run the 7-Zip version command and create, list, test, and extract a tiny temporary archive containing generated text; remove only those test artifacts. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
