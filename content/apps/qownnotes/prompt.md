# QOwnNotes setup prompt

Set up QOwnNotes from its official installation page (https://www.qownnotes.org/installation/). Detect Windows, macOS, or Linux, architecture, package managers, existing native, portable, AppImage, Snap or Flatpak installation, settings sessions, note folders, external sync clients, Nextcloud or ownCloud accounts, QOwnNotesAPI, CalDAV tasks, scripts, browser companion, PGP tools, AI, LanguageTool and Markdown LSP integrations. Install one stable signed or repository-verified package matching the existing ownership model. Do not add a package repository, switch confinement models, enable automatic updates, or migrate portable settings without approval.

Do not launch the first-run wizard or select a note folder during installation. Preserve every Markdown note, filename, directory, attachment, embedded image, link, tag, bookmark, workspace, layout, search, trash item, version, sync conflict, task, share, script, encryption setting, key association, account and application preference. QOwnNotes stores notes as ordinary local files and does not itself synchronize notes or attachments; never claim that connecting QOwnNotesAPI replaces the user's Nextcloud, ownCloud or other filesystem sync client. Do not move a folder into a sync root or enable sharing merely to verify setup.

Treat community scripts and custom actions as executable code with potential file and network access. Do not browse a script repository, install or update a script, invoke `--action`, enable a browser extension, connect AI or grammar services, or launch an LSP before reviewing source, endpoints and data scope. Never use `--clear-settings`. Avoid `--dump-settings` because it can expose environment and account details. `--decrypt-note` prints plaintext, and a decrypt password supplied as an argument can appear in process lists and shell history; never decrypt a real note, print keys or passwords, copy plaintext to the clipboard, or store decrypted output.

Before any later cloud connection, show server URL, TLS validation, username, requested paths, sharing behavior, CalDAV collections and credential storage. Never create public links, restore or delete server trash, overwrite note versions, resolve sync conflicts, alter tasks, clean orphaned attachments, import notebooks, or bulk-export without a complete diff and backup. Verify publisher or package provenance, checksum where available, `QOwnNotes --version`, executable, method and settings location without starting a normal instance. Confirm no notes, folders, attachments, profiles, accounts, network requests, scripts, plaintext, clipboard, sync state or server data changed. Roll back only the installed application and setup-owned shortcuts.
