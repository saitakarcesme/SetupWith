# Papers setup prompt

Set up Papers from its official GNOME project and verified Flathub listing (https://apps.gnome.org/Papers/). Inventory Linux architecture, Flatpak scopes, existing package and data paths, recent-document and reading-position counts, aggregate thumbnail-cache bytes, annotation and form-state presence, encrypted-document reference count, portal and printer-access presence, sandbox overrides and backup coverage without opening documents or revealing filenames, titles, authors, text, searches, annotations, form values, signatures, passwords, links, printer names or reading interests. Install stable `org.gnome.Papers` from verified Flathub in the existing ownership scope. Do not compile from source, launch Papers, enumerate directories, open or parse a PDF, DjVu, TIFF or comic archive, prompt for a password, render a page, search, read annotations, activate a link, access a printer, update recents or write a document during setup.

Preserve every document byte, owner, permission and timestamp, plus annotations, forms, signatures, attachments, layers, bookmarks, reading positions, recents, thumbnails, print preferences, remotes, overrides and scope ownership. Documents and comic archives are untrusted parser containers, not inert pages. Redact content and reading history. Never store an encryption password in catalog data, logs or command history, flatten a signature, discard an incremental update, rewrite an original, submit a form, launch embedded content or make Papers the default handler without explicit review.

Before later opening, validate signature and type independently of extension; enforce file, page, object, archive-depth, decompression, image-pixel, font, memory and time limits in parser isolation. Disable document JavaScript and automatic attachment launch. Obtain encrypted-document passwords through a non-echoing prompt with defined memory lifetime and no clipboard use. Show whether a signature is cryptographically valid, trusted and current as separate facts. Test supported formats only with disposable synthetic fixtures, including malformed archives, not user documents.

Annotation or form changes require an exact diff, authorship and destination preview, original preservation and atomic compatible save. External links and email addresses require final-target confirmation after redirects; never infer safety from visible link text. Printing requires printer identity, physical location, page range, copies, duplex, color, scaling, document-title exposure and spool-retention review. Verify provenance, app ID, origin, commit, runtime, executable, files and static permissions offline. Prove no document, password, parser, render, search, annotation, form, link, printer, recent item, cache or write was touched. On failure, rollback only the new Papers ref in its original scope; preserve shared runtimes, remotes, overrides, documents, annotations, forms, signatures, reading state, print settings and backups.
