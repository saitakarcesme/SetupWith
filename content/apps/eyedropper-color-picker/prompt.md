# Eyedropper setup prompt

Set up Eyedropper from its official repository and verified Flathub listing (https://apps.gnome.org/Eyedropper/). Inventory Linux architecture, Flatpak scopes, existing package and data paths, Wayland or X11 session, portal implementation, monitor color-profile presence, clipboard-manager policy and custom-format count without taking a screenshot, reading the clipboard or exposing format contents. Install stable `com.github.finefindus.eyedropper` from verified Flathub in the existing ownership scope. Do not compile from source, launch the app, request screen capture, sample a pixel, edit a color or copy any value during setup.

Preserve custom output formats, precision choices, last color, editor state, theme and portal decisions. A screen picker may expose pixels from messages, credentials, customer records or protected media even when only one color is wanted. Before future capture require a clean desktop, hidden notifications, closed sensitive windows, confirmed monitor, smallest portal scope and an approved pixel location. Never automate broad screenshots, bypass a portal denial or sample another person's display or remote session without authorization.

Record the source color's notation, alpha, assumed color space, transfer function, white point, bit depth and ICC profile before conversion. Hex, RGB, HSL and HSV are representations or models, while CMYK output depends on an actual print condition; XYZ and CIE Lab require explicit reference assumptions. Do not present a numerical conversion as device-independent brand truth, preserve more precision than the input supports or silently discard alpha. Flag clipping and out-of-gamut results, and compare the original and edited values separately.

Clipboard copying can persist in managers and synchronized devices. Show the exact non-sensitive value and destination before copying, avoid primary-selection surprises and clear only a setup-created test value if approved. Eyedropper does not replace contrast testing, calibrated proofing or brand review. Verify provenance, app ID, origin, commit, runtime, executable, portal declarations, files and permissions offline. Prove no screenshot, pixel sample, clipboard read/write, custom format, recent color, display profile, network or filesystem state changed. On failure, rollback only the new Eyedropper ref in its original scope; preserve runtimes, remotes, overrides, formats and desktop privacy settings.
