# Starship setup prompt

Codex, first detect the operating system, architecture, active and login shells, terminal, existing `starship` binary, package ownership, and current shell startup files. On macOS prefer Homebrew `starship`; on Debian/Ubuntu or Fedora-family systems use an available trusted package or Starship’s official installer after explaining the source; on Windows prefer `winget install Starship.Starship`. Ask before administrator access, executing a downloaded installer, modifying shell startup files, or installing a Nerd Font. Preserve existing `starship.toml` and shell initialization. Configure only `preferred_shell`, `prompt_preset`, and `nerd_font` when supplied. Initialize Starship in the correct profile using an idempotent, clearly marked line, and generate or merge the selected built-in preset without overwriting unrelated modules. Treat `nerd_font` as a preference check: verify availability and ask before installing any font. Verify with `starship --version`, `starship explain`, `starship timings`, and a clean non-interactive shell invocation that confirms initialization without duplicate prompt hooks. Avoid changing the system default shell. Rollback should remove the marked initialization line, restore the previous config, and uninstall only the package added during this run. Finish with a structured summary of shell detection, install source, files changed, preset status, font status, verification, approvals, and rollback.
