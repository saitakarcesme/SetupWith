# OpenToonz setup prompt

Set up OpenToonz from its official project site (https://opentoonz.github.io/e/index.html). Detect Windows, macOS, or Linux, architecture, graphics capabilities, package managers, existing stable or portable installation, OpenToonz Stuff location, project roots, current project, custom rooms and shortcuts, palettes, brushes, plugins, color profiles, codecs, FFmpeg, scanner or camera integration, render farm and version-control settings. Install the latest stable signed package or documented distribution package. Do not select a nightly build, compile an unpinned branch, replace OpenToonz Stuff, or migrate another Toonz variant automatically.

Launch without opening, creating or selecting a production project. Preserve every TNZ scene, TLV/PLI level, raster image, palette, drawing, scan, audio file, xsheet, storyboard, effect graph, project alias, output, cache, backup, autosave, temporary scene, custom room, shortcut, brush, plugin, studio palette, version-control working copy and uncommitted change. Record project roots and the `+inputs`, `+drawings`, `+scenes`, `+extras`, `+outputs` and `+palettes` mappings read-only. Never change a default folder because existing scenes may then fail to retrieve assets, and never assume files under a temp project are disposable.

Cleanup can generate TLV/TPL files and, for a partially processed level, offer to overwrite cleaned frames or delete the existing level and rebuild it from a selection. Rendering and batch cleanup can write many files or submit remote tasks. Do not scan, clean up, paint, save, save all, import, collect assets, convert, render, export, overwrite, delete unused content, clear caches, recover, or submit farm jobs during setup. Before any later operation, show all selected frames and levels, source and destination paths, project aliases, overwrite policy, output range, resolution, codec, color settings, external processes and recovery copy. Keep “Keep Original Cleaned Up Drawings As Backup” enabled for approved cleanup and verify storage capacity first.

Do not connect scanners, cameras, microphones, tablets, version-control servers, shared palettes, network project roots or render nodes without separate approval. Verify publisher or package provenance, checksum when available, version, executable, bundle paths, OpenToonz Stuff resolution, project-root baseline and optional external binaries using an empty offline launch. Close without saving and confirm no project became current, no temp scene was retained or removed, and no scene, level, palette, asset, preference, room, shortcut, cache, backup, device grant, repository, render task or network share changed. Roll back only the installed application and setup-owned shortcuts while preserving all production material and settings.
