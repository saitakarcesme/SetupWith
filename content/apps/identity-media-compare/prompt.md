# Identity setup prompt

Set up Identity from its official GNOME GitLab project and verified Flathub listing (https://gitlab.gnome.org/YaLTeR/identity). Inventory Linux architecture, Flatpak scopes, existing Identity package, portal grants, recent-file and association state, decoder stack, hardware acceleration and comparison preferences without opening or decoding any media. Install stable `org.gnome.gitlab.YaLTeR.Identity` from verified Flathub in the existing ownership scope. Do not compile from source, launch Identity, pass CLI display/zoom flags, open a file or claim image/video associations during setup.

Preserve every image and video byte-for-byte with paths, ownership, timestamps, metadata, color profiles, orientation, alpha and linked sidecars. Do not scan directories, follow unreviewed symlinks, hydrate cloud placeholders, mount remote storage, read thumbnails or create recent-document entries. Media may reveal identities, locations, unpublished work or medical imagery; never expose filenames, full paths, dimensions, duration or properties in diagnostics. Window titles and tab tooltips can disclose names and paths during future use, so review display context before opening sensitive material.

Treat image and video files as untrusted parser input. Identity uses modern image loaders including glycin and video pipelines using GStreamer and optional GPU acceleration. Do not decode an AVIF, JPEG XL, WebP, SVG, high-bit-depth image or video merely to verify installation; do not install codecs, enable hardware paths or open an audio device. Before future comparison show each exact input hash and trust source, decoder/plugin path, sandbox boundary, expected color-space/orientation handling, audio behavior and resource limits. Visual similarity is not byte equality and color-management differences must not be reported as file corruption.

Do not copy the current file to the clipboard, drag media out to another app, synchronize playback, inspect properties or change tab/row/column preferences. Verify Identity provenance, app ID, origin, installed commit, runtime, executable, files and declared permissions offline. Prove no media read, placeholder hydration, decoder process, GPU or audio activity, portal grant, recent entry, clipboard, association or network request changed. On failure, rollback only the new Identity ref in its original scope; preserve shared runtimes, remotes, overrides, media, decoder packages and desktop integration.
