# DBeaver setup prompt

Codex, inspect the OS, architecture, shell, existing DBeaver Community installation, Java runtime, workspace directory, drivers, secure storage, and desktop integration before making changes. On macOS prefer the official signed application or Homebrew Cask `dbeaver-community`; on Debian/Ubuntu use DBeaver’s official package or repository; on Fedora-family systems use the official RPM; on Windows prefer `winget install dbeaver.dbeaver.community`. Ask before administrator access, replacing an application, changing file associations, installing database drivers, opening a browser, or overwriting workspace settings. Preserve the workspace, connection metadata, scripts, drivers, certificates, and secure credential storage. Configure only `workspace_directory`, `default_driver`, and `editor_theme` when supplied. Do not create real database connections or store passwords unless separately approved. If the requested driver is absent, present its official Maven artifact and ask before downloading it. Verify application launch, executable version information, workspace writability, theme persistence, driver manager status, and opening a temporary SQL script without connecting to a server. Rollback restores workspace preferences, removes only drivers downloaded here, and uninstalls only the application channel added in this run. Finish with a structured summary of package source, workspace, driver state, theme, verification, approvals, and rollback steps.
