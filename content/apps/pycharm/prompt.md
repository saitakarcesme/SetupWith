# PyCharm setup prompt

Set up PyCharm from its verified official source (https://www.jetbrains.com/pycharm/download/). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install the current unified PyCharm build from JetBrains' download page or an already approved Toolbox App, matching the machine architecture and retaining older editions side by side.

Preserve Preserve PyCharm settings, plugins, local history, trusted projects, interpreter definitions, virtual environments, custom VM options, licenses, and both Community and Professional profiles.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: python_interpreter, project_directory, editor_theme, plugin_policy. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not activate a Pro trial, sign in to JetBrains, import settings, open or index a project, create an interpreter, install plugins, or change Python file associations without consent. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch PyCharm to the welcome screen with no project, record the build and runtime JDK, confirm settings directories, and verify that no interpreter or trial was activated. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
