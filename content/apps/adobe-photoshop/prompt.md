# Adobe Photoshop setup prompt

Set up Adobe Photoshop from its verified official source (https://www.adobe.com/creativecloud/desktop-app.html). Supported targets: macOS, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the Creative Cloud desktop app to select a supported Photoshop release and disclose its download size, required free space, GPU compatibility, and whether an older major version would be removed. Keep optional stock assets, language packs, and third-party plug-ins out of the install plan.

Preserve PSD and PSB files, autosave recovery data, scratch-disk choices, Camera Raw cache and presets, actions, brushes, patterns, gradients, workspaces, color settings, proof profiles, fonts, plug-ins, linked assets, and previous Photoshop versions. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: scratch_disks, color_settings, gpu_acceleration, plugin_directories. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not open a personal document, migrate presets, remove an old version, install plug-ins or fonts, change scratch disks or file associations, enable cloud-document sync, invoke Generative Fill, upload imagery, or start a trial or subscription without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch Photoshop to the home screen with no document, report the exact build, GPU status, scratch-disk target, color settings, and plug-in search paths, then close it. If an image test is approved, use a generated temporary PNG only; rollback preserves presets, recovery files, caches, and projects. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
