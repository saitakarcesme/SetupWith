# RStudio setup prompt

Set up RStudio from its verified official source (https://posit.co/download/rstudio-desktop/). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download RStudio Desktop from Posit's current open-source download route for the OS and architecture, and first identify a compatible existing R installation. Do not install or replace R, Quarto, TeX, compilers, Pandoc, or system build tools unless each missing dependency is separately approved.

Preserve RStudio preferences, projects and `.Rproj` files, source documents, notebooks, `.Rprofile`, `.Renviron`, workspace and history files, package libraries, renv caches and lockfiles, snippets, add-ins, connections, terminal settings, and prior R versions. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: r_version, default_working_directory, cran_mirror, restore_workspace. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not open a user project, restore or save `.RData`, run `.Rprofile`, install or update packages, contact a CRAN mirror, expose environment variables, connect to a database, render a notebook, alter the working directory, or replace the selected R version without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the Posit package and RStudio build, then start a clean session with `--no-restore` and no project, reporting the selected R executable and library paths without listing private environment values. Run only `R.version.string` if approved; rollback retains projects, histories, environments, packages, and preferences. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
