# WebStorm setup prompt

Set up WebStorm from its verified official source (https://www.jetbrains.com/webstorm/download/). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the signed WebStorm package from JetBrains or an approved Toolbox App, select the stable channel for the host architecture, and leave Node.js and package managers untouched.

Preserve Preserve WebStorm settings, plugins, local history, JavaScript runtimes, package-manager mappings, trusted projects, licenses, run configurations, and custom inspection profiles.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: node_interpreter, package_manager, project_directory, javascript_engine. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not start a paid trial, import another IDE profile, open or index a repository, install Node.js, execute package scripts, enable AI features, or add plugins without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Open WebStorm without a project, capture its build and runtime JDK, confirm existing Node.js detection read-only, and ensure no workspace files or file associations changed. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
