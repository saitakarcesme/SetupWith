# GIMP setup prompt

Codex, first inspect the OS, architecture, shell, existing GIMP installation, user profile, plugins, scripts, brushes, themes, color profiles, and file associations. Install the official GIMP package for the detected supported platform: the signed application on macOS, distribution packages or official Flatpak on Linux, and the official Windows installer or supported `winget` package. Ask before administrator access, replacing an application, changing file associations, installing Flatpak, enabling third-party plugins, or overwriting profile files. Preserve all user resources, shortcuts, templates, recent files, and plugin configuration. Configure only `theme`, `plugin_directory`, and `default_export_format` when supplied. Validate the export format and plugin directory, and add paths without removing existing search locations. Do not install external plugins automatically. Verify application launch, version information, profile loading, theme persistence, plugin-directory discovery, and a noninteractive export of a generated temporary image to the selected format. Never open or alter user artwork for testing. Rollback restores profile backups, removes only paths or files added here, and uninstalls only the package installed during this run. Finish with a structured summary of install source, profile path, theme, plugin directories, export format, verification, approvals, and rollback.
