# Arc Browser setup prompt

Set up Arc Browser from its verified official source (https://arc.net/download). Supported targets: macOS, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download Arc only from arc.net, verify its signature, and do not import data or create an Arc account automatically.

Preserve existing Arc profiles, Spaces, bookmarks, history, cookies, passwords, extensions, and default-browser choice. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: default_browser, profile_location, import_source, spaces, auto_updates. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Stop before Arc sign-in, MFA or CAPTCHA, sync, importing browser data, extension installation, or changing defaults. Ask before firewall/autostart, certificates, reboot, or large profile downloads. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Open to Arc's account onboarding, confirm version and signature, and leave sign-in, import, sync, extensions, and default-browser state unchanged. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
