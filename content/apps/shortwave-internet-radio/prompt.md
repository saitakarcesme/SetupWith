# Shortwave setup prompt

Set up Shortwave from its official GNOME project and verified Flathub listing (https://apps.gnome.org/Shortwave/). Inventory Linux architecture, Flatpak scopes, existing package and data paths, library and recording counts, aggregate recording and cache bytes, station-directory policy, output route, last volume, network-device discovery state, and notification policy without listing station names, stream URLs, track titles, listening history, receiver names, network addresses or filenames. Install stable `de.haeckerfelix.Shortwave` from verified Flathub in the existing ownership scope. Do not compile from source, launch Shortwave, search the station directory, resolve or open a stream, recognize a track, download artwork, discover receivers, record audio, change MPRIS state, emit sound, or modify the library during setup.

Preserve the station library, saved tracks, recordings, partial files, playback and volume state, output selection, receiver preferences, cache, notification choices, remotes, overrides and scope ownership. A radio library and listening history can disclose language, religion, politics or location; redact them from diagnostics and lock-screen metadata. Station names, titles, artwork and playlist contents are remote untrusted metadata. Installation must not clean caches, rename recordings, repair the library, resume playback or select a network speaker.

Before later playback, require station-directory provenance, request-retention terms, the initial stream URL, each playlist and redirect hop, final media hosts, HTTPS or explicit cleartext exception, MIME and codec expectations, bitrate and retry limits. Treat streams as hostile decoder input and never install codecs automatically. Track recognition and artwork may contact additional services; disclose endpoints and allow disabling. Recording requires explicit start and stop, destination, format, duration and byte quota, partial-file handling, retention and local copyright review. Network playback requires a bounded discovery window and confirmation of the exact receiver; do not cast based only on a friendly name.

Confirm the physical output route and start at muted or low volume before any later audio. Verify provenance, app ID, origin, commit, runtime, executable, files and sandbox permissions offline. Prove no DNS request, directory search, stream connection, decoder, metadata lookup, artwork fetch, multicast discovery, receiver contact, recording, library write, MPRIS change, notification or audio occurred. On failure, rollback only the new Shortwave ref in its original scope; preserve shared runtimes, remotes, overrides, library, recordings, cache, output state and receiver preferences.
