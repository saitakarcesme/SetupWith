# AutoCAD setup prompt

Set up AutoCAD from its verified official source (https://www.autodesk.com/support/download-install.html). Supported targets: macOS, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use Autodesk Account's official individual installer for the entitled AutoCAD version, platform, architecture, and language, and show download and extracted-installation space separately. Select core AutoCAD only; specialized toolsets, Material Library, Desktop Connector, add-ins, and old-version removal require their own approval.

Preserve DWG and DWT files, sheet sets, plot styles and PC3 devices, CUIx workspaces, profiles, tool palettes, blocks, fonts, hatch patterns, LISP and scripts, trusted paths, add-ins, license state, autosaves, recovery files, and previous AutoCAD versions. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: version, install_location, toolsets, template_path. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Stop before Autodesk sign-in or activation, trial or subscription choice, importing settings, removing an older release, installing toolsets or add-ins, changing file associations or trusted paths, opening and upgrading a drawing, loading AutoLISP, accessing cloud documents, or accepting a restart. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch AutoCAD with no drawing and suppress automatic script loading, report product year, build, license status without account data, graphics configuration, template, autosave, and support paths. Use no user DWG for testing; rollback retains all drawings, profiles, plot configuration, custom code, recovery files, and licenses. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
