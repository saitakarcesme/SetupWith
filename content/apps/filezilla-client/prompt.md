# FileZilla setup prompt

Set up FileZilla from its verified official source (https://filezilla-project.org/download.php?show_all=1). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Obtain FileZilla Client, never FileZilla Server, from the official project download page or a trusted distribution package. Review the visible installer for bundled offers and decline every unrelated optional product before installation.

Preserve Site Manager entries, trusted host keys and TLS certificates, queue state, transfer filters, bookmarks, speed limits, interface layout, update channel, and any XML settings from an existing portable or installed copy. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: interface_layout, transfer_mode, concurrent_transfers, default_local_directory. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not import sites, expose saved passwords, accept a new SSH host key or TLS certificate, connect to any server, upload or download files, change file permissions, delete remote items, enable synchronized browsing, or replace the default protocol handler without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Verify the FileZilla publisher or package signature and report the client version. Launch with Site Manager closed and an empty queue, confirm that no network session was opened, and describe rollback that restores settings while retaining site profiles, host-key decisions, and unfinished transfers. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
