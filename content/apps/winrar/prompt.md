# WinRAR setup prompt

Set up WinRAR from its verified official source (https://www.win-rar.com/download.html). Supported targets: Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download the current signed WinRAR installer matching Windows architecture directly from win-rar.com, report its version and trial licensing model, and leave archive associations and Explorer integration unselected until preferences are approved.

Preserve existing WinRAR profiles, compression presets, file associations, shell-menu choices, registration data, password-organizer state, temporary directory, archive comments, and settings belonging to other compression utilities. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: archive_associations, context_menu_entries, default_compression, temp_directory. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not open unknown archives, execute archived programs, save archive passwords, replace broad file associations, enable legacy context menus, or overwrite extracted files; encrypted archive passwords must be entered manually by the user. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Verify the RARLAB signature and application version, create and extract only a disposable password-free text archive in a temporary folder, compare its checksum, and confirm that approved associations and context-menu entries match the requested scope. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
