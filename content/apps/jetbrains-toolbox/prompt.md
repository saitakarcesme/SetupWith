# JetBrains Toolbox setup prompt

Set up JetBrains Toolbox from its verified official source (https://www.jetbrains.com/toolbox-app/). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download JetBrains Toolbox App from its official product page, validate the JetBrains signature, and use the documented per-user location without installing any IDE yet.

Preserve Preserve the Toolbox settings file, installed-tool inventory, custom tools directory, download cache, update channels, shell scripts, and separately installed JetBrains products.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: tools_install_location, update_channel, automatic_updates, shell_scripts_location. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not sign in, import settings, install or update an IDE, delete cached rollbacks, add browser extensions, or create shell launchers and startup entries without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Open Toolbox to the local tools view, report its version and configured directories, confirm existing IDE discovery without modification, then ensure no download or update was queued. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
