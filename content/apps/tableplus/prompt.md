# TablePlus setup prompt

Set up TablePlus from its verified official source (https://api.tableplus.com/download/). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use TablePlus's official platform selector for the current operating system, verify the package and license channel, and install without adding database drivers or opening connections.

Preserve Preserve saved connections, encrypted credentials, workspace tabs, query history, custom drivers, SSH keys, licenses, filters, safe-mode settings, and local backup files.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: connection_storage, query_history, safe_mode, update_channel. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not activate a license, import connections, install drivers, access an SSH key, disable safe mode, store a password, or connect to any local or remote database without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Launch TablePlus to the connection chooser, record the application version and data path, and confirm that no connection opened, credential migrated, query executed, or driver downloaded. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
