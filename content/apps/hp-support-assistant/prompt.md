# HP Support Assistant setup prompt

Set up HP Support Assistant from its verified official source (https://support.hp.com/us-en/help/hp-support-assistant). Supported targets: Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Confirm the Windows PC meets HP Support Assistant requirements, obtain the signed installer from HP Support, and explain HP services, device discovery, analytics, scheduled checks, diagnostics, driver access, and restart behavior before installation.

Preserve existing HP driver and BIOS versions, diagnostic history, warranty information, device nicknames, update schedule, notification choices, telemetry preferences, support logs, Windows Update state, and enterprise management policy. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: update_schedule, notification_policy, diagnostics_consent, device_discovery. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Do not transmit serial numbers, register devices, run invasive diagnostics, install drivers, flash BIOS or firmware, change schedules, enable analytics, contact a virtual agent, or reboot without approval and BitLocker recovery readiness. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm HP's signature and application version, perform only a local read-only device inventory, compare update, service, notification, and driver state against baseline, and ensure no diagnostic upload, firmware task, download, or restart is pending. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
