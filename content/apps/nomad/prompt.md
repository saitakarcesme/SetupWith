# Nomad setup prompt

Set up Nomad from its verified official source (https://github.com/hashicorp/nomad). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install HashiCorp's signed Nomad binary or package, determine whether this is CLI-only or an approved disposable dev agent, and keep server and client roles explicit.

Preserve Nomad data, agent configuration, job specifications, ACL bootstrap state, TLS material, namespaces, and service definitions. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: data_directory, datacenter, bind_address, http_port, deployment_mode. The only available credential references are secret://nomad/token. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not join a cluster, bootstrap ACLs, submit jobs, drain clients, start persistent agents, or expose RPC and HTTP ports without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `nomad version`; use no remote address, and only with approval start a short-lived loopback dev agent, inspect its status, then stop and remove its temporary data. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
