# Jujutsu setup prompt

Set up Jujutsu from its verified official source (https://github.com/jj-vcs/jj). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install a stable `jj` release from an official package or artifact and keep it independent from existing Git tooling and repositories.

Preserve Jujutsu configuration, Git configuration, repository metadata, colocated workspaces, operation logs, and user identity. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: git_name, git_email, default_branch, editor_command. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not initialize, colocate, migrate, clone, or rewrite any existing repository and do not set global identity without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `jj version`, inspect configuration sources, and create a disposable temporary repository for `jj status` without touching user worktrees. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
