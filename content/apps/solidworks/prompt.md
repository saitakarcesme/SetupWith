# SOLIDWORKS setup prompt

Set up SOLIDWORKS from its verified official source (https://www.solidworks.com/support/downloads). Supported targets: Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the SOLIDWORKS Downloads portal and Installation Manager for the entitled year and service pack, check certified graphics and Windows support, and choose an individual core installation. Exclude Electrical, PDM, SolidNetWork License Manager, SQL components, Visualize, CAM, and administrative images unless requested.

Preserve SLDPRT, SLDASM, and SLDDRW files, external references, design tables, Toolbox and Hole Wizard data, templates, sheet formats, weldment profiles, macros, journal and recovery files, user settings, add-ins, serial entitlements, network license configuration, and older releases. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: release, products, toolbox_location, license_type. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Stop before 3DEXPERIENCE or download-portal sign-in, entering a serial number, accepting license terms, upgrading Toolbox, modifying a shared installation, installing PDM or SQL services, changing a network-license server, importing settings, opening an assembly, rebuilding models, or restarting Windows. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the Installation Manager and SOLIDWORKS publisher signatures, launch without opening a document, and report exact year and service pack, license mode, graphics certification status, Toolbox path, and loaded add-ins. Rollback must preserve CAD files, shared Toolbox data, serial entitlements, settings, and prior releases. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
