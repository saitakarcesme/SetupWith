# Home Assistant setup prompt

Codex, inspect the OS, architecture, shell, existing Home Assistant installation, configuration directory, integrations, backups, database, USB devices, network discovery, and occupied port 8123. Prefer Home Assistant Container with the official image on a supported Docker host, or Home Assistant OS only when the user explicitly approves dedicating a machine or VM. Do not install Home Assistant Core into the system Python. Ask before administrator access, installing Docker, creating services, granting USB or host-network access, opening ports, changing firewall rules, launching a browser, or overwriting configuration. Preserve `configuration.yaml`, secrets files, automations, dashboards, add-ons, backups, and database data. Configure only `config_directory`, `server_port`, `timezone`, and `unit_system` when supplied. Use `secret://provider/HASS_TOKEN` only through protected runtime integration where needed; never print, echo, log, or commit it. Validate YAML with Home Assistant’s configuration check before restart. Verify image identity, persistent storage, startup logs, HTTP readiness, timezone and unit settings, and configuration validation without onboarding or discovering devices automatically. Rollback restores configuration, stops and removes only created containers, and preserves all data and backups unless deletion is approved. Finish with a structured summary of installation type, storage, networking, settings, verification, approvals, and rollback.
