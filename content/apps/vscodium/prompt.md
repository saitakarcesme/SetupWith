# VSCodium setup prompt

Set up VSCodium from its verified official source (https://github.com/VSCodium/vscodium). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Prefer the official VSCodium repository, signed package, or release artifact for the detected platform, and keep it separate from any existing Visual Studio Code profile unless the user asks to migrate.

Preserve existing VSCodium and VS Code user-data directories, extensions, keyboard shortcuts, settings, and workspace trust decisions. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: preferred_shell, editor_font_size, editor_theme, settings_sync. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not import profiles, enable Settings Sync, install extensions, or change the default editor without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Verify the installed binary with `codium --version`, launch one clean window, and confirm the expected user-data and extensions directories without opening an untrusted workspace. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
