# Paperless-ngx setup prompt

Codex, inspect the OS, architecture, shell, existing Paperless-ngx deployment, Docker availability, PostgreSQL or SQLite database, Redis, consume and media directories, OCR languages, and occupied ports. Prefer the official Paperless-ngx Docker Compose installation with persistent volumes. Ask before administrator access, installing or starting Docker, creating services, running migrations, exposing ports, changing firewall rules, opening a browser, importing documents, or overwriting compose and environment files. Preserve documents, originals, thumbnails, metadata, correspondents, tags, database volumes, and export backups. Configure only `consume_directory`, `media_root`, `server_port`, and `ocr_language` when supplied. Inject `secret://provider/PAPERLESS_SECRET_KEY`, `secret://provider/PAPERLESS_DBPASS`, and `secret://provider/PAPERLESS_ADMIN_PASSWORD` through protected environment or secret files; never print, echo, log, or commit values. Confirm OCR language packages before installation and ask before downloading additional language data. Verify container health, migration completion, consume-directory permissions, OCR capability, database connectivity, and the web login page. Process only a disposable sample document, never user files, during verification. Rollback restores manifests, removes only created containers, and retains documents and databases unless deletion is explicitly authorized. Finish with a structured summary of deployment, storage paths, OCR, port, verification, approvals, and rollback.
