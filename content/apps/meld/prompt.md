# Meld setup prompt

Set up Meld from the official GNOME project page (https://gnome.pages.gitlab.gnome.org/meld/). Detect Linux or Windows, architecture, desktop session, package managers, existing Meld version and preferences, supported version-control clients, and configured Git diff or merge tools. On Linux prefer the distribution package or verified Flathub release; on Windows use the official project installer. Explain that macOS is not officially supported and do not substitute semi-official or old third-party builds unless the user explicitly accepts that limitation.

Preserve Meld preferences, recent comparisons, text and folder filters, keyboard shortcuts, window state, version-control integration, Git configuration, working trees, indexes, conflict stages, untracked files, file permissions, encodings, line endings, symbolic links, and compared directories. Apply only the requested comparison mode, reviewed filters, or version-control integration. Back up any configuration before editing it, and never register Meld globally as a Git difftool or mergetool without showing the exact configuration keys and commands.

Meld can edit files and its comparison controls can replace, insert, copy, or delete content and directory entries. Open user data read-only for initial verification and use disposable copies for interaction tests. Before any merge action, identify source and destination panes, focused file, base version, unsaved state, encoding, line ending, permissions, and version-control status. Do not follow symlinks into unrelated paths, recurse through unapproved network mounts, overwrite binary files, save generated output, stage changes, resolve conflicts, commit, or push. Warn that text and folder filters can hide meaningful differences; test filter expressions against copies before enabling them.

Verify package provenance, Meld version, executable and preference paths, and integration commands. Compare two disposable text files containing public sample data, navigate differences without applying them, close without saving, and confirm hashes and metadata remain unchanged. For directory mode, scan only a setup-created directory and perform no copy or delete. Confirm Git configuration and repository status match their baseline and no recent item exposes a sensitive path. Roll back the installed package and setup-owned preferences only, restore prior Git configuration, and preserve every compared file, repository, filter, and user setting.
