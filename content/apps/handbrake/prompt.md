# HandBrake setup prompt

Set up HandBrake from its verified official source (https://github.com/HandBrake/HandBrake). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install the official stable HandBrake GUI and matching CLI where requested, verifying package signatures and avoiding third-party download sites.

Preserve custom presets, queue state, logs, preferences, destination defaults, source media, and any existing HandBrake installation. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: output_directory, default_preset, hardware_encoder, subtitle_preference. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not scan protected media, overwrite files, start encodes, enable hardware encoders, or change destination defaults without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `HandBrakeCLI --version` when installed and launch the GUI with no source; perform no media scan or transcode during setup verification. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
