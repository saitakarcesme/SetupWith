# Keras setup prompt

Set up Keras from its verified official source (https://github.com/keras-team/keras). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Create an isolated Python environment, choose one supported Keras backend explicitly, and install mutually compatible stable versions rather than every accelerator stack.

Preserve Python environments, dependency locks, Keras configuration, model files, caches, and existing backend installations. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: python_version, virtual_environment, compute_backend, float_precision. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not switch a project's backend, replace GPU drivers, download model weights, or load serialized models without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Import Keras, report its version and active backend, then build and run a tiny untrained in-memory model without saving artifacts or fetching data. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
