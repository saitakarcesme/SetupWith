# OWASP ZAP setup prompt

Set up OWASP ZAP from its verified official source (https://github.com/zaproxy/zaproxy). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install the official stable ZAP package, cross-platform archive, or container with a supported Java runtime and a dedicated user-owned workspace.

Preserve ZAP sessions, contexts, scripts, add-ons, certificates, browser profiles, API settings, scan policies, and reports. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: java_home, workspace_directory, proxy_address, proxy_port, browser_profile. The only available credential references are secret://zap/api-key. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not proxy browser traffic, generate or trust a root certificate, install add-ons, spider or scan any target, expose the API, or alter proxy settings without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run the version command and launch in safe mode with no session or target; confirm the UI opens, then close without sending network requests. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
