# Hydrogen setup prompt

Set up Hydrogen from its official release repository and manual (https://hydrogen-music.org/documentation/manual/manual_en.html). Detect Windows, macOS, or Linux, architecture, package managers, existing Hydrogen installation, audio servers and devices, JACK state and graph, MIDI ports, OSC listeners, NSM or JACK sessions, configuration and user-data paths, songs, patterns, playlists, samples, drumkits and export folders. Install the current stable signed package or checksummed official release. Do not build the main branch, add an audio server, change drivers, or install optional codecs automatically.

Install without launching the graphical application or loading a song, playlist or kit. Preserve every `.h2song`, `.h2pattern`, `.h2playlist` and `.h2drumkit`, external sample, custom instrument, automation curve, tempo map, mixer state, session folder, linked kit, preference, recent file, export, MIDI map and audio connection. Do not create or migrate user data, replace the last-loaded kit, scan sound libraries, contact the online kit list, or write a default configuration during setup.

Hydrogen's automatic audio mode can open a device, and selecting JACK may start the JACK server and connect stereo or per-instrument ports. Do not start or stop audio services, seize ALSA/OSS devices, change sample rate or buffer size, connect JACK ports, enable transport or timebase, open MIDI input/output, send feedback, bind controls, or expose an OSC port without showing the exact device and graph diff and obtaining approval. Treat downloaded drumkits and their samples as untrusted content; show source, license, hashes, extracted paths and overwrite behavior before installation. Never overwrite a song, replace or delete a kit, relocate samples, repair session links, or assume a broken link is unused.

Export can create a stereo mix, individual instrument tracks, MIDI or LilyPond files and may overwrite destinations. Require an explicit range, format, sample rate, depth, compression, destination and collision report before any later export. Verify publisher or package provenance, checksum, `hydrogen --version`, executable, method, library paths and data locations using CLI flags that do not start audio, MIDI, OSC, JACK or the GUI. Confirm no process, port, device, connection, song, kit, sample, session, config, cache or output changed. Roll back only the installed application and setup-owned shortcuts while preserving all creative assets and audio infrastructure.
