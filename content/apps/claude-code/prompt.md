# Claude Code setup prompt

Set up Claude Code from its verified official source (https://docs.anthropic.com/en/docs/claude-code/getting-started). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use Anthropic's documented native or package installation method appropriate to the operating system, avoid `sudo` for package installation, and record the selected update channel.

Preserve Preserve `.claude` settings, project instructions, hooks, MCP servers, authentication data, cached sessions, custom commands, and any existing package-manager or native-binary installation.. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: permission_mode, preferred_model, auto_updates, allowed_tools. The only available credential references are secret://anthropic/api-key. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Stop before authentication, API-key configuration, automatic migration, hook activation, MCP registration, repository access, or broad tool allowlists; never enable permission bypass flags. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `claude --version` and `claude doctor` without entering a project, confirm the installer type and executable path, and ensure no repository files or permissions were changed. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
