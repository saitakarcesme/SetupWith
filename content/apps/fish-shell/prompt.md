# fish setup prompt

Set up fish from its verified official source (https://github.com/fish-shell/fish-shell). Supported targets: macOS, Linux. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the official fish package channel for the detected Unix-like environment and confirm the installed version is supported by any existing shell framework.

Preserve fish configuration, functions, completions, universal variables, abbreviations, history, and the current login shell. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: shell_prompt, config_directory, environment_variables, default_shell. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not source unknown scripts, import environment variables, install plug-ins, or run `chsh` without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `fish --version` and start `fish --no-config` for a clean interactive smoke test; inspect rather than execute the user's existing configuration. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
