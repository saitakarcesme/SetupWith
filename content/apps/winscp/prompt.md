# WinSCP setup prompt

Set up WinSCP from its verified official source (https://winscp.net/downloads.php). Supported targets: Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the stable WinSCP installer or portable package from the official downloads page and verify the documented Martin Prikryl digital signature. Preserve the current installation style and choose per-user installation unless an all-users deployment is explicitly requested.

Preserve stored sites, master-password protection, SSH host-key cache, PuTTY and Pageant integration, transfer queues, workspace tabs, synchronized-directory settings, scripts, registry or INI configuration mode, and portable data. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: interface_style, configuration_storage, default_local_directory, keepalive_interval. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Stop before importing PuTTY sites, saving credentials, accepting an SSH fingerprint or TLS certificate, starting a remote session, synchronizing directories, editing or deleting remote files, registering URL handlers, adding Explorer integration, or restarting Explorer or Windows. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Check the installer signature, run `winscp.exe /version` or inspect About, and open only the Login dialog with no session selected. Confirm no remote connection or synchronization began and no shell restart occurred; rollback must restore the prior registry or INI configuration mode. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
