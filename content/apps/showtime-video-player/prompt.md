# Video Player setup prompt

Set up GNOME Video Player (app ID `org.gnome.Showtime`) from its official GNOME source and Flathub listing (https://apps.gnome.org/Showtime/). Inventory Linux architecture, Flatpak scopes, any existing ref, application-data ownership, recent-item and resume-position counts, file-portal grants, media plugin classes, hardware-decoder availability, subtitle settings, screenshot destination grant, audio mute and route, sandbox overrides and backup coverage without exposing filenames, paths, titles, frames, subtitles or viewing history. Install the stable Flathub ref in the existing scope. Do not compile, launch the player, open or probe a video, load subtitles, play audio, enter fullscreen, change speed or tracks, capture a frame, open a portal or create a file during setup.

Preserve recents, resume positions, playback speed, preferred audio and subtitle choices, window/fullscreen state, screenshot preferences, portal grants, volume, mute, routing, permissions, remotes, overrides and scope ownership. Private films, screen recordings and subtitle text must not appear in logs, thumbnails or diagnostics. Do not crawl media folders or contact online subtitle and metadata services.

Treat containers, codecs, attachments and subtitle files as untrusted structured input. Before later playback, confirm the exact selected file, size, checksum, symlink resolution, read-only intent, codec/plugin plan and resource limits. Review every audio track and subtitle source by language, commentary status, encoding and timing; external subtitles must not escape their approved path or execute markup. Confirm the fullscreen monitor and screen-sharing state before hiding controls. Start audio on an approved sink at low volume.

A screenshot is a separate write action: preview the exact frame, confirm rights and privacy, output format, destination, canonical filename, collision policy and metadata before an atomic write. Verify GNOME provenance, app ID, manifest, commit, runtime, executable, plugins, files, checksum and permissions offline. Prove no media probe, playback, subtitle load, audio route, fullscreen transition, screenshot, file write, network or preference change occurred. On failure, rollback only the new Video Player ref; preserve shared runtimes, plugins, recents, positions, tracks, subtitles, audio state, portals and backups.
