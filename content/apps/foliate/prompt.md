# Foliate setup prompt

Set up Foliate from its official project and verified Flathub listing (https://johnfactotum.github.io/foliate/). Detect Linux architecture, desktop environment, package managers, existing distro or Flatpak installation, book library, application data, reading-progress JSON, annotations, bookmarks, OPDS catalogs, offline dictionaries, Speech Dispatcher, voices, audio output and file associations. Install one current stable verified Flatpak or reviewed distribution package matching the existing ownership model. Do not build the GTK branch, install optional speech engines or dictionaries, add remotes, broaden sandbox access, or switch packaging methods without approval.

Install without launching Foliate, scanning a folder, opening a publication or claiming EPUB, MOBI, AZW3, FB2, CBZ or PDF associations. Preserve every ebook, cover, metadata item, library entry, reading position, navigation history, bookmark, annotation, tag, plain JSON sidecar, OPDS credential, catalog, downloaded title, dictionary and preference. Reading data can reveal interests, research, beliefs and highlighted passages; never display it in diagnostics, upload it, or place an annotation export into a synced folder without consent.

Treat ebook HTML, CSS, fonts, images, links and media as untrusted publication content rendered through WebKit. Keep network access off, do not follow external links, execute downloads, expose local file paths, copy selections, or open an experimental PDF for verification. Never remove DRM, bypass access controls, modify a purchased book, or infer permission to redistribute it. Before any OPDS use, show the catalog URL, TLS status, authentication, requested feed, acquisition type, license, destination and expected network requests.

Online dictionary, Wikipedia and translation actions can transmit selected text and surrounding language context. Use offline dictionaries by default and require endpoint approval before lookup. Narration may spawn Speech Dispatcher, select a voice, open an audio device or play embedded media overlays; do not start services, install voices or produce audio during setup. Verify Flathub or package provenance, version, app ID, installed commit, runtime, declared permissions, executable and data paths from metadata without running the reader. Confirm no book, progress, annotation, JSON, catalog, credential, network, audio, clipboard, handler or sandbox state changed. Roll back only the installed package and setup-owned launcher.
