# Tableau Desktop setup prompt

Set up Tableau Desktop from its verified official source (https://www.tableau.com/support/releases/desktop). Supported targets: macOS, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Select the exact supported Tableau Desktop release from Tableau's official releases page, verify its signature, and install the authoring application without activating a license, adding database drivers, migrating repositories, or enabling usage reporting.

Preserve existing workbooks, packaged workbooks, extracts, data sources, Tableau Repository, preferences, custom geocoding, connector drivers, licenses, saved server sessions, credentials, extensions, and AutoSave or recovery content. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: product_release, repository_location, extract_storage, usage_reporting. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Stop before license activation, Tableau Cloud or Server sign-in, production data connection, saved credential access, extract refresh, workbook migration, extension installation, telemetry, publish, overwrite, or repository upgrade without backups and approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm Tableau's signature, product version, repository and log paths, launch to the activation or start screen without connecting data, and ensure no workbook, extract, server session, license, repository, or production source changed. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
