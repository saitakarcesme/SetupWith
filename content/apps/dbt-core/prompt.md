# dbt Core setup prompt

Set up dbt Core from its verified official source (https://github.com/dbt-labs/dbt-core). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install dbt Core and exactly one approved warehouse adapter in an isolated environment, pinning compatible versions and honoring any existing project lock or package file.

Preserve `profiles.yml`, dbt projects, packages, manifests, target artifacts, logs, macros, and warehouse credentials. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: python_version, virtual_environment, dbt_profiles_directory, warehouse_adapter, target_name. The only available credential references are secret://dbt/database-password. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not connect to a warehouse, run models, modify profiles, fetch packages, or print compiled SQL containing sensitive values without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `dbt --version` and parse the selected project offline where possible; use `dbt debug` only after the target and network connection are explicitly approved. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
