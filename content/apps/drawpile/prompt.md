# Drawpile setup prompt

Set up Drawpile from its official downloads page (https://drawpile.net/download/). Detect Windows, macOS, or Linux, architecture, package managers, existing installed or portable client, browser version, protocol handler, configuration, canvases, projects, autorecovery, recordings, brushes, tablet settings, accounts, server list, session presets and dedicated-server binaries. Install only the current stable official desktop client or verified distribution package. Do not select alpha, beta, portable side-by-side or browser builds, install a server, or register invite-link handlers without approval.

Install without opening a canvas, joining or hosting a session, logging in, accepting community-server rules, or contacting session listings. Preserve every local drawing, layer, animation, project, brush, palette, recording, timelapse, chat log, autorecovery command stream, snapshot, role preset, ban export, account token, server bookmark, content filter, tablet map and preference. Never upload an existing canvas to demonstrate collaboration and never treat an autorecovery or recording as expendable cache.

A session transmits drawing actions, canvas contents, participant identities and chat to a server and peers. Before any later connection, show the exact TLS URL, operator, server ownership, authentication method, retention and content rules. Keep sessions password-protected by default and never publish them, share invite or operator passwords, weaken layer ACLs, grant Trusted or Operator roles, reveal censored layers, kick or ban users, import role or ban files, force undo another artist, lock or reset a canvas without explicit approval. Ban exports may contain IP addresses and use a server-specific encryption key.

Do not start the built-in or dedicated server, listen on TCP 27750, edit a firewall, configure UPnP or router port forwarding, announce a session, expose a residential IP, create external-auth keys, or enable server-wide recordings. Session recordings and timelapses can retain the complete creative process and participant activity; require a retention path and consent before capture. Verify publisher or package provenance, checksum where available, client version, executable, method, protocol-handler baseline and data paths with offline CLI or package metadata. Confirm no network request, listener, session, account, drawing, recovery, recording, role, ban, handler, tablet or firewall state changed. Roll back only the installed client and setup-owned shortcuts.
