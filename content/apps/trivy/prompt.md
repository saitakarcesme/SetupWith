# Trivy setup prompt

Codex, inspect the OS, architecture, shell, existing `trivy` binary, package source, cache, configuration, ignore files, container runtime, and CI-related settings before installation. On macOS prefer Homebrew `trivy`; on Linux use Aqua Security’s official signed repository or verified release package; on Windows prefer `winget install AquaSecurity.Trivy`. Ask before administrator access, adding repositories, downloading vulnerability databases, scanning private directories, accessing container sockets, modifying ignore files, or uploading results. Preserve existing `trivy.yaml`, `.trivyignore`, caches, policies, and CI configuration. Configure only `cache_directory`, `severity_threshold`, `ignore_unfixed`, and `output_format` when supplied. Reference `secret://provider/GITHUB_TOKEN` only through secure environment injection for approved GitHub rate-limit or repository access; never print, echo, log, or commit it. Verify `trivy --version`, configuration parsing, database metadata, and a scan of a disposable local filesystem or a small approved public image. Do not scan the user’s home directory or private repositories automatically. Rollback restores config backups, removes only downloaded test artifacts and the installed package, and retains caches unless deletion is approved. Finish with a structured summary of install source, database status, scan target, policies, findings count, approvals, and rollback.
