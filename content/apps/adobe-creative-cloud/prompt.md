# Adobe Creative Cloud setup prompt

Set up Adobe Creative Cloud from its verified official source (https://www.adobe.com/creativecloud/desktop-app.html). Supported targets: macOS, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download Adobe's signed Creative Cloud desktop installer for the supported OS and architecture, note that the manager uses Adobe background components and a fixed application location, and install only the manager. Do not select trials or queue Photoshop, fonts, plug-ins, or any other app.

Preserve installed Adobe application versions, Creative Cloud preferences, entitlement and activation state, Libraries and synced files, Adobe Fonts choices, plug-ins, presets, color profiles, project assets, update policy, install language, and enterprise package management. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: app_install_location, default_language, auto_update, launch_at_login. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Stop before Adobe account or enterprise SSO sign-in, MFA, starting a trial or paid plan, accepting a subscription obligation, installing or removing an app, enabling Fonts or Libraries sync, changing auto-update, uninstalling old versions, adding plug-ins, or enabling launch at login. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Verify Adobe's signature and Creative Cloud desktop build, inventory Adobe background processes and login items, and open only to the sign-in screen. Confirm no creative application, font, library, plug-in, trial, update, or cloud synchronization was queued; rollback must respect Adobe's dependency-aware uninstaller. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
