# Neo4j setup prompt

Set up Neo4j from its verified official source (https://github.com/neo4j/neo4j). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use Neo4j Desktop for an approved local graphical workflow or the official Community Server package or container, checking Java and major-version compatibility first.

Preserve graph databases, transaction logs, configuration, plug-ins, import files, certificates, authentication data, and backups. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: java_home, data_directory, listen_address, bolt_port, http_port. The only available credential references are secret://neo4j/password. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not upgrade a store, reset credentials, install plug-ins, import graphs, expose Bolt or HTTP ports, or start a persistent service without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run the version command; only with a fresh temporary database start loopback listeners, query `RETURN 1`, and stop cleanly without touching existing stores. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
