# Parallels Desktop setup prompt

Set up Parallels Desktop from its verified official source (https://www.parallels.com/products/desktop/download/). Supported targets: macOS. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the signed Parallels Desktop trial or entitled installer for the Mac's Intel or Apple silicon architecture and verify the supported macOS release. Install the hypervisor application only; do not download Windows, migrate a PC, import Boot Camp, or create a guest.

Preserve all `.pvm` bundles, snapshots, suspend states, virtual disks, Windows activation state, license and account metadata, custom networks, resource allocations, shared-folder mappings, Coherence preferences, and Parallels Tools versions. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: vm_directory, resource_profile, shared_folders, coherence_mode. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Stop before Parallels account sign-in, trial or subscription activation, Windows license purchase, OS download, VM import or creation, shared Mac profile and folder access, camera or microphone sharing, network extension approval, privileged helper changes, Tools installation, or host restart. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Check the Parallels signature and build, inspect privileged helpers, system or network extensions, and the configured VM directory, then launch Control Center without starting or registering a guest. Confirm no OS image downloaded and provide rollback that leaves every PVM, snapshot, and activation record intact. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
