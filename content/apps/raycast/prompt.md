# Raycast setup prompt

Set up Raycast from its verified official source (https://www.raycast.com/download). Supported targets: macOS, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Download Raycast's signed macOS release or official Windows beta for the detected platform, disclose the Windows beta status, and install the core launcher without enabling cloud sync, AI, community extensions, or login startup.

Preserve existing Raycast preferences, commands, snippets, quicklinks, clipboard history, extension data, custom scripts, themes, account state, AI settings, global hotkeys, and macOS or Windows accessibility permissions. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: global_hotkey, clipboard_history, extension_allowlist, launch_at_login. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not grant Accessibility, Input Monitoring, microphone, contacts, calendar, file indexing, or clipboard permissions; install extensions, send clipboard data to AI, enable cloud sync, or create login persistence without separate consent. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the signed application and platform-specific version, open the launcher with an approved non-conflicting hotkey, run only its local calculator, and verify sync, AI, third-party extensions, clipboard history, permissions, and startup remain disabled. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
