# Consul setup prompt

Set up Consul from its verified official source (https://github.com/hashicorp/consul). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Install HashiCorp's signed Consul package or binary and distinguish a CLI-only setup from an approved disposable development agent before writing configuration.

Preserve Consul data, agent configuration, ACL state, gossip encryption keys, TLS certificates, service definitions, and cluster membership. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: data_directory, datacenter, bind_address, http_port, deployment_mode. The only available credential references are secret://consul/http-token. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not join a datacenter, bootstrap ACLs, register services, modify KV data, start persistent agents, or expose ports without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `consul version` and configuration validation; only when approved start a loopback dev agent with temporary data, query its local leader state, and stop it. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
