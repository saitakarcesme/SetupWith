# vLLM setup prompt

Set up vLLM from its verified official source (https://github.com/vllm-project/vllm). Supported targets: Linux. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Confirm supported Linux hardware, drivers, Python, and accelerator libraries before installing the matching stable vLLM wheel in a dedicated environment; prefer containers only when requested.

Preserve Python environments, model caches, serving configuration, container volumes, GPU drivers, and existing inference services. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: python_version, virtual_environment, compute_backend, model_cache_directory, listen_address, listen_port. The only available credential references are secret://hf/token. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not download gated models, expose an API port, start a persistent server, replace accelerator drivers, or enable remote code without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Import `vllm`, report its version and detected device, and stop there unless the user approves downloading a small model and running a loopback-only smoke test. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
