# PowerShell setup prompt

Set up PowerShell from its verified official source (https://github.com/PowerShell/PowerShell). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use Microsoft's official stable package or repository for PowerShell 7, keeping Windows PowerShell 5.1 side by side and avoiding preview channels unless requested.

Preserve all PowerShell profiles, installed modules, PSReadLine history, remoting configuration, execution policy, and Windows PowerShell. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: execution_policy, profile_path, module_path, default_shell. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not weaken execution policy, trust repositories, install modules, enable remoting, or change the default shell without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `pwsh -NoProfile -Command '$PSVersionTable'`, confirm the executable path and edition, and perform no profile loading or remote connection. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
