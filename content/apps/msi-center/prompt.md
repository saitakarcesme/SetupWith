# MSI Center setup prompt

Set up MSI Center from its verified official source (https://www.msi.com/Landing/MSI-Center). Supported targets: Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Verify the MSI system or motherboard model and supported MSI Center generation, install only the signed base application, and present each optional feature module, hardware service, driver, SDK, and restart separately before selection.

Preserve existing BIOS and firmware, fan curves, User Scenario settings, Mystic Light profiles, monitoring history, installed feature modules, driver versions, MSI SDK services, overclock settings, and legacy Dragon Center data. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: feature_modules, user_scenario, mystic_light, update_policy. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Do not flash BIOS or firmware, add drivers or modules, alter clocks, voltage, fan curves, battery modes, lighting, telemetry, startup services, or account state without explicit hardware-specific approval and recovery instructions. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm MSI signatures and base-app version, perform a read-only hardware inventory, compare temperature, clock, cooling, lighting, module, and driver state to baseline, and ensure no firmware, Live Update, or restart action is pending. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
