# Emacs setup prompt

Codex, first inspect the OS, architecture, shell, graphical session, existing Emacs binaries, package-manager source, and user configuration such as `~/.emacs`, `~/.emacs.d`, or `~/.config/emacs`. On macOS prefer a maintained Homebrew Emacs package or the official GNU build appropriate to the user’s existing channel; on Debian/Ubuntu use `apt install emacs`; on Fedora-family systems use `dnf install emacs`; on Windows prefer `winget install GNU.Emacs`. Ask before administrator access, changing the active Emacs distribution, installing fonts, or replacing file associations. Preserve all init files, package archives, lockfiles, custom variables, and server configuration. Configure only `editor_theme`, `preferred_shell`, and `font_size` when supplied. Add an isolated, clearly marked SetupWith Lisp block or separate file loaded from the existing init, avoiding duplicate `custom-set-variables` sections. Do not refresh package archives or install themes without approval. Verify with `emacs --version`, a batch-mode load of the user configuration, and `emacs --batch --eval` checks for the requested shell and font settings where applicable. Launching the GUI requires approval in remote environments. Rollback should remove the added block or file, restore backups, and uninstall only the installed package. Finish with a structured summary of detected init path, installation method, configuration edits, batch results, approvals, and rollback.
