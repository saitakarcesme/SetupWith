# Curtail setup prompt

Set up Curtail from its official repository and verified Flathub listing (https://github.com/Huluti/Curtail). Inventory Linux architecture, Flatpak scopes, existing Curtail package, compressor preferences, lossless/lossy quality, safe or overwrite mode, recursive setting, metadata policy, output prefix/suffix, open-with integration and portal grants without selecting or reading images. Install stable `com.github.huluti.Curtail` from verified Flathub in the existing ownership scope. Do not compile from source, launch Curtail, activate its D-Bus service, claim handlers or compress a sample file during setup.

Preserve every image and SVG byte-for-byte with filename, permissions, ownership, timestamps, hard links, symlinks, sidecars and directory structure. Do not enumerate a photo library, recurse into folders, cross mount boundaries, hydrate cloud placeholders, render previews or open the output folder. Filenames are data, not shell commands; never interpolate paths containing metacharacters into a shell. Treat malformed PNG/JPEG/WebP/SVG input and external SVG references as untrusted parser content.

Lossless means preserving decoded image content, not necessarily identical bytes or metadata. Lossy output deliberately changes pixels. EXIF, GPS, XMP, ICC profiles, orientation, copyright and embedded thumbnails each have privacy and fidelity consequences whether kept or stripped. Before future compression show exact source/destination, encoder and version, mode, quality, expected metadata fields, color-profile handling, size estimate and visual acceptance method. Never remove an ICC profile or orientation silently, and never claim privacy merely because common EXIF tags were removed.

Keep safe mode and non-recursive operation unless explicitly approved. Overwrite requires a verified independent backup, atomic replacement plan and restoration test; a generated output file is not a backup. Resolve prefix/suffix collisions and reject existing destinations before processing. If output is larger, preserve the original and do not replace it. Verify Curtail source, app ID, origin, commit, runtime, executable, bundled encoders, files and permissions offline. Prove no source read, output, metadata change, recursive scan, portal, handler, preview, D-Bus activation or process occurred. On failure, rollback only the new Curtail ref in its original scope; preserve shared runtimes, remotes, overrides, images and compression preferences.
