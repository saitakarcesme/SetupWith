# Apache Airflow setup prompt

Set up Apache Airflow from its verified official source (https://github.com/apache/airflow). Supported targets: macOS, Linux. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Create a dedicated Python environment and install a pinned Airflow release with the matching official constraints file; select LocalExecutor or SequentialExecutor only after reviewing database requirements.

Preserve DAGs, plug-ins, logs, `airflow.cfg`, metadata databases, connections, variables, and encryption keys. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: python_version, airflow_home, executor, listen_address, listen_port. The only available credential references are secret://airflow/fernet-key, secret://airflow/database-url. Treat every reference as opaque: never print, echo, log, resolve, or paste its value.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not initialize or migrate an existing metadata database, create admin users, run DAGs, start persistent services, or expose the webserver without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `airflow version` and `airflow config list` with secrets redacted; use `airflow db check` only against an explicitly approved test database. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
