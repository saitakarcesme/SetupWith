# Fretboard setup prompt

Set up Fretboard from its official GitHub repository and verified Flathub listing (https://apps.gnome.org/Fretboard/). Inventory Linux architecture, Flatpak scopes, an existing `dev.bragefuglseth.Fretboard` ref, application-data ownership, bookmark and settings counts, locale, notation preference, display scale, sandbox overrides and backup coverage without revealing saved chord names, fret positions or practice material. Install the stable verified Flathub ref in the existing ownership scope. Do not compile from source, launch Fretboard, query a chord, plot notes, change a voicing, create a bookmark, reset settings or inspect bookmark contents during setup.

Preserve every saved chord, bookmark order, last-view state, accidental spelling, notation preference, window state, permission, remote, override and scope owner. Fretboard is a local chord reference: it does not need a microphone, audio capture, MIDI access, an instrument connection, an account or network access after installation. Do not grant those capabilities or infer a user’s songs from bookmark names.

Before a later lookup, confirm standard guitar tuning, string and fret assumptions, handedness, capo position, root spelling, chord quality, extensions, inversion and slash bass. Treat plotted notes as intentional input and show the resulting symbol plus alternative interpretations before saving. A mathematically valid voicing may still be physically unsuitable; label muted/open strings and barres, present alternatives, and leave ergonomic or teaching judgments to the musician. Test only with an agreed public example such as an unsaved C-major chord.

Verify the repository owner, app ID, Flathub verification, manifest source, commit, runtime, executable, files, checksum and declared permissions offline. Confirm no chord query, fret input, bookmark write, microphone request, audio session, network connection or settings mutation occurred. If installation fails, rollback only the newly installed Fretboard ref in its original scope; preserve shared runtimes, remotes, overrides, bookmarks, settings and backups.
