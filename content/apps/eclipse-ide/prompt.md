# Eclipse IDE setup prompt

Set up Eclipse IDE from its verified official source (https://github.com/eclipse-platform/eclipse.platform). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the official Eclipse Installer or a verified package matching the machine architecture, and choose only the requested IDE package with a supported JDK.

Preserve existing Eclipse installations, workspaces, `.metadata`, preferences, plug-ins, secure storage, and project files. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: jdk_path, workspace_directory, editor_theme, installed_plugins. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not reuse, migrate, or index an existing workspace and do not install marketplace plug-ins without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Start Eclipse with a new empty temporary workspace, confirm the IDE and Java runtime versions, then close it without importing projects or altering the user's default workspace. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
