# Sweet Home 3D setup prompt

Set up the free desktop edition of Sweet Home 3D from its official download page (https://www.sweethome3d.com/download/) and primary SourceForge distribution. Detect Windows, macOS, or Linux, architecture, package managers, Java runtime, existing installer, store, portable JAR or Web Start edition, application data, recent homes, recovery files, furniture and texture libraries, plugins, rendering codecs and print settings. Install one current stable official free package matching the existing ownership model. Do not switch to a paid store edition, online version, Web Start, unverified mirror, or separate JAR runtime without approval.

Install without opening or creating a home and without associating `.sh3d`, `.sh3f`, `.sh3t` or `.sh3p` files. Preserve every home plan, floor, wall, room, dimension, label, imported model, texture, image, furniture item, light, camera, viewpoint, photo, video, recovery file, backup, recent path, preference, library and plugin. Floor plans can reveal addresses, room layouts, security details and precise dimensions; never upload, preview in an online service, include in diagnostics or use a real home for verification.

Treat SH3P plugins as arbitrary Java code loaded inside the application. Do not install, update or execute a plugin. Before importing SH3F furniture, SH3T textures, OBJ/DAE/3DS models or images, show provenance, license, attribution, hashes, archive contents, scale, units, texture paths and catalog changes. Never overwrite an identically named library, silently rescale a model, fetch remote assets, or assume a free download permits redistribution. Keep existing Java and native rendering libraries untouched.

Photo, panorama and video rendering can consume substantial CPU, GPU, memory and disk and may invoke codecs. OBJ, SVG, PDF, CSV, image, clipboard and print exports can expose the complete design and overwrite files. Require exact resolution, quality, camera path, output list, renderer, codec, resource limit, destination and collision report before any later render or export. Verify publisher or SourceForge provenance, checksum when published, package version, executable, bundled Java/runtime ownership, library paths and data locations from package metadata without a normal launch. Confirm no plan, recovery, library, plugin, association, render, export, clipboard, print job, process or network state changed. Roll back only the installed application and setup-owned shortcuts.
