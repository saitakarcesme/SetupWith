# uv setup prompt

Codex, first inspect the OS, architecture, shell, PATH, existing `uv` binary, Python installations, project files, and any package-index configuration. On macOS prefer Homebrew `uv` when Homebrew manages developer tools, otherwise Astral’s official installer; on Linux use the official installer or trusted distribution package; on Windows prefer `winget install astral-sh.uv`. Ask before administrator access, executing a downloaded installer, editing PATH, changing Python selections, or modifying project lockfiles. Preserve `uv.toml`, `pyproject.toml`, `uv.lock`, pip configuration, caches, and virtual environments. Configure only `python_version`, `package_index`, and `cache_dir` when supplied. Use `uv python pin` only in a user-approved project; otherwise set user-level preferences without creating files in repositories. If authenticated index access is required, reference `secret://provider/UV_INDEX_TOKEN` through a non-printing environment or credential mechanism, never echoing, logging, or committing it. Verify with `uv --version`, `uv self version`, `uv python list`, and a disposable temporary project using `uv venv` plus a standard-library Python command. Avoid resolving or changing an existing lockfile. Rollback restores config and profile backups, removes the installed uv package or binary, and keeps caches unless deletion is approved. Finish with a structured summary of installation, Python selection, index and cache settings, verification, approvals, and rollback.
