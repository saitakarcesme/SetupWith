# Nix setup prompt

Codex, begin by inspecting the OS, architecture, shell, existing Nix installation, daemon state, profiles, channels or flakes, and `/nix` ownership. Support macOS and Linux only; do not invent a native Windows setup. Prefer the official Nix installer and determine whether single-user or multi-user mode fits the platform. Ask before administrator access, creating or modifying `/nix`, installing or changing the Nix daemon, editing shell profiles, enabling experimental features, or adding trusted users. Preserve `/etc/nix/nix.conf`, user profiles, channels, flake registries, and existing store data. Configure only `nix_channel`, `experimental_features`, and `trusted_users` when supplied. Merge settings carefully, deduplicate values, and never broaden trusted users without explicit approval. If flakes are requested, enable only the necessary supported feature flags. Verify with `nix --version`, `nix show-config`, `nix-store --verify --check-contents` only if reasonable, and a harmless evaluation or temporary shell such as `nix-shell -p hello --run hello` after explaining any download. Check daemon health where applicable without restarting it unless approved. Rollback should restore configuration backups and remove profile hooks; uninstalling Nix or deleting `/nix` requires separate destructive confirmation. Finish with a structured summary of install mode, daemon status, config changes, verification, approvals, and rollback boundaries.
