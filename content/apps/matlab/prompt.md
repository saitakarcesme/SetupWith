# MATLAB setup prompt

Set up MATLAB from its verified official source (https://www.mathworks.com/downloads/). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the MathWorks Downloads page to select an entitled MATLAB release for the exact Windows, Linux, Intel Mac, or Apple silicon architecture. Show disk estimates per product, install MATLAB alone by default, and do not add Simulink, toolboxes, documentation, support packages, or hardware drivers implicitly.

Preserve existing MATLAB releases, `startup.m`, path definitions, preferences, add-ons, projects, scripts, Live Scripts, data files, toolbox installations, compiler and runtime versions, license files, network-license settings, support packages, and generated code. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: release, installation_folder, selected_toolboxes, license_mode. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Treat drivers, kernel components, anti-cheat, background services, overlays, firewall changes, startup items, and restarts as separate approval checkpoints. Explain the exact component, vendor, privileges, persistence, and rollback before continuing. Stop before MathWorks sign-in, linking or activating a license, choosing a network-license server, installing toolboxes or support packages, downloading large documentation sets, adding hardware drivers, editing the MATLAB path, running startup code, opening a project, or executing user scripts. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run MATLAB with `-batch` only for a version and license-status-safe query that executes no startup or project code, or launch to a clean desktop with startup processing disabled. Report release, architecture, Java runtime, toolbox inventory names only, and installation path; rollback preserves releases, licenses, paths, and user code. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
