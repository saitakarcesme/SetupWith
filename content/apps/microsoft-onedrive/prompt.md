# Microsoft OneDrive setup prompt

Set up Microsoft OneDrive from its verified official source (https://www.microsoft.com/en-us/microsoft-365/onedrive/download). Supported targets: macOS, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use Microsoft's signed OneDrive channel for the detected platform. On Windows, first determine whether the inbox client is already healthy; on macOS, preserve the existing standalone or Mac App Store update channel rather than installing a second copy.

Preserve the current OneDrive root, personal and work tenant associations, Files On-Demand hydration state, Known Folder Backup choices, sync exclusions, sharing metadata, and every unsynced or conflicted local file. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: sync_root, files_on_demand, known_folder_backup, launch_on_startup. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations. Browser Use and Computer Use may open the official page, download the approved signed installer, complete the visible installer flow, verify the publisher or code signature, and launch the product once. Stop and hand control to the user before account creation, sign-in, password entry, MFA, CAPTCHA, age verification, purchases, subscriptions, license acceptance that creates a paid obligation, or linking external accounts. Never bypass DRM, regional restrictions, or platform protections. Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Stop before Microsoft sign-in, MFA, tenant selection, moving the sync root, enabling Desktop, Documents, or Pictures backup, hydrating placeholders, propagating deletions, creating shares, or enabling startup. Never use a personal file as a sync test. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm the Microsoft signature, installed version, process location, and expected sync-root path, then open only to the signed-out or paused state. Verify that no placeholder was downloaded and no file was uploaded; rollback must leave the existing root and unsynced content intact. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
