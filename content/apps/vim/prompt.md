# Vim setup prompt

Set up Vim from its verified official source (https://github.com/vim/vim). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Prefer the operating system's trusted package channel or an official Vim release, and do not replace the system-provided `vi` or change alternatives automatically.

Preserve `.vimrc`, `.vim`, vimfiles, plug-in lock state, swap and undo directories, and system editor alternatives. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: preferred_shell, editor_theme, tab_width, config_directory. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not install plug-in managers, download plug-ins, change `$EDITOR`, or edit system-wide Vim configuration without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `vim --version`, confirm the binary path and required features, then use a disposable file for a noninteractive read/write check without loading untrusted project configuration. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
