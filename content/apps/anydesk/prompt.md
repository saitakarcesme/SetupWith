# AnyDesk setup prompt

Set up AnyDesk from its verified official source (https://anydesk.com/en/downloads). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use the official AnyDesk package for the exact platform and decide explicitly between portable execution and a persistent installation. Do not silently install the system service, custom client build, network appliance, or organization policy package when the user only requested an attended client.

Preserve the existing AnyDesk address, known-clients history, address books, aliases, access-control lists, permission profiles, unattended-access configuration, local trace files, custom branding, and service or startup state. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: install_mode, unattended_access, access_control_list, launch_on_startup. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Stop before connecting to an address, accepting an incoming request, revealing the local address, setting an unattended password, adding trusted devices, enabling clipboard or file transfer, recording a session, granting accessibility or screen capture, or installing the background service. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Check AnyDesk's digital signature and reported version, distinguish portable from installed mode, and inspect service and startup entries. Open only to an idle local screen with networking disconnected when practical; verify no session, permission grant, password, alias, or persistent service was created. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
