# Collision setup prompt

Set up Collision from its canonical Codeberg project and verified Flathub listing (https://codeberg.org/GeopJr/Collision). Inventory Linux architecture, Flatpak scopes, existing Collision package and preferences, enabled algorithms, portal grants, result-export location and any separately installed GNOME Files/Nautilus extension without selecting or reading user files. Install stable `dev.geopjr.Collision` from verified Flathub in the existing ownership scope. Do not use the GitHub mirror as the release authority, compile from source, launch Collision, hash a sample file or install the optional host Nautilus extension.

Preserve every target file byte-for-byte and retain algorithm preferences, exports, portal choices and extension state. Hashing is read-only but not impact-free: reading large, sparse, removable, encrypted, network-mounted or cloud-placeholder files may consume bandwidth, hydrate data, wake devices or expose access patterns. Never traverse a directory, follow an unreviewed symlink, read a special file, resolve private real paths into logs or hash user data as installation verification. If a file changes while being read, reject the result rather than presenting it as stable evidence.

A matching checksum proves equality only to the referenced digest; it does not prove the digest source or file publisher is trustworthy. Before future verification show the expected hash's independent HTTPS/signature source, release and channel, exact filename binding, algorithm and manifest parsing. Prefer SHA-256, SHA-512 or BLAKE3 for integrity. Treat MD5 and SHA-1 as collision-weakened compatibility checks, and CRC32/Adler32 as accidental-error detection, never as authenticity evidence. Do not silently trim ambiguous records, select the first hash from a multi-file manifest or compare across different algorithms.

Markdown exports and clipboard copies can disclose filenames, absolute paths and digests. Require explicit fields, destination permissions and redaction before export. The Nautilus extension runs outside the Flatpak and has its own security/update boundary; do not install, update, restart Files or claim its context menu during setup. Verify Collision source, app ID, origin, commit, runtime, executable, files and permissions offline. Prove no file was opened, hydrated or hashed, no portal grant, export, clipboard, extension, process, network mount or network request changed. On failure, rollback only the new Collision ref in its original scope; preserve shared runtimes, remotes, overrides, files, reports and host extensions.
