# kitty setup prompt

Set up kitty from its verified official source (https://github.com/kovidgoyal/kitty). Supported targets: macOS, Linux. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Use kitty's official binary installer, signed macOS application, or trusted distribution package and keep user and system installs distinct.

Preserve kitty configuration, session files, themes, kittens, shell integration, and desktop or file associations. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: preferred_shell, terminal_font, terminal_theme, config_directory. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Do not run custom kittens, enable remote control, modify login shells, or change the default terminal without approval. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Run `kitty --version`, validate the intended configuration path, and open one local window without restoring sessions or executing startup commands. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
