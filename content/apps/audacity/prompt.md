# Audacity setup prompt

Codex, inspect the operating system, architecture, shell, existing Audacity installation, audio input and output devices, sample-rate support, plugins, preferences, and project directories before changes. Use Audacity’s official signed installer on macOS or Windows; on Linux prefer the distribution package or official AppImage when suitable. Ask before administrator access, replacing the application, changing file associations, granting microphone access, installing FFmpeg or plugins, enabling telemetry-related options, or overwriting preferences. Preserve projects, autosaves, macros, effects, plugin paths, and custom shortcuts. Configure only `recording_device`, `playback_device`, `sample_rate`, and `project_directory` when supplied. Confirm that requested devices are present and that the sample rate is supported by both input and output hardware. Never open or rewrite an existing project for testing. Verify application launch, device enumeration, plugin scanning, recording and playback through a short disposable mono test, and export to an uncompressed temporary file. Ask before accessing a live microphone in restricted environments. Rollback restores preference backups, removes only plugins or codec components added here, and uninstalls only the installed package while leaving projects intact. Finish with a structured summary of installer, devices, sample rate, project path, verification, approvals, and rollback.
