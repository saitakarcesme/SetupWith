# Cartridges setup prompt

Set up Cartridges from its canonical project and verified Flathub listing (https://apps.gnome.org/Cartridges/). Inventory Linux architecture, desktop, Flatpak scopes, existing Cartridges package and data, game entries, covers, hidden flags, sort preferences, GNOME search-provider state, and locally installed Steam, Lutris, Heroic, Bottles, itch, Legendary, RetroArch, Flatpak and desktop-entry sources. Install stable `page.kramo.Cartridges` from the verified Flathub origin in the existing ownership scope. Do not use a mirrored release binary, source build or alternate channel, and do not add filesystem overrides during setup.

Install without launching Cartridges, importing a source, scanning game directories, downloading cover art, enabling search integration or starting a game. Preserve every library entry, source association, title, executable, command, argument, environment variable, working directory, compatibility prefix, ROM path, cover, hidden state, date added, last-played value and preference. Local launcher databases and manifests can reveal owned games, account identifiers, play habits and filesystem layout; never print their contents or upload an inventory. No-login import does not mean privacy-free import.

Treat imported launch commands as executable code. Before any future import or manual edit, show the exact source database, records selected, duplicate-resolution plan, resolved executable, arguments, working directory, environment, compatibility layer and required sandbox paths. Never normalize shell metacharacters into a command, execute a title to verify it, merge duplicates by name alone, modify the source launcher, expose an entire home directory or infer access to ROM collections. Keep imported data read-only until the user approves the proposed Cartridges-only records.

Automatic cover lookup can transmit game titles to SteamGridDB or another database and download animated, remotely controlled media. Require endpoint, query, license, size and destination approval; do not fetch covers as a setup test. The GNOME search provider can expose library names in shell search and activate a game, so do not enable or query it. Verify Cartridges provenance, app ID, origin, installed commit, runtime, executable, files and declared permissions through Flatpak metadata offline. Compare preflight data, source and integration inventories and prove no import, library record, cover, command, handler, search-provider setting, process or network request changed. On failure, rollback only the new Cartridges ref in its original scope; preserve shared runtimes, remotes, overrides and all game data.
