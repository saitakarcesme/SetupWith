# Loupe setup prompt

Set up Loupe from its official GNOME project and verified Flathub listing (https://apps.gnome.org/Loupe/). Inventory Linux architecture, Flatpak scopes, existing package and data paths, recent-item and thumbnail-cache counts, aggregate cache bytes, portal grants, supported decoder classes, edit-policy presence, sandbox overrides and backup coverage without opening images or revealing filenames, directory names, pixels, thumbnails, EXIF, GPS, timestamps, device identifiers, faces, edits or private subjects. Install stable `org.gnome.Loupe` from verified Flathub in the existing ownership scope. Do not compile from source, launch Loupe, enumerate a directory, open or decode an image, generate a thumbnail, read metadata, navigate to an adjacent file, render animation, crop, rotate, flip, rewrite a file, update recents or invoke a portal during setup.

Preserve every original and edited image byte, owner, permission, timestamp and metadata field, plus sidecars, recent state, thumbnail caches, display preferences, remotes, overrides and scope ownership. Image files are untrusted parser input even when their extension and MIME appear familiar. Never expose embedded GPS, camera identifiers, timestamps, faces or hidden thumbnails in diagnostics. Installation must not apply EXIF orientation destructively, regenerate a lossy image, strip profiles or metadata, traverse sibling files, or replace the default image handler without review.

Before later viewing, validate signature and final format independently from the filename; enforce file-byte, pixel, dimension, frame, recursion, decompression, memory and time limits in decoder isolation. Decide whether animation is allowed. Review EXIF, XMP and IPTC fields before any export or share. Treat orientation as a display transform until an explicit edit. Define color-space, ICC, HDR, alpha and bit-depth behavior so the preview and saved output are not silently different. Use a synthetic corpus for decoder testing, including malformed and oversized fixtures, without touching user media.

For crop, rotation or flip, preview the exact transform, destination, format, quality and metadata result. Preserve the original by default, use an atomic write, prevent symlink and filename collisions, verify available space and compare decoded dimensions and checksum after save. Verify provenance, app ID, origin, commit, runtime, executable, files and static permissions offline. Prove no directory enumeration, file or metadata read, decode, thumbnail, render, adjacent navigation, edit, write, recent-item or cache mutation occurred. On failure, rollback only the new Loupe ref in its original scope; preserve shared runtimes, remotes, overrides, images, metadata, sidecars, caches and backups.
