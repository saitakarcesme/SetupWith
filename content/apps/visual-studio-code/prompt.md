# Visual Studio Code setup prompt

Codex, first inspect the operating system, CPU architecture, current shell, PATH, existing Visual Studio Code installations, and any managed or portable setup. Report what you find before changing anything. On macOS, prefer the official signed app or Homebrew Cask package `visual-studio-code`; on Debian/Ubuntu use Microsoft’s signed repository and `code` package; on Fedora-family systems use Microsoft’s RPM repository; on Windows prefer `winget install Microsoft.VisualStudioCode`, unless an existing installer channel should be preserved. Ask before using administrator access, replacing an existing app bundle, changing PATH, or enabling browser sign-in. Preserve `settings.json`, `keybindings.json`, snippets, profiles, and extensions. Configure only `preferred_shell`, `editor_font_size`, and `editor_theme` when supplied, merging settings rather than overwriting files. If requested, install the `code` shell command through the supported mechanism and verify it resolves correctly. Confirm launchability, print `code --version`, open a temporary folder, and check that the integrated terminal uses the requested shell without modifying the system default. Rollback must remove only components added in this run and restore any backed-up settings. Finish with a structured summary containing detected platform, install method, changed files, configured values, verification results, skipped approvals, and rollback commands.
