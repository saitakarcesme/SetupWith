# Warp setup prompt

Set up Warp from its verified official source (https://www.warp.dev/download). Supported targets: macOS, Linux, Windows. Begin with a read-only preflight covering the operating system, architecture, shell, package managers, disk space, relevant runtimes or hardware, and any existing installation. Choose Warp's signed platform package or documented package-manager channel for the detected architecture, verify Metal, ConPTY, glibc, and graphics prerequisites, and do not add a Linux repository or replace a stable build with Warp Preview without approval.

Preserve the current login shell, terminal profiles, imported themes and shortcuts, Warp local state, privacy choices, crash-reporting preference, account session, cloud-synced settings, workflows, agent profiles, command history, and default-terminal associations. Back up files before editing and explain the selected version, source, location, dependencies, and commands. Apply only supplied, supported preferences: startup_shell, telemetry_enabled, crash_reporting, settings_sync. No credential references are needed for this setup.

Ask before elevation, system-wide packages, services or startup items, ports or firewall rules, sign-in, large downloads, overwrites, or migrations.  Do not enable startup items, background services, overlays, notifications, analytics, or device permissions unless they are requested and separately approved. Keep first launch signed out and offline-capable; stop before browser authentication, SSO, importing another terminal's settings, enabling telemetry or crash reports, syncing settings, indexing repositories, running an agent, sharing sessions, installing the Oz CLI, or changing PATH and default-terminal integration. For a large game or media download, report the exact size, destination drive, free space, and bandwidth impact, then wait for approval. Never delete game libraries, save files, media libraries, mods, profiles, or cloud-sync data. If the platform or configuration is unsupported, stop and offer the closest official alternative.

Confirm package signature, Warp version, architecture, graphics or ConPTY readiness, and selected startup shell; open a disposable local session, execute only a harmless printf command, inspect privacy toggles and network log, then verify no login, cloud sync, repository index, telemetry opt-in, or shell file change occurred. Report the version, executable, configuration and data paths, changed files, active processes or listeners, and verification evidence without exposing sensitive values. End with manual steps and exact rollback or uninstall instructions that remove only setup-owned changes, restore backups, stop new services, and preserve user data.
